# 01 快速开始（5 分钟）

> 面向第一次接触本软件的用户。跟着下面的步骤走，5 分钟内即可完成安装并看到软件运行起来。

---

## 一、前置条件

- 已安装 **Python 3.10 及以上**（推荐 3.12），并能使用 `pip`。
- 如果要使用远程 MATLAB 计算引擎，还需要 **MATLAB R2020b 及以上**（推荐 R2025b）。
- 完整环境要求请见 [02 用户安装指南](02_用户安装指南.md)。

> 提示：只想快速看一眼软件？可以跳过 MATLAB，直接用内置的本地计算引擎和演示数据跑通全流程。

---

## 二、最快安装

### 方式 A：从源码安装（推荐用于评估）

```bash
# 1. 进入项目目录
cd D:\work\demo\industrial-vision

# 2. 创建并激活虚拟环境（强烈建议）
python -m venv venv
venv\Scripts\activate

# 3. 安装依赖
pip install -r requirements.txt
```

### 方式 B：直接运行打包好的 exe

如果拿到的是已经打包好的 `CSAM_Repair.exe`，双击即可运行，无需安装 Python，跳到下面的「启动软件」一节。

---

## 三、启动软件

本软件由两部分组成：**MATLAB Server**（可选，提供远程算法计算）和 **GUI 主程序**。第一次上手只需启动 GUI 即可。

### 1. 启动 GUI 主程序

```bash
# 确保已激活虚拟环境
cd D:\work\demo\industrial-vision
python run_app.py
```

窗口标题为「冷喷涂缺陷修复软件 v1.0.0」，默认尺寸 1700×950，采用暗色主题。启动后约 300 毫秒会自动加载一份 8000 点的演示数据，无需准备任何外部文件。

### 2. 启动 MATLAB Server（可选）

只有当你在左侧「计算引擎」下拉框里选择了「远程服务 (MATLAB)」时才需要这一步。

```matlab
% 在 MATLAB 命令窗口中执行
cd('D:\work\demo\industrial-vision\matlab_server')
startup
```

看到 `CSAM MATLAB Server starting on tcp://*:5570 ...` 即表示服务已就绪。

---

## 四、30 秒验证连接成功

软件启动后，请观察窗口右下角的状态栏：

| 状态栏显示 | 含义 |
|------------|------|
| ⚫ 本地模式 | 使用本地计算引擎，可直接开始操作，无需 MATLAB |
| 🟡 远程服务就绪（未连接） | 已检测到远程服务能力，切换到「远程服务 (MATLAB)」后会尝试连接 |

只要看到上述任一提示，并且左侧能看到演示点云，就说明软件已正常运行。

---

## 五、最简操作流程

软件启动后已经自动加载了演示数据，下面 5 步即可跑通「加载点云 → 选区 → 生成路径 → 形貌预测 → 导出」的完整链路：

1. **选区**：在中心 3D 视图上方点击「✂️ 选取模式」按钮切换到选取模式，用鼠标在点云上拖出一个矩形框选住缺陷区域（红色高亮）。
2. **生成路径**：在左侧「路径规划面板」点击蓝色按钮 **「🔧 生成修复路径」**。本地引擎会逐层实时渲染路径航点。
3. **进入形貌预测**：点击左侧工作流的 **「02 形貌预测」** 步骤按钮。
4. **执行预测**：点击紫色按钮 **「🔮 执行形貌预测」**，等待沉积模拟完成，右侧「结果摘要」会显示填充点数、修复层数等指标。
5. **导出结果**：回到「01 数据与路径」点击 **「📤 导出 G-code」** 保存刀具路径，或在「02 形貌预测」点击 **「📄 导出 PDF 报告」** 生成修复报告。

> 完整的页面、按钮、参数说明请见 [03 用户操作手册](03_用户操作手册.md)。

## 六、第一个问题？

如果上面任意一步卡住了，大概率是下面几种情况：

- **窗口一片空白 / 点云没显示？** 等待 1–2 秒让演示数据加载完成；或点击左侧「📂 加载点云」并在弹窗里选「是」加载演示数据。
- **「生成修复路径」按钮是灰的？** 说明还没框选缺陷区域，请先切换到「✂️ 选取模式」并框选至少 3 个点。
- **选了「远程服务 (MATLAB)」但没反应？** 请先按上面第三节的方法启动 MATLAB Server，详见 [06 故障排查](06_故障排查.md)。
- **提示许可证验证失败？** 开发环境下会自动使用内置开发密钥，不影响功能；生产环境需设置 `CSAM_HMAC_SECRET`，详见 [02 用户安装指南](02_用户安装指南.md)。

更多常见问题请查阅 [05 常见问题](05_常见问题.md)。
