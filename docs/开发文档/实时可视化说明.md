# 实时可视化使用说明

> 版本：1.0.0 | 协议：v2.1 | 更新日期：2026-07-14 | 文档语言：简体中文

## 这份文档讲什么

讲软件在 MATLAB 计算时，怎么让画面跟着一步步刷新，而不是等全部算完才显示。

你会学到：

- 计算过程中画面怎么变
- 怎么用滑块、播放、暂停看每一层
- 怎么看耗时、层数、点数、网格数
- 出问题怎么办

---

## 一句话理解

MATLAB 每算完一小步，立刻把结果发给软件。软件马上把这一步画出来。你不用等。

---

## 整体流程图

```
MATLAB 计算（每一步）
      ↓
   发送进度（ZMQ PUB，端口 5556）
      ↓
软件接收进度（ZMQ SUB）
      ↓
立刻刷新四样东西：
   1. 3D 预览（路径 / 沉积 / 网格）
   2. 实时统计面板（耗时 / 层数 / 点数 / 网格数）
   3. 逐层播放器（滑块跟着走）
   4. 状态栏提示
```

---

## 你会看到什么

### 1. 实时统计面板（屏幕中间偏下）

四个小卡片，每算一步就更新一次：

| 卡片 | 含义 | 例子 |
|------|------|------|
| 耗时 | 从开始计算到现在用了多少秒 | `12.5s` |
| Layer | 当前层 / 总层数 | `3 / 10` |
| Point | 已经算出的航点数 | `150` |
| Mesh | 已经算出的网格三角形数 | `1200` |

卡片下面有一条进度条，显示完成百分比。

最下面一行是状态文字，例如：

```
[STAGE_PROFILE_PREDICTION] Layer 3/10 deposition step 45/100
```

### 2. 逐层播放器（统计面板下面）

这一行控件让你看每一层：

```
[◀]  [▶ 播放]  [▶]   Layer: 3 / 10
[======== slider =========]  速度: [500 ms]
```

按钮从左到右：

| 按钮 | 作用 |
|------|------|
| ◀ | 上一层 |
| ▶ 播放 | 自动一层一层往下播放（再按一次暂停） |
| ▶ | 下一层 |

滑块：用鼠标拖动，直接跳到任意一层。

速度框：改数字调整播放快慢。数字越小越快。范围 100 到 3000 毫秒。

### 3. 3D 预览画面（屏幕中间主区）

每算一步，画面立刻更新：

- 路径线（橙色的线）随着航点增加而变长
- 沉积表面（彩色网格）随着每层完成而长高
- 起点和终点用方块标记

切到 "MATLAB 形貌分析" 这个标签页，还能看到完整的形貌结果。

## 怎么操作

### 看计算过程（自动）

1. 点 "开始计算"
2. 别动，看画面自己变
3. 统计面板的数字会跳，3D 画面会跟着长
4. 进度条到 100% 就是算完了

### 回看某一层

计算完之后（或者计算中间也能看），用逐层播放器：

1. 拖滑块到你想看的层
2. 画面立刻显示那一层的样子
3. 或者按 "▶ 播放" 自动从当前层往下播
4. 按 "▶ 播放" 变成 "⏸ 暂停"，再按一次就停

### 暂停播放

按 "⏸ 暂停" 按钮。播放停在当前层。

### 调播放速度

在速度框里改数字：

- 想快：改成 100 到 200
- 想慢：改成 1000 到 3000

## 背后怎么工作的（简单版）

### 三件事配合

```
MATLAB 算一步
   ↓ 用 py. 调用发消息
Bridge 转发（端口 5556）
   ↓ 软件后台线程收消息
软件主画面刷新
```

### 关键点

- MATLAB 算一步，立刻发一次进度。不等下一步。
- 软件收到就画。不等全部算完。
- 如果 MATLAB 里发消息失败，不影响计算。计算照常跑，只是画面不更新。
- 软件把每一层的数据存起来。你拖滑块回看时，从存的地方取出来再画。

| 文件 | 改了什么 |
|------|----------|
| `profile_prediction/run_profile_prediction.m` | 在逐点循环里，每步算完调用 `py.repair_app.bridge.progress_publisher.publish_progress(...)` 发进度。包在 `try/catch` 里，失败不影响算法。 |

## 信号连接关系

软件主窗口接到进度后，分四路处理：

```
ProgressSubscriber
   ├── stats_updated  →  RealtimeStatsPanel.update_stats()
   │                      （刷新四个卡片 + 进度条）
   │
   ├── layer_completed →  MainWindow._on_layer_completed()
   │                      （同步 LayerPlayer 到当前层）
   │
   ├── mesh_updated    →  MainWindow._on_mesh_updated()
   │                      （立刻刷新 3D 预览的沉积表面）
   │
   └── progress_received → MainWindow._on_progress_received()
                           （缓存这一层数据 + 刷新航点 + 刷新 mesh）
```

拖滑块时：

```
LayerPlayer.layer_changed
   → MainWindow._on_layer_changed()
   → 从 _layer_data_cache 取出这一层数据
   → 重放航点和 mesh 到 3D 预览
```

## 什么时候启动和停止

| 事件 | 动作 |
|------|------|
| 点 "开始计算" | 启动订阅器，清空层缓存，重置统计面板和播放器 |
| 计算线程结束（成功或失败） | 停止订阅器 |
| 计算失败弹窗 | 停止订阅器 |
| 关软件窗口 | 停止订阅器 |

---

## 进度消息里有什么

每一条进度消息（`ProgressUpdate` protobuf）包含：

| 字段 | 含义 |
|------|------|
| `request_id` | 请求编号 |
| `stage` | 当前阶段（路径规划 / 形貌预测 / 结果生成） |
| `layer_index` | 当前层号 |
| `total_layers` | 总层数 |
| `progress` | 进度 0.0 到 1.0 |
| `message` | 状态文字 |
| `partial_waypoints` | 这一步的航点（含法向量和速度） |
| `partial_mesh_data` | 这一步的网格（二进制 STL） |
| `layer_profiles` | 这一层的高度和沉积效率 |

## 常见问题

### 计算时画面不动

可能原因：

1. MATLAB 没启动，或者 Bridge 没连上。看状态栏有没有 "MATLAB 已就绪"。
2. MATLAB 里 `py.` 调用失败。看 MATLAB 命令行窗口有没有报错。
3. ZMQ 端口 5556 被占用。关掉占用端口的程序。

### 滑块拖不动

总层数还是 0。等 MATLAB 算出第一步，发了第一条进度消息，滑块就能用了。

### 播放太快看不清

把速度框里的数字改大。比如改成 1000 或 2000。数字是毫秒，1000 就是每秒跳一层。

### 统计面板的数字不跳

和画面不动一样的原因。先确认 MATLAB 和 Bridge 连上了。

### 计算完了，拖滑块回看，画面是空的

这一层 MATLAB 没发数据，或者数据丢了。正常情况下每层都会有缓存。如果某一层确实没数据，跳过它看下一层就行。

## 端口说明

软件用两个 ZMQ 端口：

| 端口 | 用途 | 模式 |
|------|------|------|
| 5555 | 请求-响应（软件问，MATLAB 答） | REP / REQ |
| 5556 | 实时进度推送（MATLAB 发，软件收） | PUB / SUB |

两个端口互不干扰。5555 走正常计算请求，5556 专门推实时进度。

## 技术细节（给开发人员看）

### ZMQ PUB/SUB 为什么不会卡住 MATLAB

- PUB 是 "发完就不管" 模式。没有订阅者也不阻塞。
- MATLAB 里 `publish_progress` 包在 `try/catch` 里，任何异常都静默跳过。
- 即使软件没开，MATLAB 照常算完。

### 线程模型

```
主线程（GUI）
   ├── ProgressSubscriberWorker（QThread）
   │      └── ZMQ SUB recv 循环（1 秒超时轮询）
   │             └── 收到消息 → 发 Qt 信号
   │
   └── 信号跨线程到主线程 → 刷新 GUI
```

Qt 信号跨线程自动用队列连接，线程安全。

### STL bytes 解析

`_parse_binary_stl_to_points` 把二进制 STL 转成 N×3 点云：

- 80 字节 header 跳过
- 4 字节读三角形数量
- 每个三角形 50 字节：12 字节法向量 + 36 字节三顶点 + 2 字节属性
- 只取顶点，丢掉法向量和属性

转成点云后，复用 `RepairVisualizer` 已有的沉积表面渲染逻辑。

### 层数据缓存

`_layer_data_cache` 是个字典，key 是层号，value 是这一层的：

- 航点数组
- mesh bytes
- 进度值
- 状态文字
- 阶段名

拖滑块时从缓存取，不用重新算。计算开始时清空，保证不会有上次的残留数据。
