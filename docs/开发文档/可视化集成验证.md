# 可视化集成验证报告

> 版本：1.0.0 | 协议：v2.1 | 更新日期：2026-07-14 | 文档语言：简体中文

> 本文档验证：GUI 显示的是 MATLAB 真正计算得到的数据，不是 Python Demo 重新计算的结果。
> MATLAB 负责计算，Python 负责展示，两者职责严格分离。

---

## 一、目标与原则

### 1.1 用户要求

- GUI 必须显示 MATLAB 真正计算得到的数据
- 禁止 Python 自己重新计算
- MATLAB 负责：路径规划、形貌预测、mesh、layer、profile、particle 全部输出
- Python 负责：接收数据、原生渲染、展示

### 1.2 已验证的设计原则

| 原则 | 实现状态 | 说明 |
|------|---------|------|
| MATLAB 负责计算 | 已实现 | `MATLABPipeline` 一次调用完成路径规划 + 形貌预测 |
| Python 负责展示 | 已实现 | `ProfileResultPanel` 原生渲染所有可视化 |
| 禁止 Python 重新计算 | 已实现 | Python 仅做数值→图形的映射，不调用任何算法 |
| MATLAB figure 不参与 | 已实现 | 不读取 PNG / 视频 / MATLAB Figure，纯数值传递 |

## 二、GUI 可视化能力清单

### 2.1 主界面结构

GUI 主界面包含两个核心可视化区域：

1. **3D 预览面板**（`RepairVisualizer`）
   - 显示基体表面
   - 显示路径规划航点
   - 显示喷嘴方向（法向量）
   - 显示路径动画

2. **MATLAB 形貌分析面板**（`ProfileResultPanel`）
   - 6 个指标卡片
   - 4 个 Tab 多视图

### 2.2 指标卡片（6 个）

| 卡片名称 | 显示内容 | 数据来源 |
|---------|---------|---------|
| 材料用量 | estimated_mass_g (g) | MATLAB 形貌预测 |
| 预计耗时 | estimated_time_s (s) | MATLAB 形貌预测 |
| 沉积体积 | predicted_volume_mm3 (mm³) | MATLAB 形貌预测 |
| 均匀性 | uniformity_score (%) | MATLAB 形貌预测 |
| 粒子总数 | particle_dist.total_particles | MATLAB 形貌预测 |
| 警告数 | warnings 列表长度 | MATLAB 形貌预测 |

### 2.3 Tab 多视图（4 个）

| Tab 名称 | 显示内容 | 渲染方式 |
|---------|---------|---------|
| 沉积网格 (Mesh) | 3D 三角网格曲面，按 Z 着色 | `Poly3DCollection` |
| 逐层轮廓 | 双轴图：最大/平均高度柱状图 + 沉积效率折线 | matplotlib 双轴 |
| 粒子分布 | XY 散点热力图（速度着色）+ 速度直方图 | matplotlib scatter + hist |
| 均匀性仪表 | 半圆仪表盘 + 评价文字 + 警告列表 | matplotlib Wedge |

### 2.4 所有图形自带工具栏

每个 matplotlib 图形都继承 `NavigationToolbar2QT`，支持：
- 缩放
- 平移
- 旋转（3D 视图）
- 刷新
- 导出 PNG

## 三、MATLAB → GUI 完整数据流

### 3.1 数据流图

```
┌─────────────────────────────────────────────────────────────┐
│ MATLAB 端（计算）                                            │
│                                                              │
│  run_path_planning.m    →  航点 (M×6) + 速度 + 层号          │
│         ↓                                                    │
│  run_profile_prediction.m →  mesh (T×9)                     │
│                              layer_profiles (L×4)            │
│                              particle_distribution           │
│                              uniformity                      │
│                              estimated_mass_g                │
│                              estimated_time_s                │
│                              predicted_volume_mm3            │
│                              warnings                        │
└─────────────────────────────────────────────────────────────┘
                          ↓ MATLAB Engine API
                          ↓ (matlab.double → Python dict)
┌─────────────────────────────────────────────────────────────┐
│ Python Bridge 端（传递，不计算）                              │
│                                                              │
│  matlab_engine_proxy.py                                     │
│    call_full_pipeline()                                      │
│      → _parse_profile_result()  (matlab.double → ndarray)   │
│      → _triangles_to_binary_stl()  (mesh → STL bytes)       │
│                                                              │
│  matlab_pipeline.py                                          │
│    MATLABPipeline.run()  返回完整 dict                        │
│                                                              │
│  matlab_adapter.py                                           │
│    handle_repair()                                           │
│      → build_repair_result()  (dict → Protobuf RepairResult) │
│        - waypoints                                            │
│        - mesh_data (STL bytes)                               │
│        - layer_profiles (List[LayerProfile])                 │
│        - particle_dist (ParticleDistribution)                │
│        - uniformity_score                                     │
│        - estimated_mass_g / estimated_time_s                  │
│        - predicted_volume_mm3                                 │
│        - warnings → 嵌入 feasibility_reason                  │
└─────────────────────────────────────────────────────────────┘
                          ↓ ZeroMQ REP/REQ
                          ↓ (Protobuf 二进制)
┌─────────────────────────────────────────────────────────────┐
│ Python GUI 端（展示，不计算）                                 │
│                                                              │
│  main_window.py                                             │
│    _on_zmq_path_result()                                     │
│      → parse_repair_result()  (RepairResult → dict)          │
│      → 从 feasibility_reason 解析 warnings                   │
│      → _profile_panel.set_profile_result(dict)              │
│                                                              │
│  profile_result_panel.py                                    │
│    set_profile_result()                                      │
│      → _update_metric_cards()   (6 个指标卡片)               │
│      → _render_mesh()           (3D 三角网格)                │
│      → _render_layers()         (逐层轮廓双轴图)             │
│      → _render_particles()      (粒子分布热力图)             │
│      → _render_uniformity()      (均匀性仪表盘)              │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 数据流关键节点

| 阶段 | 文件 | 函数 | 数据格式 |
|------|------|------|---------|
| MATLAB 计算 | `run_profile_prediction.m` | `run_profile_prediction()` | MATLAB struct |
| Engine 解析 | `matlab_engine_proxy.py` | `_parse_profile_result()` | Python dict + ndarray |
| Pipeline 封装 | `matlab_pipeline.py` | `MATLABPipeline.run()` | Python dict |
| Adapter 序列化 | `matlab_adapter.py` | `handle_repair()` | Protobuf RepairResult |

| GUI 解析 | `main_window.py` | `_on_zmq_path_result()` | Python dict |
| GUI 渲染 | `profile_result_panel.py` | `set_profile_result()` | matplotlib 图形 |

## 四、各可视化字段的来源与传递路径

### 4.1 mesh（沉积网格）

```
MATLAB run_profile_prediction.m
  → result.mesh (T×9 matlab.double)
  → _parse_profile_result() 转为 ndarray (T,9)
  → _triangles_to_binary_stl() 转为二进制 STL bytes
  → build_repair_result(mesh_data=stl_bytes, mesh_format="stl_binary")
  → parse_repair_result() 解析为 mesh_bytes + mesh_format
  → set_profile_result(mesh_bytes=...)
  → _render_mesh()
      → decode_binary_stl(mesh_bytes) 解码回 (T,9)
      → Poly3DCollection 3D 渲染，按 Z 着色
```

**验证**：mesh 数据来自 MATLAB 的 `profilePredict` 算法，Python 仅做 STL 编解码和 matplotlib 渲染，不重新计算网格。

### 4.2 layer_profiles（逐层轮廓）

```
MATLAB run_profile_prediction.m
  → result.layer_profiles (L×4 matlab.double)
      每行 = [layer_idx, max_height_mm, avg_height_mm, dep_efficiency]
  → _parse_profile_result() 转为 ndarray (L,4)
  → build_layer_profile() 构建为 List[LayerProfile] Protobuf 消息
  → build_repair_result(layer_profiles=[...])
  → parse_repair_result() → parse_layer_profiles() 解析为 List[dict]
  → set_profile_result(layer_profiles=[...])
  → _render_layers()
      → 双轴图：柱状图(最大/平均高度) + 折线图(沉积效率)
```

**验证**：逐层轮廓数据来自 MATLAB 的 `profilePredict` 算法，Python 仅做柱状图和折线图渲染，不重新计算层高度。

### 4.3 particle_distribution（粒子分布）

```
MATLAB run_profile_prediction.m
  → result.particle_distribution (struct)
      含 px, py, vx, vy, vz, vcr, diameter, temperature, dep_efficiency
  → _parse_profile_result() 转为 Python dict (含 ndarray)
  → build_particle_distribution() 构建为 ParticleDistribution Protobuf 消息
  → build_repair_result(particle_dist=msg)
  → parse_repair_result() → parse_particle_distribution() 解析为 dict
  → set_profile_result(particle_dist={...})
  → _render_particles()
      → XY 散点图（速度热力着色）+ 速度直方图
```

**验证**：粒子分布数据来自 MATLAB 的 `particleFitting` 算法，Python 仅做散点图和直方图渲染，不重新生成粒子。

### 4.4 uniformity（均匀性）

```
MATLAB run_profile_prediction.m
  → result.uniformity (float)
  → _parse_profile_result() 转为 Python float
  → build_repair_result(uniformity_score=...)
  → parse_repair_result() 解析为 uniformity_score
  → set_profile_result(uniformity_score=...)
  → _render_uniformity()
      → 半圆仪表盘 + 评价文字
```

**验证**：均匀性评分来自 MATLAB 计算，Python 仅做仪表盘渲染，不重新计算均匀性。

### 4.5 路径规划航点（waypoints）

```
MATLAB run_path_planning.m
  → pointlist (M×6) + feed_rates (M×1) + layer_indices (M×1)
  → MATLABPipeline 合并为 waypoints (M×8)
  → build_repair_result(waypoints=...) 序列化为 Protobuf
  → parse_repair_result() 解析为 waypoints (M,7) + waypoint_layers (M,)
  → _finish_path_planning() 传递给 RepairVisualizer
  → 3D 预览面板显示路径动画
```

**验证**：航点数据来自 MATLAB 的 `run_path_planning` 算法，Python 仅做 3D 路径渲染和动画，不重新规划路径。

### 4.6 warnings（警告列表）

```
MATLAB run_profile_prediction.m
  → result.warnings (cell array of strings)
  → _parse_profile_result() 转为 Python list[str]
  → matlab_adapter.py handle_repair()
      → 嵌入 feasibility_reason 字符串：
        "MATLAB pipeline completed (...) | Warnings: w1; w2; w3"
  → parse_repair_result() 解析 feasibility_reason
  → main_window.py _on_zmq_path_result()
      → 从 feasibility_reason 解析回 list[str]
  → set_profile_result(warnings=[...])
  → 指标卡片显示警告数
  → 均匀性仪表盘显示警告列表
```

**验证**：警告来自 MATLAB 算法运行时的真实告警，Python 仅做字符串解析和显示，不生成警告。

> **注意**：Protobuf v2.1 协议无独立 `warnings` 字段，通过 `feasibility_reason` 字符串嵌入传递。这是本次任务修复的关键问题（见第五节）。

### 4.7 统计信息（材料用量/耗时/体积）

```
MATLAB run_profile_prediction.m
  → result.estimated_mass_g (float)
  → result.estimated_time_s (float)
  → result.predicted_volume_mm3 (float)
  → _parse_profile_result() 转为 Python float
  → build_repair_result(estimated_mass_g=..., estimated_time_s=..., predicted_volume_mm3=...)
  → parse_repair_result() 解析
  → set_profile_result(estimated_mass_g=..., estimated_time_s=..., predicted_volume_mm3=...)
  → 6 个指标卡片显示
```

**验证**：所有统计指标来自 MATLAB 计算，Python 仅做数值格式化和卡片显示，不重新估算。

## 五、已修复的问题

### 5.1 问题：warnings 字段传递缺失

**现象**：MATLAB 返回的 warnings 列表无法传递到 GUI。

**根因**：Protobuf v2.1 协议的 `RepairResult` 消息没有独立的 `warnings` 字段，`build_repair_result()` 函数也不接受 `warnings` 参数。

**修复方案**：将 warnings 嵌入 `feasibility_reason` 字符串传递，GUI 侧解析。

**修改文件 1**：`matlab_adapter.py`

```python
# _invoke_pipeline_with_fallback 返回值添加 warnings 字段
return {
    ...
    "warnings": list(result.get("warnings", []) or []),
}

# handle_repair 中将 warnings 嵌入 feasibility_reason
warnings_list = pipeline_result.get("warnings", [])
reason = "MATLAB pipeline completed (path planning + profile prediction)"
if warnings_list:
    reason += " | Warnings: " + "; ".join(str(w) for w in warnings_list[:5])
```

**修改文件 2**：`main_window.py`

```python
# _on_zmq_path_result 中从 feasibility_reason 解析 warnings
reason = result.get("feasibility_reason", "") or ""
warnings_list = []
if "Warnings:" in reason:
    warns_part = reason.split("Warnings:", 1)[1].strip()
    warnings_list = [w.strip() for w in warns_part.split(";") if w.strip()]

self._profile_panel.set_profile_result({
    ...
    "warnings": warnings_list,
})
```

### 5.2 验证 warnings 传递链路

```
MATLAB: warnings = {"层厚不足", "粒子速度偏低"}
  ↓
matlab_engine_proxy: result["warnings"] = ["层厚不足", "粒子速度偏低"]
  ↓
matlab_adapter: reason = "... | Warnings: 层厚不足; 粒子速度偏低"
  ↓
parse_repair_result: feasibility_reason = "... | Warnings: 层厚不足; 粒子速度偏低"
  ↓
main_window: warnings_list = ["层厚不足", "粒子速度偏低"]
  ↓
profile_result_panel: 指标卡片显示 "2 条"，仪表盘显示警告文字
```

## 七、禁止项检查

### 7.1 禁止 Python 重新计算

**检查结果**：Python 端没有任何算法调用。

- `profile_result_panel.py` 中仅包含：
  - STL 解码（`decode_binary_stl`）—— 数据格式转换，非计算
  - matplotlib 渲染函数 —— 图形绘制，非计算
  - 指标卡片更新 —— 数值显示，非计算

- `main_window.py` 的 `_on_zmq_path_result` 中仅包含：
  - Protobuf 解析 —— 数据格式转换，非计算
  - 字符串解析 warnings —— 数据格式转换，非计算
  - 调用 `set_profile_result` —— 数据传递，非计算

### 7.2 禁止使用 MATLAB Figure

**检查结果**：GUI 不依赖任何 MATLAB Figure。

- 不调用 `eng.figure()` / `eng.saveas()` / `eng.print()`
- 不读取 `.png` / `.jpg` / `.fig` 文件
- 不嵌入 MATLAB 图像截图
- 所有图形由 matplotlib 原生渲染

### 7.3 禁止使用 Python Demo 数据

**检查结果**：生产路径使用 MATLAB 真实计算。

- `MATLABPipeline` 是唯一生产计算路径
- Python 启发式算法仅在 MATLAB 不可用时降级使用
- 降级时 `feasibility_reason` 明确标注 "Python heuristic (MATLAB unavailable)"
- 用户可通过 `CSAM_ALGORITHM_ENGINE=matlab` 强制使用 MATLAB，失败时报错而非降级
