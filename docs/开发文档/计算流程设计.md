# 计算流程重新设计报告

> 版本：1.0.0 | 协议：v2.1 | 更新日期：2026-07-14 | 文档语言：简体中文

> 本文档描述重新设计后的计算流程：用户只需点击"开始计算"按钮，后台自动完成全部步骤。
> 用户无需打开 MATLAB、无需运行 main.m、无需复制 pointlist / velocitylist。

## 一、设计目标

### 1.1 用户要求

点击"开始计算"按钮后，后台自动完成：

```
启动 MATLAB
    ↓
启动 Bridge
    ↓
加载算法
    ↓
路径规划
    ↓
形貌预测
    ↓
更新 GUI
    ↓
生成报告
```

### 1.2 用户禁止操作

| 禁止项 | 实现方式 |
|-------|---------|
| 不得打开 MATLAB | `MatlabBridgeLauncher` 自动以 `-batch` 模式启动 MATLAB，无 GUI 窗口 |
| 不得运行 main.m | main.m 已不存在，被 `run_path_planning.m` + `run_profile_prediction.m` 替代 |
| 不得复制 pointlist | 数据通过内存传递（`MATLABPipeline`），中间文件存系统临时目录自动清理 |
| 不得复制 velocitylist | 同上，速度数据通过内存传递 |

## 二、新增模块

### 2.1 MatlabBridgeLauncher（MATLAB + Bridge 自动启动器）

**文件**：`repair_app/bridge/launcher.py`

**职责**：自动查找 MATLAB 可执行文件，以 `-batch` 模式启动 MATLAB 并运行 `matlab_bridge_server.m`，等待 Bridge 端口就绪。

**核心方法**：

| 方法 | 说明 |
|------|------|
| `start(timeout=120)` | 启动 MATLAB + Bridge，阻塞直到端口就绪或超时 |
| `stop()` | 关闭由本启动器启动的 MATLAB 进程 |
| `is_running` | Bridge 端口是否可连接 |
| `reused_existing` | 是否复用了已运行的 Bridge |

**MATLAB 查找顺序**：

1. 环境变量 `CSAM_MATLAB_EXE`（用户指定路径）
2. PATH 中的 `matlab` 命令
3. Windows: `C:\Program Files\MATLAB\R20XXx\bin\matlab.exe`
4. macOS: `/Applications/MATLAB_R20XXx.app/bin/matlab`
5. Linux: `/usr/local/MATLAB/R20XXx/bin/matlab`

**启动命令**：

```
matlab.exe -batch "cd('项目根目录'); matlab_bridge_server"
```

`-batch` 模式特点：
- 不显示 MATLAB GUI 窗口
- 在后台静默执行脚本
- 脚本结束后 MATLAB 进程退出（但 `matlab_bridge_server` 的 `serve()` 会阻塞，保持运行）

**复用机制**：

若检测到 Bridge 端口（5555）已被占用（说明用户已手动启动 `matlab_bridge_server`），则跳过启动，直接复用现有会话，避免重复启动 MATLAB。

### 2.2 ComputePipelineWorker（计算管线工作线程）

**文件**：`repair_app/ui/workers.py`

**职责**：在 QThread 中执行完整计算流程，不阻塞 GUI。

**信号**：

| 信号 | 类型 | 说明 |
|------|------|------|
| `stage` | `str` | 阶段进度提示（如"正在启动 MATLAB..."） |
| `result` | `dict` | 完整计算结果（解析后的 dict） |
| `failed` | `str` | 失败原因 |

**执行流程**：

1. **阶段 1**：调用 `MatlabBridgeLauncher.start()` 启动 MATLAB + Bridge
2. **阶段 2**：通过 ZMQ REP/REQ 发送 protobuf 修复请求
3. **阶段 3**：接收响应，`deserialize_result` + `parse_repair_result` 解析为 dict

### 3.2 一键计算槽函数链路

```
用户点击"🚀 开始计算"
    ↓
_on_start_calculation()
    ├── 验证点云 + 选区
    ├── 构造 protobuf 请求（_build_repair_request）
    ├── 创建 ComputePipelineWorker（QThread）
    └── 启动线程
        ↓
    ComputePipelineWorker.run()
        ├── 阶段1：MatlabBridgeLauncher.start()  → 信号 stage("正在启动 MATLAB...")
        ├── 阶段2：ZMQ 发送请求                  → 信号 stage("正在执行路径规划 + 形貌预测...")
        └── 阶段3：解析结果                      → 信号 stage("正在解析 MATLAB 计算结果...")
            ↓
        信号 result(dict) 或 failed(str)
            ↓
    _on_compute_result(dict)  或  _on_compute_failed(str)
        ↓
    _on_compute_result:
        ├── 验证结果成功
        ├── 更新 MATLAB 形貌分析面板（set_profile_result）
        ├── 更新 3D 预览面板（_finish_path_planning）
        ├── 自动生成 PDF 报告（_auto_generate_report）
        └── _set_busy(False)
```

### 4.1 流程图

```
┌──────────────────────────────────────────────────────────────┐
│ 用户操作                                                      │
│                                                               │
│  1. 导入 STL 点云                                             │
│  2. 选取缺陷区域                                              │
│  3. 点击"🚀 开始计算"                                         │
│      ↓                                                        │
└──────────────────────────────────────────────────────────────┘
                    ↓
┌──────────────────────────────────────────────────────────────┐
│ 后台自动执行（ComputePipelineWorker，QThread）                 │
│                                                               │
│  ┌──阶段1：启动 MATLAB + Bridge──────────────────────────┐   │
│  │  MatlabBridgeLauncher.start()                          │   │
│  │    1. 检查端口 5555 是否已就绪                          │   │
│  │    2. 若未就绪：查找 matlab.exe                        │   │
│  │    3. subprocess 启动 MATLAB -batch                    │   │
│  │    4. MATLAB 运行 matlab_bridge_server.m              │   │
│  │       ├── setenv('CSAM_BRIDGE_IN_MATLAB', '1')        │   │
│  │       ├── shareEngine('matlab_bridge')                │   │
│  │       ├── addpath('形貌预测', '路径规划')              │   │
│  │       ├── import matlab_adapter                       │   │
│  │       └── adapter.serve()  ← 阻塞，等待请求            │   │
│  │    5. 轮询端口 5555 直到就绪（超时 120s）              │   │
│  └────────────────────────────────────────────────────────┘   │
│                      ↓                                        │
│  ┌──阶段2：发送计算请求（ZMQ REP/REQ）────────────────────┐  │
│  │  ZMQ REQ socket → tcp://127.0.0.1:5555                │   │
│  │  发送 protobuf RepairRequest bytes                     │   │
│  │      ↓                                                │   │
│  │  Bridge 端接收：                                       │   │
│  │    MatlabAdapter.handle_repair(request)               │   │
│  │      → _invoke_pipeline_with_fallback(xyz, meta)      │   │
│  │      → MATLABPipeline.run(xyz, meta)                  │   │
│  │          → eng.run_path_planning(stl, params)         │   │
│  │              → 航点 (M×6) + 速度 + 层号                │   │
│  │          → eng.run_profile_prediction(...)            │   │
│  │              → mesh + layer_profiles + particle_dist  │   │
│  │              + uniformity + mass + time + warnings    │   │
│  │      → build_repair_result(waypoints, mesh, ...)      │   │
│  │      → 返回 protobuf RepairResult bytes               │   │
│  │      ↓                                                │   │
│  │  ZMQ REQ 接收响应                                     │   │
│  └────────────────────────────────────────────────────────┘   │
│                      ↓                                        │
│  ┌──阶段3：解析结果──────────────────────────────────────┐   │
│  │  deserialize_result(reply_bytes)                       │   │
│  │  parse_repair_result(msg) → dict                       │   │
│  │      含 waypoints, mesh_bytes, layer_profiles,         │   │
│  │      particle_dist, uniformity_score, warnings 等      │   │
│  └────────────────────────────────────────────────────────┘   │
│                      ↓                                        │
│  信号 result.emit(dict)                                       │
└──────────────────────────────────────────────────────────────┘
                    ↓
┌──────────────────────────────────────────────────────────────┐
│ GUI 更新（_on_compute_result，主线程）                        │
│                                                               │
│  1. 更新 MATLAB 形貌分析面板（ProfileResultPanel）             │
│     ├── 6 个指标卡片（材料用量/耗时/体积/均匀性/粒子数/警告）  │
│     ├── 沉积网格 Tab（3D mesh，按 Z 着色）                    │
│     ├── 逐层轮廓 Tab（柱状图 + 效率折线）                     │
│     ├── 粒子分布 Tab（散点热力图 + 直方图）                   │
│     └── 均匀性仪表 Tab（半圆仪表盘 + 警告列表）               │
│                                                               │
│  2. 更新 3D 预览面板（RepairVisualizer）                      │
│     ├── 基体表面                                              │
│     ├── 路径规划航点（路径动画）                              │
│     └── 喷嘴方向（法向量 quiver）                             │
│                                                               │
│  3. 自动生成 PDF 报告（_auto_generate_report）                │
│     └── 保存到桌面：repair_report_YYYYMMDD_HHMMSS.pdf         │
│                                                               │
│  4. 状态栏显示完成信息                                        │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 数据流关键节点

| 阶段 | 文件 | 函数 | 数据格式 |
|------|------|------|---------|
| 请求构造 | `main_window.py` | `_build_repair_request()` | Protobuf RepairRequest |
| MATLAB 启动 | `launcher.py` | `MatlabBridgeLauncher.start()` | subprocess + MATLAB -batch |
| Bridge 服务 | `matlab_bridge_server.m` | `adapter.serve()` | ZMQ REP 阻塞 |
| 计算执行 | `matlab_pipeline.py` | `MATLABPipeline.run()` | matlab.double → ndarray |
| 结果序列化 | `matlab_adapter.py` | `handle_repair()` | Protobuf RepairResult |
| ZMQ 传输 | `workers.py` | `ComputePipelineWorker.run()` | Protobuf bytes |
| 结果解析 | `repair_serialization.py` | `parse_repair_result()` | Python dict |
| GUI 更新 | `main_window.py` | `_on_compute_result()` | dict → matplotlib 图形 |
| 报告生成 | `main_window.py` | `_auto_generate_report()` | PDF 文件 |

## 五、禁止项实现验证

### 5.1 不得打开 MATLAB

**实现**：`MatlabBridgeLauncher` 使用 `matlab.exe -batch` 模式启动，无 MATLAB GUI 窗口。

```python
cmd = [matlab_exe, "-batch", f"cd('{project_root}'); matlab_bridge_server"]
subprocess.Popen(cmd, ...)
```

**验证**：
- 用户点击"开始计算"后，MATLAB 在后台静默运行
- 不显示 MATLAB 主窗口、不显示命令窗口
- 用户无需任何 MATLAB 操作

### 5.2 不得运行 main.m

**实现**：项目中不存在 `main.m` 文件。

**验证**：
- Glob 搜索 `**/*.m` 返回 19 个 `.m` 文件，无 `main.m`
- `matlab_bridge_server.m` 自动调用 `run_path_planning.m` + `run_profile_prediction.m`
- 这两个入口的注释明确标注："不运行离线 main.m"

### 5.3 不得复制 pointlist

**实现**：数据通过内存传递，中间文件存系统临时目录。

**验证**：
- `MATLABPipeline` 一次调用完成路径规划 + 形貌预测
- `call_full_pipeline()` 将路径规划结果直接作为参数传给形貌预测
- `get_pointlist_file()` 返回 `tempfile.mkdtemp()` 目录下的 `.npz` 文件
- `atexit.register(_cleanup_cache_dir)` 注册退出自动清理
- 用户无需手动复制任何文件

### 5.4 不得复制 velocitylist

**实现**：同上，速度数据通过内存传递。

**验证**：
- `_feed_rates_to_velocitylist()` 将数值速度转为 MATLAB string 数组
- 速度数据直接传递给 `run_profile_prediction()`，无文件 I/O
- `get_velocitylist_file()` 同样指向临时目录，退出自动清理

## 九、使用指南

### 9.1 用户操作步骤

1. 双击 `启动软件.bat` 打开软件
2. 点击"导入 STL"加载点云
3. 在中心视图选取缺陷区域（修复模式）或切换到增材模式
4. 调整参数（可选，默认值适用于大多数场景）
5. 点击"🚀 开始计算"
6. 等待后台自动完成（状态栏显示进度）
7. 查看结果：
   - 3D 预览面板：路径动画
   - MATLAB 形貌分析面板：mesh / 逐层轮廓 / 粒子分布 / 均匀性仪表
8. PDF 报告已自动保存到桌面

### 9.2 首次使用配置（可选）

若 MATLAB 未在默认安装路径，设置环境变量：

```
set CSAM_MATLAB_EXE=D:\your\path\to\matlab.exe
```

或在系统 PATH 中添加 MATLAB 的 `bin` 目录。

### 9.3 故障排查

| 问题 | 解决方案 |
|------|---------|
| "MATLAB + Bridge 启动失败" | 检查 MATLAB 是否安装，设置 `CSAM_MATLAB_EXE` 环境变量 |
| 启动超时（120s） | MATLAB 首次启动较慢，可增大超时或提前手动启动 `matlab_bridge_server` |
| 端口 5555 被占用 | 确保无其他程序占用，或重启软件 |
| 计算失败 | 查看日志，确认 MATLAB 许可证有效、算法文件完整 |

后台自动完成：**启动 MATLAB → 启动 Bridge → 加载算法 → 路径规划 → 形貌预测 → 更新 GUI → 生成报告**

整个流程对用户完全透明，无需任何手动 MATLAB 操作。
