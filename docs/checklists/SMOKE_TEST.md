# 冒烟测试检查清单

部署或构建后快速验证关键功能是否正常工作。

## 应用程序启动

- [ ] 应用程序在 30 秒内启动
- [ ] 主窗口显示标题 "冷喷涂缺陷修复软件 v1.0.0"
- [ ] 启动时无错误对话框
- [ ] 左侧面板显示 "01 路径规划" 和 "02 形貌预测" 步骤
- [ ] 右侧面板显示 3D 视图
- [ ] 无控制台错误或回溯（在启用控制台的 Windows 上）

## 点云加载

- [ ] 点击 "加载点云" 按钮 — 文件对话框打开
- [ ] 取消文件对话框 — 出现加载演示数据的提示
- [ ] 点击 "Yes" 加载演示数据 — 合成点云在 3D 视图中渲染
- [ ] 点云以颜色编码的高度显示
- [ ] 无渲染故障或缺失几何体

## 缺陷选择

- [ ] 加载点云后，选择模式处于活动状态
- [ "选取模式" 切换在导航和选择之间切换
- [ ] 矩形选择：拖拽创建红色高亮区域
- [ ] 画笔选择：点击点将其添加到选择中
- [ ] "撤销" 按钮撤销上次选择操作
- [ ] "清除选区" 按钮清除所有选择
- [ ] "反选" 按钮反转选择

## 路径规划

- [ ] 从下拉菜单中选择材料（例如 "316L 不锈钢"）
- [ ] 调整层高参数 — 值更新
- [ ] 悬停在参数上 — 出现带描述的工具提示
- [ ] 点击 "生成修复路径" — 路径规划运行
- [ ] 计算期间显示进度指示器
- [ ] 路径在 3D 视图中以彩色路径点渲染
- [ ] 路径规划无错误完成

## G-Code 导出

- [ ] 路径规划后，"导出 G-code" 按钮已启用
- [ ] 点击 "导出 G-code" — 文件保存对话框打开
- [ ] 保存文件 — 出现成功消息
- [ ] 打开保存的 `.nc` 文件 — 包含 G-code 命令
- [ ] G-code 包含 G0/G1 移动、M 代码和进给速度

## 形貌预测

- [ ] 点击 "02 形貌预测" — 页面切换到预测面板
- [ ] 冷喷涂参数可见（颗粒速度、喷嘴直径等）
- [ ] 临界速度从材料数据库自动填充（只读）
- [ ] 点击 "可行性检查" — 显示可行性结果
- [ ] 点击 "执行形貌预测" — 预测运行
- [ ] 预测完成且结果在 3D 视图中渲染
- [ ] 层动画控件功能正常

## PDF 报告导出

- [ ] 预测后，"导出 PDF 报告" 按钮已启用
- [ ] 点击 "导出 PDF 报告" — 文件保存对话框打开
- [ ] 保存文件 — 出现成功消息
- [ ] 打开保存的 `.pdf` 文件 — 报告有效且可读
- [ ] 报告包含扫描信息、参数和对比图像

## 3D 可视化

- [ ] 视图按钮（等轴测、俯视、侧视、正视）改变相机角度
- [ ] 层复选框切换表面、缺陷、路径、喷嘴、颜色图的可见性
- [ ] "逐层动画" 按钮播放逐层动画
- [ ] 层滑块可浏览沉积层
- [ ] 鼠标旋转/缩放在导航模式下正常工作

## MATLAB 集成（如可用）

- [ ] MATLAB 引擎在配置的 ZMQ 地址上运行
- [ ] 形貌预测通过 ZMQ 向 MATLAB 发送请求
- [ ] MATLAB 响应被正确接收和解析
- [ ] 无超时错误（ZMQ 轮询以 200ms 间隔工作）
- [ ] 如 MATLAB 未运行，应用程序优雅回退（如 LocalEngine 可用）

## 应用程序关闭

- [ ] 关闭应用程序窗口 — 关闭过程干净
- [ ] 无挂起线程（工作线程在 1 秒内停止）
- [ ] 关闭时无错误对话框
- [ ] ZMQ 套接字正确关闭
- [ ] 日志文件已刷新并关闭

## 错误处理

- [ ] 加载无效点云文件 — 出现错误消息（无崩溃）
- [ ] 输入超出范围的参数 — 出现验证错误消息
- [ ] 导出到只读目录 — 出现错误消息（无崩溃）
- [ ] 取消文件对话框 — 应用程序返回正常状态
