# 验收检查清单

生产发布签字的用户验收标准。

## 功能需求

### 点云处理
- [ ] 用户可加载 CSV、TXT、XYZ 和 ASC 格式的点云文件
- [ ] 用户可加载带法向量的 6 列文件（x、y、z、nx、ny、nz）
- [ ] 用户可加载不带法向量的 3 列文件（自动估计）
- [ ] 用户可加载内置演示数据而无需外部文件
- [ ] 加载的点云在 3D 视图中以正确的几何体渲染

### 缺陷选择
- [ ] 用户可使用矩形选择选择缺陷区域
- [ ] 用户可使用自由手绘选择选择缺陷区域
- [ ] 用户可使用画笔添加模式选择缺陷区域
- [ ] 用户可使用画笔移除模式取消选择区域
- [ ] 用户可撤销上次选择操作
- [ ] 用户可清除所有选择
- [ ] 用户可反转当前选择
- [ ] 选定区域以红色视觉高亮显示

### 路径规划
- [ ] 用户可从 6 种材料类型中选择（316L、Inconel 718、Ti-6Al-4V、Al 6061、铜、未指定）
- [ ] 用户可配置 9 个路径规划参数（层高、扫描角度、步长等）
- [ ] 每个参数都有解释其用途的工具提示
- [ ] 参数根据定义的边界进行验证（PARAM_SPECS）
- [ ] 用户可生成修复路径并在 3D 中查看
- [ ] 路径规划在合理时间内完成（典型输入 < 30 秒）

### 形貌预测
- [ ] 用户可配置 10 个冷喷涂参数（速度、喷嘴直径等）
- [ ] 临界速度从材料数据库自动计算（只读）
- [ ] 用户可在预测前运行可行性检查
- [ ] 用户可运行形貌预测并查看结果
- [ ] 提供逐层动画以审查沉积
- [ ] 预测在合理时间内完成（典型输入 < 60 秒）

### 导出
- [ ] 用户可在路径规划后将修复路径导出为 G-code（.nc）
- [ ] G-code 包含安全 Z 轴移动、送粉 M 代码和进给速度映射
- [ ] 用户可在形貌预测后导出 PDF 报告
- [ ] PDF 报告包含扫描信息、工艺参数、结果摘要和视觉对比
- [ ] 导出的文件有效且可在外部工具中打开

## 非功能需求

### 性能
- [ ] 应用程序在目标硬件上 30 秒内启动
- [ ] 点云加载（10,000 个点）在 5 秒内完成
- [ ] 路径规划（典型输入）在 30 秒内完成
- [ ] 形貌预测（典型输入）在 60 秒内完成
- [ ] 3D 渲染在交互期间保持 > 20 FPS
- [ ] 典型工作负载下内存使用量保持在 2 GB 以下

### 可用性
- [ ] 新用户可在 15 分钟内完成完整工作流程（加载 → 选择 → 规划 → 预测 → 导出）
- [ ] UI 标签和工具提示清晰易懂
- [ ] 错误消息具有描述性且可操作
- [ ] 参数工具提示说明用途和单位
- [ ] 步骤导航（路径规划 → 形貌预测）直观
- [ ] 视图控件（等轴测、俯视、侧视、正视）易于访问

### 可靠性
- [ ] 应用程序在正常操作期间不崩溃
- [ ] 应用程序优雅处理无效输入（错误消息，无崩溃）
- [ ] 应用程序优雅处理缺失文件
- [ ] 应用程序可从 MATLAB 连接失败中恢复（如适用）
- [ ] 线程关闭干净（无挂起进程）
- [ ] 重复操作期间无内存泄漏

### 跨平台
- [ ] 所有功能需求在 Windows 10 上通过
- [ ] 所有功能需求在 Windows 11 上通过
- [ ] 所有功能需求在 macOS 10.14+ 上通过
- [ ] UI 渲染在各平台间一致（可接受细微的字体差异）
- [ ] 导出的文件在各平台间相同（逐字节或逻辑等价）

### 安全性
- [ ] 许可证验证使用 RSA-2048 签名正常工作
- [ ] 机器绑定防止许可证转移到未经授权的机器
- [ ] HMAC 回退可用于开发/测试
- [ ] INFO 级别下不记录敏感数据
- [ ] 生产代码中无硬编码的密钥（仅使用环境变量）
