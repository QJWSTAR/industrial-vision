## 2. 运行测试

### 2.1 全部测试

```powershell
pytest repair_app/tests/ repair_app/bridge/tests/ -v
```

### 2.2 单元测试（按阶段）

```powershell
pytest repair_app/tests/test_stage1.py -v
```

各阶段测试：

```powershell
pytest repair_app/tests/test_stage1.py -v   # 阶段 1：点云加载与缺陷选择
pytest repair_app/tests/test_stage2.py -v   # 阶段 2：路径规划
pytest repair_app/tests/test_stage3.py -v   # 阶段 3：形貌预测
pytest repair_app/tests/test_stage4.py -v   # 阶段 4：导出
pytest repair_app/tests/test_stage5.py -v   # 阶段 5：集成
```

### 2.3 压力测试

```powershell
pytest repair_app/tests/test_stress.py -v
```

带性能基准：

```powershell
pytest repair_app/tests/test_stress.py -v --benchmark-only
```

### 2.4 端到端验证

```powershell
python scripts/release_validation.py
```

该脚本执行 27 项端到端检查，覆盖完整工作流。

### 2.5 覆盖率报告

```powershell
pytest --cov=repair_app --cov-report=term-missing
```

当前覆盖率 73%，CI 门控阈值 60%。

## 3. 测试分层

### 3.1 单元测试

聚焦单一模块/函数的正确性，使用 mock 隔离外部依赖。

| 测试域 | 涉及测试文件 | 说明 |
| --- | --- | --- |
| 算法 | `test_normal_estimator.py`、`test_layers.py`、`test_validation_metrics.py` | 法向量估计、逐层沉积、验证指标 |
| UI | `test_defect_selector.py` | 缺陷选择器交互 |
| 通信 | `test_stage5.py` | 阶段集成测试 |
| 服务 | `test_stage2.py`、`test_stage3.py`、`test_stage4.py` | 路径规划、形貌预测、导出服务 |
| 辅助 | `test_auto_updater.py`、`test_crash_handler.py`、`test_migration.py`、`test_fixes.py`、`test_extra_coverage.py` | 自动更新、崩溃处理、迁移、修复验证 |
| 阶段 | `test_stage1.py` ~ `test_stage5.py` | 按 5 个开发阶段组织的测试 |

### 3.2 集成测试

验证模块间协作，特别是 Bridge 通信层。

| 测试 | 文件 | 说明 |
| --- | --- | --- |
| Bridge 通信 | `repair_app/bridge/tests/test_bridge.py` | Python ↔ MATLAB Bridge 的 ZeroMQ 通信、Protobuf 序列化、请求/响应往返 |

### 3.3 端到端验证

模拟真实用户工作流，从点云加载到导出的完整链路。

| 验证脚本 | 检查项数 | 说明 |
| --- | --- | --- |
| `scripts/release_validation.py` | 27 项 | 完整工作流验证，含 STL 导入、路径规划、形貌预测、导出、MATLAB 集成 |
