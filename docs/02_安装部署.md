# 安装部署

> **版本**：1.0.0（Release Candidate） ｜ **协议**：v2.1（ZeroMQ + Protocol Buffers） ｜ **更新日期**：2026-07-14

本文档面向发布工程师与运维人员，系统说明 CSAM Repair 在 Windows、macOS、Linux 三平台上的安装、MATLAB 算法引擎的接入、环境变量配置、日志管理以及升级与卸载流程。

---

## 系统要求

### 硬件要求

| 条件 | 最低要求 | 建议 |
|------|---------|------|
| 内存 | 8 GB | 16 GB 或更多 |
| 硬盘空间 | 5 GB（不含 MATLAB） | 20 GB（含 MATLAB） |
| 显示器分辨率 | 1366×768 | 1920×1080 或更高 |

### 软件要求

| 条件 | 要求 |
|------|------|
| 操作系统 | Windows 10 64 位及以上 / macOS 10.14+ / Linux（Ubuntu 22.04+ 或 CentOS 8+） |
| Python（Python 解释器） | 3.10–3.12（推荐 3.12） |
| MATLAB（选装） | R2025b（推荐）或 R2024b+ |

### 运行时依赖

软件依赖以下核心库，安装时会自动获取：

PySide6、numpy、scipy、matplotlib、shapely、pyzmq、protobuf、reportlab、cryptography

> 测试套件包含 276 个单元测试与 27 项端到端验证。

## Windows 安装

### 方式一：从源码运行

适合开发者和需要自定义配置的用户。

#### 1. 安装 Python

1. 前往 [python.org](https://www.python.org/downloads/) 下载 Python 3.12
2. 运行安装程序，**务必勾选** "Add Python to PATH"
3. 点击"Install Now"完成安装
4. 验证：打开 PowerShell，执行 `python --version`，应显示 `Python 3.12.x`

#### 2. 获取项目代码

```powershell
git clone <repository-url>
cd <project-directory>
```

> 如从公司内部服务器获取，直接复制整个项目文件夹即可。

#### 3. 创建并激活虚拟环境

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

> **报错"无法加载文件"**：执行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，按 Y 确认后重试。

#### 4. 安装依赖

```powershell
pip install --upgrade pip
pip install -r requirements.txt
```

#### 5. 运行软件

```powershell
python run_app.py
```

或安装为系统命令后直接执行：

```powershell
pip install -e .
csam-repair
```

#### 验证安装

```powershell
python -c "from repair_app import __version__; print(f'版本: {__version__}')"
```

显示 `版本: 1.0.0` 即表示安装成功。

### 方式二：从安装包运行

如果公司提供了打包好的可执行程序（`CSAM_Repair.exe`），无需安装 Python 环境：

1. 双击运行 `CSAM_Repair.exe`
2. 首次启动较慢（单文件模式需解压临时文件，约 5-10 秒），属正常现象
3. 等待软件窗口出现即可使用

> 目标机无需 Python 环境，直接分发 `CSAM_Repair.exe` 即可。

### 方式三：构建安装包

适合发布工程师，使用 PyInstaller 打包成单文件可执行程序。

#### 前置条件

- Windows 10/11
- Python 3.10–3.12（推荐 3.12）
- 项目依赖已安装（`pip install -r requirements.txt`）
- PyInstaller 已安装（`pip install pyinstaller`）

#### 一键打包

```powershell
cd d:\work\demo\industrial-vision
.\build_windows.bat
```

输出：`dist\CSAM_Repair.exe`（单文件，约 80-120 MB）

#### 手动打包

```powershell
python -m PyInstaller --clean repair_app.spec
```

#### spec 文件说明（`repair_app.spec`）

| 配置项 | 说明 |
|--------|------|
| 单文件模式 | 所有依赖打包进单个 exe |
| hiddenimports | 显式声明所有运行时导入的模块（含 bridge/engine） |
| datas | 材料数据库（`material_db.json`）、标定配置（`calibration_db.json`）、proto 文件 |
| excludes | 排除未使用的 PySide6 模块（QtQml/QtQuick 等）以减小体积 |
| UPX 压缩 | 启用，排除 Qt DLL（压缩会导致加载失败） |
| 图标 | 自动检测项目根目录的 `p1.ico` / `p1.png` / `p1.jpg` |
| 控制台 | Windows 保留控制台便于调试 |

#### 打包验证清单

- [ ] exe 可在干净 Windows 虚拟机启动
- [ ] 主界面正常显示
- [ ] 假数据加载正常
- [ ] 缺陷选择、可行性判断正常
- [ ] G-code 导出正常
- [ ] PDF 报告生成正常
- [ ] ZMQ 联调正常（需 MATLAB 环境）

### 方式一：从源码运行

```bash
git clone <repository-url>
cd <project-directory>

python3 -m venv venv
source venv/bin/activate

pip install --upgrade pip

```

### 方式二：构建应用包

#### 前置条件

- macOS 10.14+
- Python 3.10–3.12
- 项目依赖已安装

#### 一键打包

```bash
chmod +x build_macos.sh
./build_macos.sh
```

输出：`dist/CSAM_Repair.app`（应用程序包）

#### 代码签名（分发前必须）

```bash
codesign --deep --force --verify --verbose=4 \
  --sign "Developer ID Application: <Your Name>" \
  dist/CSAM_Repair.app
```

#### 公证（Gatekeeper）

```bash
xcrun notarytool submit dist/CSAM_Repair.app.zip \
  --apple-id "<apple-id>" --team-id "<team-id>" --password "<app-password>" --wait
xcrun stapler staple dist/CSAM_Repair.app
```

> 分发前必须完成代码签名与公证，否则 macOS 用户无法运行。

```bash
# Ubuntu / Debian
sudo apt update
sudo apt install -y libgl1 libxkbcommon0 libdbus-1-3 libfontconfig1 libfreetype6

# CentOS / RHEL
sudo yum install -y mesa-libGL libxkbcommon dbus-libs fontconfig freetype
```

- 不提供 PyInstaller 打包的 .deb/.rpm 安装包

## MATLAB 安装

> MATLAB 为选装项。仅在需要使用"远程服务（MATLAB）"作为算法引擎时安装。使用本地计算引擎则无需安装。

### 安装 MATLAB R2025b

1. 运行 MATLAB 安装程序
2. 登录 MathWorks 账号或输入许可证密钥
3. 选择要安装的产品：
   - **MATLAB**（必选）
   - **Mapping Toolbox**（推荐，路径规划算法需要）
   - **Curve Fitting Toolbox**（推荐，粒子拟合算法需要）
4. 选择安装路径，等待安装完成（可能需要 30 分钟以上）

### 验证 MATLAB 安装

在 MATLAB 命令窗口输入：

```matlab
version
```

显示 `25.2.0.xxxxxxx` 即表示 MATLAB R2025b 安装成功。

检查工具箱许可证：

```matlab
license('test', 'Map_Toolbox')              % 返回 1 表示可用
license('test', 'Curve_Fitting_Toolbox')   % 返回 1 表示可用
```

### 配置 MATLAB Engine API for Python

首次连接需要在 MATLAB 中配置 Python 环境（pyenv），指向项目的虚拟环境解释器：

```matlab
pyenv('Version', 'D:\work\demo\industrial-vision\venv\Scripts\python.exe');
```

> 请将路径替换为你的实际虚拟环境路径。macOS/Linux 路径格式类似，如 `/Users/username/project/venv/bin/python`。

验证配置：

```matlab
pe = pyenv;
disp(pe.Version);
```

显示 Python 版本和路径即表示配置成功。

### 启动 MATLAB Bridge 服务

1. 将 MATLAB 工作目录切换到项目根目录：

```matlab
cd('D:\work\demo\industrial-vision')
```

2. 运行启动命令：

```matlab
matlab_bridge_server
```

3. MATLAB 会共享引擎会话并启动 Bridge 服务（默认端口 5555）。光标不返回属正常现象，说明服务已启动。

> **不要关闭 MATLAB 窗口。** 服务运行期间 MATLAB 必须保持打开。

### 验证连接

打开一个新的终端窗口，执行：

```bash
cd D:\work\demo\industrial-vision
.\venv\Scripts\python.exe -c "import zmq; ctx=zmq.Context(); s=ctx.socket(zmq.REQ); s.connect('tcp://127.0.0.1:5555'); print('连接成功'); s.close()"
```

显示 `连接成功` 即表示配置完成。

> 启动 Python GUI 后，执行路径规划时软件会自动连接 MATLAB。如果 MATLAB 不可用，软件会自动降级到 Python 启发式算法，功能不受影响。

## 环境变量配置

软件通过环境变量进行运行时配置。将 `.env.example` 复制为 `.env` 进行生产部署配置，或直接在系统环境变量中设置。

以下列出代码实际读取的全部 16 个 `CSAM_` 环境变量：

### 通用配置

| 环境变量 | 默认值 | 作用 |
|----------|--------|------|
| `CSAM_ALGORITHM_ENGINE` | `auto` | 算法引擎选择。`auto` 优先 MATLAB 不可用降级 Python；`matlab` 强制使用 MATLAB；`python` 强制使用原型算法 |
| `CSAM_ZMQ_ADDRESS` | 平台相关（见下） | ZeroMQ（ZMQ）连接地址。Windows 默认 `tcp://127.0.0.1:5555`，macOS/Linux 默认 `ipc:///tmp/csam_engine` |
| `CSAM_LOG_LEVEL` | `INFO` | Python 应用日志级别（`DEBUG`/`INFO`/`WARNING`/`ERROR`），同时控制 MatlabAdapter 日志 |
| `CSAM_HMAC_SECRET` | 开发内置密钥 | HMAC 密钥，用于许可证验证。生产环境必须设置 |

### Bridge 通信层配置

| 环境变量 | 默认值 | 作用 |
|----------|--------|------|
| `CSAM_BRIDGE_TIMEOUT_MS` | `30000` | 请求超时（毫秒）。复杂算法（如路径规划、形貌预测）耗时较长，可调大至 120000 |
| `CSAM_BRIDGE_CONNECT_MS` | `5000` | 连接超时（毫秒） |
| `CSAM_BRIDGE_HEALTH_MS` | `3000` | 健康检查超时（毫秒） |
| `CSAM_BRIDGE_HEARTBEAT_MS` | `5000` | 心跳间隔（毫秒） |
| `CSAM_BRIDGE_HEARTBEAT_MISS` | `3` | 心跳丢失阈值，超过此次数触发重连 |
| `CSAM_BRIDGE_MAX_RETRIES` | `3` | 请求最大重试次数 |
| `CSAM_BRIDGE_RETRY_MS` | `2000` | 重试间隔（毫秒） |
| `CSAM_BRIDGE_LATENCY_LOG_MS` | `1000` | 延迟日志阈值（毫秒），超过此延迟的请求会记录日志 |

### MATLAB 引擎配置

| 环境变量 | 默认值 | 作用 |
|----------|--------|------|
| `CSAM_MATLAB_SHARED_NAME` | `matlab_bridge` | MATLAB 共享会话名称，需与 `matlab_bridge_server.m` 共享的名称一致 |
| `CSAM_MATLAB_ALLOW_STANDALONE` | `0` | 是否允许独立启动 MATLAB 引擎。`1` 允许（启动慢，约 30-60 秒），`0` 不允许 |

### 更新检查配置

| 环境变量 | 默认值 | 作用 |
|----------|--------|------|
| `CSAM_UPDATE_URL` | 空 | 更新检查的 URL。为空时跳过更新检查。生产环境应指向内部更新服务器 |
| `CSAM_UPDATE_TIMEOUT` | `10` | 更新检查的超时时间（秒） |

### 配置示例

**Windows（PowerShell）：**

```powershell
$env:CSAM_LOG_LEVEL = "DEBUG"
$env:CSAM_ALGORITHM_ENGINE = "matlab"
$env:CSAM_BRIDGE_TIMEOUT_MS = "120000"
```

**macOS / Linux：**

```bash
export CSAM_LOG_LEVEL=DEBUG
export CSAM_ALGORITHM_ENGINE=matlab
export CSAM_BRIDGE_TIMEOUT_MS=120000
```

> 完整环境变量模板参见项目根 `.env.example`。

## 日志

系统日志统一由 Python 应用日志管理，支持级别控制与文件滚动。

### 日志位置

日志文件统一输出到项目根目录的 `logs/` 目录：

| 日志文件 | 级别 | 滚动策略 | 保留期 |
|----------|------|----------|--------|
| `logs/app_{date}.log` | 全部级别（DEBUG 及以上） | 单文件 10 MB 滚动 | 30 天 |
| `logs/error_{date}.log` | ERROR 及以上 | 按日期滚动 | 60 天 |
| `logs/structured_{date}.jsonl` | 全部级别（JSONL 结构化，可选） | 按日期滚动 | 30 天 |
| 控制台 | 全部级别 | — | 彩色输出 |

### 日志级别

`DEBUG` / `INFO` / `WARNING` / `ERROR`

- 生产环境默认 `INFO`
- 排查问题时切换为 `DEBUG`（注意 DEBUG 日志量大，会影响性能与磁盘占用）

### 级别配置

**Windows（PowerShell）：**

```powershell
$env:CSAM_LOG_LEVEL = "DEBUG"
```

**macOS / Linux：**

```bash
export CSAM_LOG_LEVEL=DEBUG
```

### MatlabAdapter 日志

MatlabAdapter 运行于 MATLAB 宿主进程内（通过 `pyenv` 调用 Python），其日志通过 Python logger 输出，日志名为 `csam.bridge.matlab`，与 Python 应用日志统一管理，输出到 `logs/` 目录。级别通过 `CSAM_LOG_LEVEL` 统一控制。

### 日志分析技巧

1. **按 `request_id` 关联请求全链路**：每个请求分配唯一 `request_id`，在 Python 与 MATLAB 日志中均可检索，用于追踪完整调用链
2. **`error` 级别优先排查**：`error_{date}.log` 仅记录 ERROR 及以上，是定位故障的起点
3. **结构化日志便于聚合**：`structured_{date}.jsonl` 可导入 ELK / Loki 等日志平台进行聚合分析
4. **MATLAB 日志与 Python 日志交叉比对**：同一 `request_id` 在两侧均有记录，可定位通信层与算法层的边界问题

### 关键事件

以下为系统中需要重点关注的日志事件：

| 事件 | 来源 | 含义 |
|------|------|------|
| `adapter.start` | MatlabAdapter | MatlabAdapter 启动成功 |
| `request.start` | Bridge / MatlabAdapter | 请求处理开始（携带 request_id） |
| `request.crash` | MatlabAdapter | 请求处理过程中发生崩溃 |
| `adapter.stop` | MatlabAdapter | MatlabAdapter 停止 |
| `heartbeat.miss` | Bridge | 心跳丢失 |
| `engine.lost` | Bridge | MATLAB 引擎连接丢失 |
| `fallback.invoke` | MatlabAdapter | MATLAB 不可用，降级到 Python 原型 |

## 升级与卸载

### 升级

#### 升级前准备

1. 备份配置和数据（`.env`、`config/calibration_db.json`、`repair_app/core/material_db.json`、`morphology_prediction/`、`logs/`）
2. 记录当前版本号（`repair_app/__init__.py` 中 `__version__`）
3. 暂存或提交本地改动：

```bash
git stash        # 暂存未提交改动
# 或
git commit -am "WIP: 升级前提交"
```

#### 升级步骤

1. 拉取最新代码：

```bash
git pull origin main
```

2. 更新 Python 依赖：

```bash
pip install -r requirements.txt
```

3. 更新 MATLAB 算法文件（如算法目录有变更）
4. 重启 MATLAB 算法服务：在 MATLAB 中运行 `matlab_bridge_server`
5. 重启 GUI：

```bash
python run_app.py
```

#### 升级后验证

1. 运行测试套件：

```bash
pytest --cov=repair_app
```

覆盖率应 ≥ 60%（CI 门控阈值）。

2. 启动 GUI 验证 MATLAB 算法服务连接正常
3. 执行一次完整工作流：加载模型 → 选区 → 路径生成 → 形貌预测 → 导出

#### 回滚

```bash
git checkout <旧版本标签或commit>
pip install -r requirements.txt
# 重启 MATLAB 算法服务（matlab_bridge_server）与 GUI
```

#### MATLAB 升级注意事项

- **R2025b 非 ASCII 字符限制**：R2025b 拒绝 `.m` 文件中的非 ASCII 字符，升级 MATLAB 版本前需确认所有算法文件注释为纯 ASCII
- **工具箱许可证变更**：升级后检查工具箱许可证是否仍有效（`license('test', 'Map_Toolbox')` 等）

### 卸载

#### 从源码安装的卸载

1. 关闭软件和 MATLAB 服务
2. 删除项目文件夹：

```powershell
Remove-Item -Recurse -Force D:\work\demo\industrial-vision
```

3. 如安装为系统命令，执行：

```powershell
pip uninstall csam-repair
```

#### 从安装包安装的卸载

1. 关闭软件
2. 删除 `CSAM_Repair.exe` 文件
3. 删除用户配置目录（如有）

#### 卸载 MATLAB（如需要）

通过 MATLAB 安装程序卸载，参考 MathWorks 官方文档。

## Inno Setup 安装程序（Windows）

Windows 平台可使用 [Inno Setup](https://jrsoftware.org/isinfo.php) 将 `CSAM_Repair.exe` 封装为用户友好的安装程序（含开始菜单快捷方式、卸载入口、关联文件类型等）。

### 基本流程

1. 先通过 `build_windows.bat` 生成 `dist\CSAM_Repair.exe`
2. 编写 Inno Setup 脚本（`.iss` 文件），指定：
   - 源文件：`dist\CSAM_Repair.exe`
   - 安装目录：`{pf}\CSAM Repair`
   - 开始菜单快捷方式
   - 卸载入口
3. 使用 Inno Setup Compiler 编译 `.iss` 文件，生成 `CSAM_Repair_Setup.exe`
4. 用户双击安装程序，按提示完成安装

> Inno Setup 脚本模板示例可参阅 `docs/07_开发指南.md`。也可使用 [NSIS](https://nsis.sourceforge.io/) 作为替代方案。

### 分发

- **Windows**：直接分发 `CSAM_Repair.exe` 或安装程序 `CSAM_Repair_Setup.exe`，目标机无需 Python 环境
- **macOS**：分发 `CSAM_Repair.app`（需签名 + 公证）
- **Linux**：仅支持从源码运行
