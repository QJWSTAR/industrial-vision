# 1. 软件简介

## 这个软件是做什么的？

这是一款**冷喷涂缺陷修复软件**。

简单说：工厂生产金属零件时，零件表面可能会有坑洞、划痕、凹槽等缺陷。这个软件帮你：

1. **看清缺陷长什么样** — 把零件扫描成 3D 点云数据，在屏幕上看清楚
2. **算出怎么修** — 自动计算喷涂路径，告诉你喷枪应该怎么走
3. **预测修完的效果** — 模拟喷涂过程，预测修完后是什么样
4. **生成加工文件** — 导出数控机床能用的 G-code 文件和 PDF 报告

---

## 它能解决什么问题？

### 以前的做法（手工经验）

- 老师傅凭经验判断怎么修
- 手动编写喷涂路径，容易出错
- 修完才知道效果好不好，返工成本高
- 没有标准化的报告

### 现在的做法（用这个软件）

- 软件自动分析缺陷形状
- 软件自动生成最优喷涂路径
- 先在电脑上模拟预测效果，满意了再实际操作
- 自动生成 G-code 和 PDF 报告，可追溯

---

## 谁应该使用这个软件？

| 角色 | 怎么用 |
|------|--------|
| **操作工** | 日常使用：加载点云 → 选缺陷 → 生成路径 → 导出 G-code |
| **技术员** | 调整工艺参数，做可行性检查，导出报告 |
| **工程师** | 分析修复方案，评估不同材料的效果 |
| **质检员** | 查看 PDF 报告，核对修复参数和结果 |

> **你不需要懂编程。** 这个软件有图形界面，用鼠标点按钮就行。

---

## 软件能做什么？不能做什么？

### 能做的

- 加载 3D 点云数据（CSV、TXT、XYZ、ASC 格式）
- 在 3D 视图中查看零件表面
- 用鼠标框选缺陷区域
- 自动生成喷涂路径
- 模拟冷喷涂沉积过程
- 预测修复后的形貌
- 检查修复方案是否可行
- 导出 G-code 数控加工文件
- 导出 PDF 修复报告

### 不能做的

- 不能直接控制喷涂设备（需要把 G-code 导入到数控系统）
- 不能扫描零件（需要用其他三维扫描设备获取点云数据）
- 不能修改点云数据（只读，不能编辑点的坐标）

## 工作流程一览

软件把修复工作分成 **4 个步骤**，按顺序进行：

```
第 1 步：数据与路径
  加载点云 → 框选缺陷 → 生成路径
        ↓
第 2 步：形貌预测
  可行性检查 → 执行形貌预测
        ↓
第 3 步：结果校核
  查看指标 → 查看截面 → 查看风险
        ↓
第 4 步：输出交付
  导出 G-code → 导出 PDF 报告
```

> 你会在左侧栏看到这 4 个步骤。完成一步后，下一步才会解锁。

## 需要什么条件才能使用？

### 必须有的

- 一台 Windows 电脑（Windows 10 或 11，64 位）
- 软件已经安装好（见 [安装指南](02_安装指南.md)）

### 可选的

- **MATLAB 软件**：如果你需要用远程计算引擎（更精确的算法），需要在电脑上安装 MATLAB R2025b。如果只用本地计算，不需要 MATLAB。
- **三维扫描设备**：用于获取真实零件的点云数据。如果没有，软件内置了演示数据可以练习。
