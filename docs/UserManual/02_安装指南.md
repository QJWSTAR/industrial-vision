# 2. 安装指南

> 本指南从一台**全新的 Windows 电脑**开始，带你一步步装好软件。
> 你不需要任何编程知识。跟着做就行。

---

## 安装前请检查

### 你的电脑满足这些条件吗？

| 条件 | 最低要求 | 建议 |
|------|---------|------|
| 操作系统 | Windows 10 64 位 | Windows 11 64 位 |
| 内存 | 8 GB | 16 GB 或更多 |
| 硬盘空间 | 5 GB（不含 MATLAB） | 20 GB（含 MATLAB） |
| 显示器分辨率 | 1366×768 | 1920×1080 或更高 |

### 需要安装的软件清单

按以下顺序安装：

1. **Python**（必装）— 软件运行的基础环境
2. **CSAM Repair 软件**（必装）— 本软件本体
3. **MATLAB R2025b**（选装）— 仅在使用远程计算引擎时需要

> 如果你只是试用或使用本地计算，可以跳过 MATLAB 安装。

---

## 第 1 步：安装 Python

### 1.1 下载 Python

1. 打开浏览器，访问：https://www.python.org/downloads/
2. 点击页面上黄色的 **"Download Python 3.12.x"** 按钮（选最新的 3.12 版本）
3. 等待下载完成

### 1.2 安装 Python

1. 双击下载的安装文件（如 `python-3.12.x-amd64.exe`）
2. **重要！** 在安装界面底部，勾选 **"Add Python to PATH"**（将 Python 添加到 PATH）

   【截图：Python 安装界面，红圈标注 "Add Python to PATH"】

3. 点击 **"Install Now"**
4. 等待安装完成，点击 **"Close"**

### 1.3 验证 Python 安装

1. 按 `Win + R` 键，输入 `powershell`，按回车打开 PowerShell
2. 输入以下命令并按回车：
   ```
   python --version
   ```
3. 如果显示 `Python 3.12.x`，说明安装成功

> **如果显示"不是内部或外部命令"**：你忘了勾选 "Add Python to PATH"。请重新安装，记得勾选。

---

## 第 2 步：获取软件

### 方式一：从公司内部服务器获取（推荐）

1. 从公司指定的软件分发位置复制整个项目文件夹
2. 将文件夹放在 `D:\work\demo\industrial-vision`（或你喜欢的位置）

### 方式二：从安装包安装

如果公司提供了安装程序（`.exe` 文件），双击运行，按提示选择安装路径即可。

> 以下步骤假设软件文件夹位于 `D:\work\demo\industrial-vision`。如果你的路径不同，请替换成你的实际路径。

---

## 第 3 步：安装软件依赖

软件需要一些额外的组件才能运行。按以下步骤安装：

### 3.1 打开 PowerShell

1. 按 `Win + R`，输入 `powershell`，按回车

### 3.2 进入软件目录

输入以下命令并按回车：
```
cd D:\work\demo\industrial-vision
```

### 3.3 创建虚拟环境

> "虚拟环境"你可以理解成软件专用的一个独立空间，不会影响电脑上其他程序。

输入以下命令并按回车：
```
python -m venv venv
```

等待几秒钟，完成后不会有任何提示（这是正常的）。

### 3.4 激活虚拟环境

输入以下命令并按回车：
```
.\venv\Scripts\Activate.ps1
```

如果命令行前面出现了 `(venv)`，说明激活成功。

> **如果报错"无法加载文件...因为在此系统上禁止运行脚本"**：
> 输入 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，按 Y 确认，然后重新执行激活命令。

### 3.5 安装依赖

输入以下命令并按回车：
```
pip install -r requirements.txt
```

这一步会下载和安装软件需要的所有组件，可能需要几分钟，请耐心等待。

看到最后出现 `Successfully installed ...` 就说明安装成功了。

### 3.6 验证安装

输入以下命令并按回车：
```
pip install -e ".[dev]"
```

然后输入：
```
python -c "from repair_app import __version__; print(f'版本: {__version__}')"
```

如果显示 `版本: 1.0.0`，说明软件安装成功！

## 第 4 步：（选装）安装 MATLAB R2025b

> **什么时候需要装 MATLAB？**
> - 如果你要使用"远程服务（MATLAB）"计算引擎 → 需要
> - 如果你只用"本地计算引擎" → 不需要

### 4.1 获取 MATLAB

MATLAB 是商业软件，需要从 MathWorks 公司购买许可证。请联系你们公司的 IT 部门获取安装包和许可证。

### 4.2 安装 MATLAB

1. 运行 MATLAB 安装程序
2. 登录 MathWorks 账号或输入许可证密钥
3. 选择要安装的产品：
   - **MATLAB**（必选）
   - **Mapping Toolbox**（推荐，路径规划算法需要）
   - **Curve Fitting Toolbox**（推荐，粒子拟合算法需要）
4. 选择安装路径（如 `D:\work\matlab`）
5. 等待安装完成（可能需要 30 分钟以上）

### 4.3 验证 MATLAB

1. 双击桌面上的 MATLAB 图标启动
2. 在 MATLAB 命令窗口（`>>` 提示符后）输入：
   ```
   version
   ```
3. 如果显示 `25.2.0.xxxxxxx`，说明 MATLAB R2025b 安装成功

> **详细的 MATLAB 验证步骤**，请参阅 [MATLAB 验证手册](../MATLAB_R2025B_Validation_Playbook.md)。

## 第 5 步：首次启动软件

### 5.1 启动软件

在 PowerShell 中（确保已激活虚拟环境），输入：
```
python run_app.py
```

或者，如果你已经将软件安装为系统命令：
```
csam-repair
```

### 5.2 你应该看到什么

1. 先出现一个黑色的命令行窗口，显示一些启动信息
2. 然后弹出软件的主窗口，标题为 **"冷喷涂缺陷修复工作流"**
3. 左侧栏显示工作流步骤和操作按钮
4. 中间是 3D 视图区域
5. 右侧栏显示信息面板

【截图：软件首次启动画面】

### 5.3 如果启动失败

| 问题 | 解决方法 |
|------|---------|
| 提示 "No module named 'PySide6'" | 在 PowerShell 中运行 `pip install PySide6` |
| 提示 "No module named 'zmq'" | 运行 `pip install pyzmq` |
| 窗口白屏 | 更新显卡驱动 |
| 提示权限不足 | 以管理员身份运行 PowerShell |

更多问题请查阅 [故障排查](08_故障排查.md)。

## 第 6 步：（如需远程计算）配置 MATLAB 连接

如果你要使用远程 MATLAB 计算引擎，需要额外配置：

### 6.1 在 MATLAB 中配置 Python 环境

1. 启动 MATLAB
2. 在 MATLAB 命令窗口输入：
   ```matlab
   pyenv('Version', 'D:\work\demo\industrial-vision\venv\Scripts\python.exe');
   ```
   > 把路径换成你的实际路径

3. 验证配置：
   ```matlab
   pe = pyenv;
   disp(pe.Version);
   ```
   如果显示 Python 版本和路径，说明配置成功。

### 6.2 启动 MATLAB 计算服务

在 MATLAB 命令窗口输入：
```matlab
cd('D:\work\demo\industrial-vision')
matlab_bridge_server
```

> 这条命令会让 MATLAB 进入等待状态（光标不返回）。这是正常的，说明服务已启动。
> **不要关闭 MATLAB 窗口。**

### 6.3 验证连接

打开一个新的 PowerShell 窗口，输入：
```
cd D:\work\demo\industrial-vision
.\venv\Scripts\python.exe -c "import zmq; ctx=zmq.Context(); s=ctx.socket(zmq.REQ); s.connect('tcp://127.0.0.1:5555'); print('连接成功'); s.close()"
```

如果显示 `连接成功`，说明配置完成。
