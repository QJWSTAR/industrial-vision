# 6. 案例教程

> 本章提供 5 个完整的实战案例，从简单到复杂。
> 每个案例都包含：目标、准备、操作步骤、预期结果、常见错误。

## 案例 1：修复一个圆形坑洞（入门）

### 目标
使用演示数据修复一个圆形坑洞缺陷，熟悉基本流程。

### 准备
- 软件已安装并启动
- 不需要任何外部文件

### 操作步骤

1. **启动软件**
   ```
   cd D:\work\demo\industrial-vision
   .\venv\Scripts\Activate.ps1
   python run_app.py
   ```

2. **加载演示数据**
   - 点击 "📂 加载点云"
   - 取消文件对话框
   - 点击"是"加载演示数据

3. **选取缺陷**
   - 切换到 "✂️ 选取模式"
   - 选择 "矩形框选"
   - 在零件中央凸台处，框选有凹陷的区域（圆形坑洞位置大约在凸台中央偏右）

4. **选择材料**
   - 材料下拉框选择 "316L 不锈钢"

5. **生成路径**
   - 参数保持默认
   - 点击 "🔧 生成修复路径"
   - 等待完成

6. **查看结果**
   - 3D 视图中应出现路径线条
   - 右侧显示航点数

### 预期结果
- 路径线条覆盖坑洞区域
- 航点数在 50-200 个之间
- 弹出"路径规划完成"提示

### 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| "请至少选取 3 个点" | 框选区域太小或没框到点 | 重新框选更大区域 |
| 路径线条没有出现 | 计算未完成或失败 | 等待或重新生成 |
| 路径只在一侧 | 缺陷区域没选全 | 清除选区重新选 |

## 案例 2：修复沟槽缺陷并导出 G-code

### 目标
修复一个矩形沟槽缺陷，并导出 G-code 数控加工文件。

### 准备
- 完成案例 1 或重新开始

### 操作步骤

1. **加载演示数据**（同案例 1）

2. **选取沟槽缺陷**
   - 演示数据中包含一个矩形沟槽（位于凸台左侧偏后）
   - 切换到选取模式
   - 用"矩形框选"框住沟槽区域

3. **选择材料**
   - 选择 "316L 不锈钢"

4. **调整参数**
   - 层高：1.5 mm（沟槽较深，用较薄层）
   - 扫描步长：1.5 mm
   - 规划层数：15（沟槽深，需要更多层）

5. **生成路径**
   - 点击 "🔧 生成修复路径"

6. **导出 G-code**
   - 点击 "📤 导出 G-code"
   - 保存到桌面，文件名 "groove_repair.nc"

7. **验证 G-code**
   - 用记事本打开 .nc 文件
   - 检查开头有 G21（毫米单位）、G90（绝对坐标）
   - 检查有 M7（送粉开）和 M9（送粉关）
   - 检查有 G1 指令（直线移动）

### 预期结果
- G-code 文件生成成功
- 文件开头有标准 G-code 头
- 包含多段 G1 移动指令
- 有 M7/M9 送粉控制

### 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| 导出时提示"安全检查未通过" | 航点坐标有异常值 | 重新生成路径 |
| G-code 文件为空 | 路径未生成 | 先生成路径再导出 |
| G-code 中有 NaN | 数据异常 | 检查点云数据质量 |

## 案例 3：使用不同材料修复并做可行性检查

### 目标
对比不同材料的修复效果，学会使用可行性检查功能。

### 准备
- 完成案例 1 的步骤 1-3

### 操作步骤

1. **选取缺陷**（同案例 1）

2. **第一次尝试：纯铜**
   - 材料选择 "纯铜"
   - 查看材料信息：v_cr: 340 m/s
   - 生成路径
   - 切换到形貌预测页
   - 粒子速度设为 300 m/s（低于临界速度 340）
   - 点击 "🔍 可行性检查"
   - **预期结果**：❌ 不可行，提示"粒子速度不足"

3. **修正参数**
   - 粒子速度改为 500 m/s（高于 340）
   - 重新点击 "🔍 可行性检查"
   - **预期结果**：✅ 可行

4. **第二次尝试：Ti-6Al-4V**
   - 回到路径规划页
   - 材料改为 "Ti-6Al-4V"
   - 查看材料信息：v_cr: 680 m/s
   - 生成路径
   - 切换到形貌预测页
   - 粒子速度保持 500 m/s
   - 点击 "🔍 可行性检查"
   - **预期结果**：❌ 不可行，500 < 680

5. **修正参数**
   - 粒子速度改为 800 m/s
   - 气体压力改为 50 bar
   - 重新检查
   - **预期结果**：✅ 可行或⚠️ 有条件可行

### 预期结果
- 理解临界速度的概念：粒子速度必须大于材料的临界速度
- 学会根据可行性检查结果调整参数

### 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| 可行性检查显示"未检测到有效缺陷区域" | 没选缺陷或选取点太少 | 重新选取缺陷 |
| 可行性检查不可点 | 没有完成路径规划 | 先生成路径 |

## 案例 4：执行形貌预测并导出 PDF 报告

### 目标
完成完整的形貌预测流程，生成 PDF 修复报告。

### 准备
- 完成案例 1 的全部步骤

### 操作步骤

1. **切换到形貌预测页**
   - 点击左侧 "02 形貌预测"

2. **确认输入数据**
   - 状态应显示 "✅ 航点数据就绪"

3. **设置参数**
   - 粒子速度：500 m/s
   - 喷嘴直径：6.0 mm
   - 喷涂角度：90°
   - 预测层数：5

4. **可行性检查**
   - 点击 "🔍 可行性检查"
   - 确认结果为 ✅ 可行或 ⚠️ 有条件可行

5. **执行形貌预测**
   - 点击 "🔮 执行形貌预测"
   - 等待计算完成（10-60 秒）

6. **查看结果**
   - 3D 视图显示沉积效果
   - 用"逐层动画"查看逐层沉积
   - 拖动层滑块查看单层

7. **导出 PDF 报告**
   - 点击 "📄 导出 PDF 报告"
   - 保存到桌面，文件名 "repair_report.pdf"
   - 打开 PDF 查看内容

### 预期结果

PDF 报告应包含：
- 封面："冷喷涂缺陷修复报告" + 生成时间
- 扫描信息：扫描 ID、点云数量、缺陷体积
- 工艺参数表：所有参数的键值对
- 结果摘要：填充点数、层数等
- 修复前后对比图：3D 散点图
- 沉积体高度色温图
- 逐层沉积分析表

### 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| 形貌预测失败 | 路径数据缺失 | 重新生成路径 |
| PDF 导出失败 | reportlab 未安装 | pip install reportlab |
| PDF 中文乱码 | 中文字体问题 | 检查系统字体 |
| 预测结果为空 | 参数不合理 | 检查可行性检查结果 |

## 案例 5：使用 MATLAB 远程计算引擎

### 目标
连接 MATLAB R2025b 进行精确的路径规划计算。

### 准备
- MATLAB R2025b 已安装
- MATLAB 计算服务已启动（见 [安装指南](02_安装指南.md) 第 6 步）

### 操作步骤

1. **确认 MATLAB 服务正在运行**
   - 打开 PowerShell，输入：
     ```
     Get-NetTCPConnection -State Listen -LocalPort 5555
     ```
   - 确认有输出（端口 5555 在监听）

2. **启动软件**
   ```
   cd D:\work\demo\industrial-vision
   .\venv\Scripts\Activate.ps1
   python run_app.py
   ```

3. **检查连接状态**
   - 底部状态栏左下角应显示 "🟡 远程服务就绪"
   - 如果显示 "⚫ 本地模式"，说明 MATLAB 服务未启动

4. **加载演示数据**（同案例 1）

5. **选取缺陷**（同案例 1）

6. **选择远程引擎**
   - 计算引擎下拉框选择 "远程服务 (MATLAB)"

7. **生成路径**
   - 点击 "🔧 生成修复路径"
   - 状态栏显示 "正在向远程服务发送计算请求..."
   - 等待 MATLAB 返回结果

8. **验证结果**
   - MATLAB 命令窗口会显示收到请求的日志
   - 3D 视图显示路径
   - 结果与本地引擎可能有差异（MATLAB 算法更精确）

### 预期结果
- 状态栏显示 "远程服务路径规划完成"
- 3D 视图显示路径线条
- MATLAB 命令窗口有请求记录

### 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| "远程服务"选项灰色 | MATLAB 服务未启动 | 启动 MATLAB 并运行 matlab_bridge_server |
| 请求超时 | MATLAB 响应慢或卡住 | 检查 MATLAB 窗口，必要时重启 |
| "远程服务路径规划失败" | MATLAB 侧出错 | 查看 MATLAB 命令窗口的错误信息 |
| 连接被拒绝 | 端口 5555 未监听 | 确认 matlab_bridge_server 正在运行 |
