## 4.1 顶部标题栏

标题栏位于窗口最上方，显示软件名称和当前状态。

### 标题
- **软件名称**：冷喷涂缺陷修复工作流
- **副标题**：数据导入 → 缺陷选区 → 路径规划 → 形貌预测 → 工艺交付

### 状态标签

标题栏右侧有两个状态标签：

| 标签 | 显示内容 | 含义 |
|------|---------|------|
| 模式状态 | "修复模式" 或 "增材模式" | 当前工作模式（见下文"修复模式"说明） |
| 工作流状态 | "等待数据" / "等待选区/路径" / "等待形貌预测" / "计算中" / "交付就绪" | 当前工作流程的进度 |

## 4.2 左侧栏 — 路径规划页

左侧栏在路径规划页面时显示以下内容（从上到下）：

### 4.2.1 工作流步骤

显示 4 个步骤，完成一步后下一步解锁：

| 步骤 | 按钮文字 | 什么时候能点 |
|------|---------|-------------|
| 01 数据与路径 | "01 数据与路径\n加载点云、选区、生成路径" | 随时可点 |
| 02 形貌预测 | "02 形貌预测\n等待路径规划输出" → "航点就绪，等待执行" | 路径生成后可点 |
| 03 结果校核 | "03 结果校核\n等待路径与预测结果" | 预测完成后显示 |
| 04 输出交付 | "04 输出交付\n等待预测完成" → "可导出 G-code 与 PDF 报告" | 预测完成后显示 |

> 步骤前的 ✓ 表示该步骤已完成。

### 4.2.2 材料选择

| 元素 | 说明 |
|------|------|
| 材料下拉框 | 选择修复材料，可选：未指定、316L 不锈钢、Inconel 718、Ti-6Al-4V、6061 铝合金、纯铜 |
| 材料信息 | 显示当前材料的临界速度和密度，如 "v_cr: 600 m/s \| 密度: 7980 kg/m³" |

**什么时候选材料？**
- 加载点云后、生成路径前选择
- 不同材料有不同的工艺参数限制

**各材料说明**：

| 材料 | 临界速度 | 适用场景 |
|------|---------|---------|
| 316L 不锈钢 | 600 m/s | 最常用的修复材料，默认选择 |
| Inconel 718 | 640 m/s | 高温合金，航空发动机零件 |
| Ti-6Al-4V | 680 m/s | 钛合金，航空航天 |
| 6061 铝合金 | 590 m/s | 铝合金零件 |
| 纯铜 | 340 m/s | 导电/导热零件 |

### 4.2.3 加载点云

| 按钮 | 功能 |
|------|------|
| 📂 加载点云 | 打开文件对话框，选择点云文件加载 |

**支持的文件格式**：
- CSV（.csv）：逗号分隔，可含 3 列（x,y,z）或 6 列（x,y,z,nx,ny,nz）
- TXT（.txt）：同 CSV
- XYZ（.xyz）：空格分隔，3 列
- ASC（.asc）：空格分隔，3 列

> 如果取消文件对话框，会询问是否加载演示数据。

### 4.2.4 修复模式

| 选项 | 说明 |
|------|------|
| 增材模式（全表面覆盖） | 对整个零件表面生成全覆盖路径 |
| 修复模式（缺陷填充） | 只在缺陷区域生成填充路径 |

**什么时候用哪个？**
- **修复模式**：零件有局部缺陷（坑、槽、划痕），只需要修缺陷部分 → 默认选择
- **增材模式**：需要在整个表面增加涂层

**模式提示**：
- 修复模式："💡 在中心视图框选缺陷区域 → 调参数 → 点击生成路径"
- 增材模式："💡 增材模式：将对整个零件表面生成全覆盖路径"

### 4.2.5 计算引擎

| 选项 | 说明 |
|------|------|
| 本地计算引擎 | 使用电脑自带的 Python 算法计算，速度快，适合日常使用 |
| 远程服务 (MATLAB) | 连接 MATLAB 进行计算，精度更高，需要 MATLAB 正在运行 |

**什么时候选哪个？**
- 日常使用、快速预览 → 本地计算引擎
- 需要精确结果、最终交付 → 远程服务（需要 MATLAB）

> 如果"远程服务"选项是灰色的，说明 MATLAB 没有运行或没有安装。详见 [安装指南](02_安装指南.md)。

### 4.2.6 路径规划参数

| 参数名 | 默认值 | 范围 | 单位 | 含义 |
|--------|--------|------|------|------|
| 层高 | 2.0 | 0.1–10.0 | mm | 每层喷涂的厚度。值越小，修复越精细但耗时越长 |
| 扫描角度 | -45.0 | -90.0–90.0 | ° | 喷枪移动方向的角度。-45° 表示斜向扫描 |
| 扫描步长 | 2.0 | 0.1–10.0 | mm | 相邻两条扫描线之间的距离。值越小，路径越密 |
| 边缘步长 | 2.0 | 0.1–10.0 | mm | 边缘区域的步长 |
| 倾斜角度 | 60.0 | 0.0–90.0 | ° | 喷枪相对零件的倾斜角度 |
| 增材缓冲 | 2.0 | 0.0–10.0 | mm | 增材模式下超出边界的缓冲距离 |
| 修复缓冲 | 0.0 | 0.0–10.0 | mm | 修复模式下超出缺陷边界的缓冲距离 |
| 路径过渡距离 | 10.0 | 1.0–100.0 | mm | 两条不相邻路径之间的过渡距离 |
| 避障精度 | 0.5 | 0.1–5.0 | mm | 避开障碍物的精度，值越小越精确但计算越慢 |
| 规划层数 | 10 | 1–50 | 层 | 路径规划的总层数 |

**参数调整建议**：
- 新手：保持默认值即可
- 想要更精细：减小层高和扫描步长
- 想要更快：增加层高和扫描步长

### 4.2.7 输出选项

| 选项 | 说明 |
|------|------|
| 保存计算中间文件到磁盘 | 勾选后，路径规划的结果会保存到硬盘，形貌预测从文件读取；不勾选则只在内存中传递 |

**什么时候勾选？**
- 日常使用：勾选（默认）
- 不需要做形貌预测：可以不勾选

### 4.2.8 操作按钮

| 按钮 | 功能 | 什么时候用 |
|------|------|-----------|
| 🔧 生成修复路径 | 根据参数和选区生成喷涂路径 | 选好缺陷、调好参数后点击 |
| 📤 导出 G-code | 将生成的路径导出为数控加工文件 | 路径生成完成后点击 |

## 4.3 左侧栏 — 形貌预测页

点击左侧 "02 形貌预测" 切换到此页面。

### 4.3.1 输入数据来源

| 显示项 | 含义 |
|--------|------|
| 状态 | "请先完成路径规划" → "航点数据就绪 (xxx 个)" |
| 来源 | "文件" 或 "内存"，表示路径数据的来源 |

### 4.3.2 P1 动画演示

| 元素 | 说明 |
|------|------|
| MATLAB 帧状态 | 显示 MATLAB 中间帧的数量，如 "MATLAB 帧: xx 张" 或 "未找到" |
| ▶ 播放 P1 演示动画 | 播放预存的 MATLAB 三视图动画 |

> 这只是一个演示功能，展示喷涂过程的概念动画。

### 4.3.3 冷喷涂工艺参数

| 参数名 | 默认值 | 范围 | 单位 | 含义 |
|--------|--------|------|------|------|
| 粒子速度 | 500.0 | 100–1200 | m/s | 粉末颗粒撞击零件表面的速度 |
| 临界速度 | 400.0 | 100–1000 | m/s | 颗粒能附着的最小速度（由材料自动计算，**不能手动改**） |
| 喷嘴直径 | 6.0 | 1.0–20.0 | mm | 喷枪喷嘴的直径 |
| 喷涂角度 | 90.0 | 0.0–180.0 | ° | 喷枪与零件表面的角度，90° 为垂直 |
| 喷涂距离 | 30.0 | 5.0–100.0 | mm | 喷嘴到零件表面的距离 |
| 粉末粒径 | 25.0 | 5.0–100.0 | μm | 粉末颗粒的直径 |
| 气体温度 | 800.0 | 200–1200 | °C | 喷涂气体的温度 |
| 气体压力 | 40.0 | 10.0–100.0 | bar | 喷涂气体的压力 |
| 送粉速度 | 30.0 | 5.0–200.0 | g/min | 每分钟送入的粉末量 |
| 移动速度 | 500.0 | 50–2000 | mm/s | 喷枪移动的速度 |

**临界速度为什么不能改？**
因为它由你选的材料决定。每种材料有自己的临界速度（如 316L 不锈钢是 600 m/s），软件自动填入。

### 4.3.4 沉积参数

| 参数名 | 默认值 | 范围 | 含义 |
|--------|--------|------|------|
| 深度补偿 | 1.0 | 0–2 | 补偿系数，用于调整沉积深度 |
| 预测层数 | 5 | 1–20 | 形貌预测的层数 |

### 4.3.5 操作按钮

| 按钮 | 功能 | 什么时候用 |
|------|------|-----------|
| 🔍 可行性检查 | 检查当前参数和缺陷是否适合冷喷涂修复 | 执行形貌预测前先检查 |
| 🔮 执行形貌预测 | 模拟喷涂过程，预测修复后的形貌 | 路径规划完成后执行 |
| 📄 导出 PDF 报告 | 生成包含参数、对比图和结果的 PDF 报告 | 形貌预测完成后导出 |

## 4.4 中心视图 — 3D 点云操作

路径规划页面的中心视图用于查看和选取点云。

### 4.4.1 工具栏

| 按钮/控件 | 说明 |
|-----------|------|
| 🧭 导航模式 / ✂️ 选取模式 | 点击切换。导航模式可旋转缩放视图；选取模式可框选缺陷 |
| 模式下拉框 | 选择选取方式：矩形框选、自由选区、区域选择、取消选择 |
| 笔刷半径 | 区域选择/取消选择模式下的笔刷大小（0.5–20.0 mm） |
| ↩ 撤销 | 撤销上一次选区操作 |
| ✕ 清除选区 | 清除所有已选区域 |
| ⇄ 反选 | 把已选和未选的区域互换 |
| 信息标签 | 显示 "选中: xxx / xxxx 点" |

### 4.4.2 四种选取方式

| 方式 | 怎么用 | 适合什么场景 |
|------|--------|-------------|
| 矩形框选 | 按住鼠标左键拖动画矩形 | 大面积缺陷，形状规则 |
| 自由选区 | 按住鼠标左键画任意形状 | 形状不规则的缺陷 |
| 区域选择 | 用笔刷涂抹添加选区 | 补充选取，精细调整 |
| 取消选择 | 用笔刷涂抹取消选区 | 擦除多余选区 |

### 4.4.3 导航操作

在导航模式下：
- **左键拖动**：旋转视图
- **右键拖动**：平移视图
- **滚轮**：缩放

### 4.4.4 坐标轴

视图中的坐标轴标注：
- X (mm)：长度方向
- Y (mm)：宽度方向
- Z (mm)：高度方向

## 4.7 右侧栏 — 信息面板

右侧栏从上到下显示以下信息：

### 4.7.1 点云信息

| 显示项 | 含义 |
|--------|------|
| 点数 | 当前加载的点云总点数 |
| 已选 | 当前选中的缺陷区域点数 |

### 4.7.2 可行性报告

| 显示项 | 含义 |
|--------|------|
| 状态 | "尚未检查" → "✅ 可行" / "⚠️ 有条件可行" / "❌ 不可行" |

- ✅ 通过的检查项
- ⚠️ 警告项（有条件通过，建议调整）
- 🚫 阻断项（不可行，必须修改）

### 4.7.3 进度

| 显示项 | 含义 |
|--------|------|
| 进度条 | 0–100%，显示当前计算进度 |
| 进度文字 | 显示当前操作，如 "正在生成修复路径..."、"路径规划中... 第 3/10 层" |

### 4.7.4 结果摘要

| 显示项 | 含义 |
|--------|------|
| 填充点数 | 修复区域填充的沉积点数 |

| 预计耗时 | 预计喷涂时间（秒） |
| 修复层数 | 实际修复的层数 |

## 4.9 对话框说明

### 4.9.1 文件对话框

| 对话框 | 什么时候出现 | 说明 |
|--------|-------------|------|
| 加载点云 | 点击"📂 加载点云" | 选择 .csv/.txt/.xyz/.asc 文件 |
| 导出 G-code | 点击"📤 导出 G-code" | 选择保存位置，默认文件名 repair.nc |
| 导出 PDF | 点击"📄 导出 PDF 报告" | 选择保存位置，默认文件名 repair_report.pdf |

### 4.9.2 提示对话框

| 提示 | 什么时候出现 | 怎么处理 |
|------|-------------|---------|
| "未选择文件。是否加载内置演示数据？" | 取消文件选择对话框 | 点"是"用演示数据，点"否"重新选择文件 |
| "路径规划完成！" | 路径生成成功 | 点"确定"，然后进行下一步 |
| "请至少选取 3 个点" | 缺陷区域选太少 | 重新框选更大的区域 |
| "请先加载点云" | 没加载数据就点生成 | 先点"加载点云" |
| "请在中心视图选取缺陷区域" | 没选缺陷就点生成 | 先在 3D 视图框选缺陷 |
| "路径规划仍在进行中" | 重复点击生成 | 等待当前计算完成 |
| "请先生成修复路径" | 没做路径规划就做形貌预测 | 先完成路径规划 |
| "未找到航点数据" | 路径数据丢失 | 重新执行路径规划 |
