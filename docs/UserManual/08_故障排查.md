## 8.1 启动问题

### 问题 1：软件无法启动

**症状**：双击或命令行运行后，软件窗口不出现。

**可能原因**：
1. Python 没有安装或版本不对
2. 软件依赖没有安装
3. 虚拟环境没有激活

**解决方法**：
1. 打开 PowerShell，输入 `python --version`，确认输出 Python 3.10-3.12
2. 进入软件目录：`cd D:\work\demo\industrial-vision`
3. 激活虚拟环境：`.\venv\Scripts\Activate.ps1`
4. 重新运行：`python run_app.py`
5. 查看命令行输出的错误信息

### 问题 2：启动时提示 "No module named 'xxx'"

**症状**：启动报错，提示找不到某个模块。

**解决方法**：

| 缺少的模块 | 解决命令 |
|-----------|---------|
| PySide6 | `pip install PySide6` |
| zmq | `pip install pyzmq` |
| numpy | `pip install numpy` |
| scipy | `pip install scipy` |
| shapely | `pip install shapely` |
| reportlab | `pip install reportlab` |
| cryptography | `pip install cryptography` |

或者一次性重装所有依赖：
```
pip install -r requirements.txt
```

### 问题 3：启动时提示 "无法加载文件...禁止运行脚本"

**症状**：激活虚拟环境时报脚本执行策略错误。

**解决方法**：
```
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```
按 Y 确认，然后重新激活虚拟环境。

### 问题 4：窗口出现但白屏

**症状**：软件窗口出现但全是白色，看不到任何内容。

**可能原因**：显卡驱动问题。

**解决方法**：
1. 更新显卡驱动到最新版
2. 尝试设置环境变量：`$env:QT_QPA_PLATFORM="windows"` 后重新启动
3. 如果仍有问题，尝试 `$env:QT_OPENGL="angle"` 后重新启动

## 8.2 数据加载问题

### 问题 5：点云文件加载失败

**症状**：点击加载后提示"加载失败"。

**可能原因**：
1. 文件格式不对
2. 文件内容有问题（空文件、格式错误）
3. 文件路径包含特殊字符

**解决方法**：
1. 确认文件格式是 .csv、.txt、.xyz、.asc 之一
2. 用记事本打开文件，确认内容是数字，不是乱码
3. CSV 文件应该用逗号分隔，XYZ/ASC 用空格分隔
4. 确认至少有 3 列数字（x, y, z 坐标）
5. 把文件复制到一个简单路径（如 D:\test\）再试

### 问题 6：加载后 3D 视图为空

**症状**：文件加载成功但 3D 视图看不到东西。

**解决方法**：
1. 在 3D 视图区域滚动鼠标滚轮，缩小视图
2. 检查右侧"点云信息"，确认点数大于 0
3. 如果点数正常但看不见，可能是坐标范围太大或太小，尝试用鼠标右键拖动平移视图

### 问题 7：演示数据加载失败

**症状**：取消文件对话框后，点击"是"加载演示数据但失败。

**解决方法**：
1. 关闭软件
2. 重新启动软件
3. 再次尝试加载演示数据
4. 如果仍失败，重新安装软件

## 8.3 选取缺陷问题

### 问题 8：选取模式按钮点不了

**症状**："✂️ 选取模式"按钮灰色，无法点击。

**原因**：还没有加载点云数据。

**解决方法**：先点击"📂 加载点云"加载数据。

### 问题 9：框选后没有红色高亮

**症状**：在选取模式下框选了区域，但点没有变红。

**可能原因**：
1. 框选区域没有覆盖到点
2. 框选方向不对

**解决方法**：
1. 确认框选区域覆盖了点云
2. 尝试从左上角往右下角拖动
3. 查看右侧"已选"是否有数字
4. 如果"已选"为 0，说明没有选到点，重新框选

### 问题 10：选取的点太少

**症状**：提示"请至少选取 3 个点"。

**解决方法**：
1. 点击"✕ 清除选区"
2. 框选更大的区域
3. 确认框选区域覆盖了有点的位置
4. 可以先用"导航模式"旋转视图，找到缺陷位置，再切换到选取模式

### 问题 11：选区无法清除

**症状**：点击"清除选区"后红色区域还在。

**解决方法**：
1. 点击"✕ 清除选区"按钮
2. 如果无效，切换到"取消选择"模式，用笔刷擦除
3. 如果仍无效，重新加载数据

## 8.4 路径规划问题

### 问题 12：生成路径按钮灰色

**症状**："🔧 生成修复路径"按钮灰色点不了。

**可能原因**：
1. 没有加载点云
2. 没有选取缺陷（修复模式下）
3. 正在计算中

**解决方法**：
1. 确认已加载点云
2. 确认已选取缺陷区域（至少 3 个点）
3. 如果正在计算，等待完成

### 问题 13：路径规划一直卡住

**症状**：点击生成后长时间无响应。

**可能原因**：
1. 点云数据太大
2. 参数设置导致计算量大
3. 本地引擎计算慢

**解决方法**：
1. 等待 1-2 分钟
2. 如果仍无响应，按 Ctrl+C 终止，重启软件
3. 减小规划层数（如改为 5 层）
4. 增大扫描步长（如改为 3.0 mm）
5. 减小点云数据量

### 问题 14：路径规划失败

**症状**：弹出"路径规划失败"错误。

**解决方法**：
1. 查看错误信息
2. 常见原因：
   - 选取的缺陷区域太小 → 重新选取更大区域
   - 参数超出范围 → 检查参数是否在允许范围内
   - 点云数据有问题 → 重新加载或使用演示数据
3. 如果使用远程引擎，检查 MATLAB 是否正常运行

### 问题 15：路径生成但看起来不对

**症状**：路径线条出现了，但分布不合理。

**解决方法**：
1. 检查是否选对了缺陷区域
2. 调整扫描角度（如从 -45° 改为 0°）
3. 调整扫描步长
4. 确认修复模式选择正确（修复模式 vs 增材模式）

## 8.5 形貌预测问题

### 问题 16：可行性检查显示"不可行"

**症状**：可行性检查结果为 ❌。

**解决方法**：查看具体原因：

| 原因 | 解决 |
|------|------|
| 粒子速度不足 | 增大粒子速度（必须大于临界速度） |
| 缺陷太小 | 换小直径喷嘴 |
| 缺陷太深 | 减小层高，分多层修复 |
| 侧壁太陡 | 调整喷涂角度 |
| 喷涂角度太低 | 增大喷涂角度（至少 30°） |

### 问题 17：形貌预测失败

**症状**：点击执行形貌预测后弹出错误。

**解决方法**：
1. 确认已完成路径规划
2. 确认可行性检查通过
3. 检查冷喷涂参数是否在合理范围
4. 重新执行路径规划后再试

### 问题 18：形貌预测结果为空

**症状**：预测完成但 3D 视图没有沉积效果。

**解决方法**：
1. 检查右侧"结果摘要"，看填充点数是否为 0
2. 如果为 0，可能是参数不合理
3. 调整参数（增大粒子速度、增大送粉速度）
4. 重新执行预测

## 8.6 导出问题

### 问题 19：G-code 导出失败

**症状**：点击导出后提示"G-code 导出失败"。

**解决方法**：
1. 确认已生成路径
2. 确认有保存权限（尝试保存到桌面）
3. 查看命令行错误日志
4. 如果提示"安全检查未通过"，说明航点坐标有异常值，重新生成路径

### 问题 20：PDF 报告导出失败

**症状**：点击导出后提示"PDF 报告生成失败"。

**可能原因**：
1. reportlab 未安装
2. 中文字体问题
3. 没有形貌预测结果

**解决方法**：
1. 安装 reportlab：`pip install reportlab`
2. 确认已完成形貌预测
3. 确认系统有中文字体
4. 尝试保存到简单路径（如 D:\）

### 问题 21：导出的文件打开是乱码

**症状**：G-code 文件用记事本打开是乱码。

**解决方法**：
- G-code 是纯文本文件，应该用记事本能正常打开
- 如果乱码，尝试用 VSCode 或 Notepad++ 打开
- 选择 UTF-8 编码

## 8.7 MATLAB 连接问题

### 问题 22："远程服务"选项灰色

**症状**：计算引擎下拉框中"远程服务 (MATLAB)"选项灰色不可选。

**原因**：MATLAB 服务未启动或未正确配置。

**解决方法**：
1. 确认 MATLAB R2025b 已安装
2. 启动 MATLAB
3. 在 MATLAB 中执行：
   ```matlab
   cd('D:\work\demo\industrial-vision')
   pyenv('Version', 'D:\work\demo\industrial-vision\venv\Scripts\python.exe')
   matlab_bridge_server
   ```
4. 等待 MATLAB 显示服务已启动
5. 在 PowerShell 中验证端口：`Get-NetTCPConnection -State Listen -LocalPort 5555`

### 问题 23：远程请求超时

**症状**：选择远程引擎生成路径后，长时间无响应。

**解决方法**：
1. 查看 MATLAB 命令窗口是否有错误输出
2. 如果 MATLAB 卡住，在 MATLAB 中按 Ctrl+C 终止服务
3. 重新启动服务：在 MATLAB 中再次运行 `matlab_bridge_server`
4. 重试请求

### 问题 24：MATLAB 提示"文本字符无效"

**症状**：MATLAB 启动服务时报"文本字符无效"错误。

**原因**：MATLAB 算法文件中含非 ASCII 字符。

**解决方法**：联系开发者修复 .m 文件中的非 ASCII 字符。

## 8.8 界面显示问题

### 问题 25：界面文字太小看不清

**解决方法**：
1. 右键桌面 → 显示设置 → 调整缩放比例到 125% 或 150%
2. 或在软件启动前设置：`$env:QT_AUTO_SCREEN_SCALE_FACTOR=1`

### 问题 26：3D 视图旋转不了

**解决方法**：
1. 确认在"导航模式"（不是选取模式）
2. 用鼠标左键拖动旋转
3. 如果仍不行，点击视角下拉框选择一个预设视角

### 问题 27：界面布局错乱

**解决方法**：
1. 关闭软件
2. 重新启动
3. 如果仍错乱，检查显示器分辨率是否满足最低要求（1366×768）

## 8.9 性能问题

### 问题 28：软件运行很慢

**可能原因**：
1. 点云数据太大
2. 电脑内存不足
3. 参数设置导致计算量大

**解决方法**：
1. 减小点云数据量
2. 关闭其他占内存的程序
3. 减小规划层数
4. 增大扫描步长和层高
4. 增加电脑内存

### 问题 29：软件卡死无响应

**解决方法**：
1. 等待 30 秒，看是否恢复
2. 如果不恢复，按 Ctrl+C 终止
3. 在任务管理器中结束 Python 进程
4. 重新启动软件

## 8.10 何时联系开发者

遇到以下情况，请记录错误信息并联系开发者：

| 情况 | 需要记录的信息 |
|------|---------------|
| 软件反复崩溃 | 命令行错误信息、操作步骤 |
| 计算结果明显错误 | 输入参数、输出结果截图 |
| MATLAB 连接异常 | MATLAB 命令窗口的完整错误信息 |
| 导出的文件格式不对 | 文件内容截图 |
| 界面显示异常 | 截图 |

**联系开发者时请提供**：
1. 你做了什么操作（具体步骤）
2. 你期望看到什么
3. 实际发生了什么
4. 命令行的完整错误信息（截图或复制）
5. 软件版本号（1.0.0）
