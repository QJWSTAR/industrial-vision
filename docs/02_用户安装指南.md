## 一、Windows 安装

### 系统要求

| 项目 | 最低要求 | 推荐 |
|------|----------|------|
| 操作系统 | Windows 10 64 位 | Windows 11 64 位 |
| 内存 | 8 GB | 16 GB 及以上 |
| 磁盘空间 | 2 GB（不含 MATLAB） | 5 GB 及以上 |
| 显卡 | 支持 OpenGL 2.1 | 独立显卡，显存 2 GB+ |
| 屏幕分辨率 | 1366×768 | 1920×1080 及以上 |

> 软件默认窗口尺寸 1700×950，分辨率低于 1920×1080 时可能出现界面拥挤，建议使用更高分辨率。

### 获取软件

- **源码包**：解压到任意目录，例如 `D:\work\demo\industrial-vision`。
- **打包版**：拿到 `CSAM_Repair.exe` 单文件可执行程序，无需安装 Python，直接双击运行。本指南后续章节主要面向源码安装方式。

## 二、Python 安装

### 1. 安装 Python

本软件需要 **Python 3.10 – 3.12**，推荐使用 **3.12**。

- 从 [python.org](https://www.python.org/downloads/) 下载安装包。
- 安装时务必勾选 **「Add Python to PATH」**。
- 安装完成后打开 PowerShell 验证：

```powershell
python --version
# 期望输出: Python 3.12.x
```

### 2. 创建虚拟环境

虚拟环境可以避免污染系统 Python，强烈建议使用。

```powershell
cd D:\work\demo\industrial-vision

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
venv\Scripts\activate
```

激活成功后，命令行提示符前会出现 `(venv)` 字样。后续所有 `pip` 命令都应在激活状态下执行。

> 如果使用 PowerShell 时遇到执行策略报错，请先执行：
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

### 3. 升级 pip

```powershell
python -m pip install --upgrade pip
```

### 4. 安装依赖

```powershell
pip install -r requirements.txt
```

运行时依赖列表（见 `requirements.txt`）：

| 依赖 | 最低版本 | 用途 |
|------|----------|------|
| numpy | ≥ 1.21 | 点云数组运算 |
| scipy | ≥ 1.7 | 凸包、空间运算 |
| shapely | ≥ 1.8 | 几何运算 |
| PySide6 | ≥ 6.4 | GUI 界面框架 |
| matplotlib | ≥ 3.5 | 3D 可视化与截面图 |
| pyzmq | ≥ 24 | ZeroMQ 通信（连接 MATLAB） |
| protobuf | ≥ 5.26 | 协议序列化 |
| reportlab | ≥ 4.0 | PDF 报告生成 |
| cryptography | ≥ 41.0 | RSA 许可证验证 |

### 5. 可选开发依赖

仅参与开发、测试或打包时需要：

```powershell
# 一次性安装全部开发依赖
pip install pytest pytest-cov pytest-benchmark flake8 bandit pyinstaller
```

| 依赖 | 用途 |
|------|------|
| pytest | 单元测试框架 |
| pytest-cov | 测试覆盖率统计 |
| pytest-benchmark | 性能基准测试 |
| flake8 | 代码风格检查 |
| bandit | 安全扫描 |
| pyinstaller | 打包为 exe |

### 6. 验证安装

```powershell
python run_app.py
```

如果窗口正常弹出并显示「冷喷涂缺陷修复软件 v1.0.0」，说明 Python 端安装成功。

## 三、MATLAB 安装

MATLAB 是可选组件，仅在需要远程算法计算时安装。本地计算引擎无需 MATLAB。

### 1. 安装 MATLAB

- 版本要求：**MATLAB R2020b 及以上**，推荐 **R2025b**。
- 从 [MathWorks 官网](https://www.mathworks.com/) 下载并安装。

### 2. 必需的工具箱

| 工具箱 | 是否必需 | 用途说明 |
|--------|----------|----------|
| Mapping Toolbox | 按需 | 仅 `generate_path`（路径规划）和 `profile_predict`（形貌预测）需要其中的 `polyxpoly` 函数 |
| Curve Fitting Toolbox | 按需 | 仅 `particle_fitting`（粒子拟合）需要其中的 `fit` / `fittype` 函数 |

> **重要**：`containers.Map`、`graph`、`conncomp`、`dfsearch` 这些函数属于 **MATLAB 基础功能**，不需要额外购买任何工具箱。如果 health 检查报告这些函数不可用，属于误报，不影响使用。

如果不使用路径规划、形貌预测和粒子拟合中的 MATLAB 实现，可以不安装上述工具箱，软件会自动降级到本地引擎。

### 3. 启动 MATLAB Server

打开 MATLAB，在命令窗口中执行：

```matlab
cd('D:\work\demo\industrial-vision\matlab_server')
startup
```

看到如下输出即表示服务已就绪：

```
CSAM MATLAB Server starting on tcp://*:5570 (port 5570), protocol v...
```

`startup` 会自动完成以下工作：
- 将 `matlab_server` 目录加入路径；
- 自动探测并加入「路径规划」和「形貌预测」算法目录（通过查找特征 `.m` 文件定位，避免中文目录名编码问题）；
- 读取环境变量构建配置；
- 启动 ZMQ 服务并阻塞等待请求。

### 4. R2025b 注意事项

在 MATLAB R2025b 上运行时，有几点需要留意：

- **非 ASCII 字符解析问题**：R2025b 的解析器在部分场景下会拒绝非 ASCII 字符（如中文注释）。本软件的 MATLAB 代码已修复此问题，日志输出统一使用 UTF-8 编码，可正常运行。
- **Java 显示怪癖**：在 R2025b 中执行 `version('-java')` 可能显示 `Java is not enabled`，这只是一个显示怪癖，**Java 实际上已启用**。可用 `usejava('jvm')` 验证，返回 `1`（逻辑真）即表示 JVM 正常工作，不影响任何依赖 Java 的功能。

## 四、依赖安装详细说明

### 依赖来源

所有 Python 依赖均来自官方 PyPI 仓库，安装 `requirements.txt` 时会自动拉取。

### 常见依赖问题

**PySide6 安装缓慢或失败**

PySide6 体积较大，建议配置国内镜像源加速：

```powershell
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**matplotlib 中文字体不显示**

软件已内置 CJK 字体处理（`repair_app/platform/fonts.py`），通常无需手动配置。如果仍然出现方块，请确认系统已安装微软雅黑或思源黑体。

**pyzmq 编译报错**

Windows 下 pyzmq 提供预编译轮子，一般不需要编译。如果遇到编译错误，请确认使用的是 64 位 Python。

### 全功能安装（可选）

项目 `pyproject.toml` 提供了额外依赖组：

```powershell
# 安装 loguru 增强日志
pip install -e ".[full]"

# 安装全部开发工具
pip install -e ".[dev]"
```

## 五、环境变量

软件通过环境变量控制通信、日志、MATLAB 连接等行为。未设置时使用默认值，多数情况下无需修改。

### 配置方式

1. **`.env` 文件**：将项目根目录下的 `.env.example` 复制为 `.env`，按需填写。软件启动时会自动读取。
2. **系统环境变量**：在 Windows「系统属性 → 环境变量」中设置，优先级高于 `.env` 文件。

```powershell
# 复制模板
copy .env.example .env
# 然后用文本编辑器打开 .env 修改
```

### 关键环境变量一览

#### 许可证与安全

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `CSAM_HMAC_SECRET` | 许可证 HMAC 校验密钥。**生产环境必须设置**；开发环境留空则使用内置开发回退密钥 | 空（开发模式） |

#### ZMQ 通信地址

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `CSAM_ZMQ_ADDRESS` | ZMQ 传输地址 | Windows: `tcp://127.0.0.1:5555` |

#### MATLAB 执行平台

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `CSAM_MATLAB_BIND` | MATLAB Server 监听地址（`startup.m` 读取） | `tcp://*:5570` |
| `CSAM_MATLAB_HOST` | GUI 端连接 MATLAB 的主机 | `127.0.0.1` |
| `CSAM_MATLAB_PORT` | GUI 端连接 MATLAB 的端口 | `5570` |
| `CSAM_MATLAB_LOG_DIR` | MATLAB Server 日志目录 | `./logs` |
| `CSAM_MATLAB_HEARTBEAT_MS` | MATLAB Server 心跳间隔（毫秒） | `1000` |
| `CSAM_MATLAB_LOG_LEVEL` | MATLAB Server 日志级别 | `info` |
| `CSAM_ENGINE_DISABLE_MATLAB` | 设为 `1` 强制禁用 MATLAB 引擎，降级到本地原型引擎（用于调试） | `0` |

#### Bridge 通信层

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `CSAM_BRIDGE_TIMEOUT_MS` | 请求超时（毫秒） | `30000` |
| `CSAM_BRIDGE_CONNECT_MS` | 连接超时（毫秒） | `5000` |
| `CSAM_BRIDGE_HEALTH_MS` | 健康检查超时（毫秒） | `2000` |
| `CSAM_BRIDGE_HEARTBEAT_MS` | 心跳间隔（毫秒） | `2000` |
| `CSAM_BRIDGE_HEARTBEAT_MISS` | 心跳连续丢失多少次后触发重连 | `3` |
| `CSAM_BRIDGE_MAX_RETRIES` | 最大重试次数 | `3` |
| `CSAM_BRIDGE_RETRY_MS` | 重试初始间隔（毫秒） | `200` |
| `CSAM_BRIDGE_LATENCY_LOG_MS` | 延迟超过此阈值（毫秒）则记录 WARNING | `5000` |

#### 日志

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `CSAM_LOG_LEVEL` | Python 端日志级别（`DEBUG` / `INFO` / `WARNING` / `ERROR`） | `INFO` |

#### 引擎生命周期监控

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `CSAM_HEARTBEAT_INTERVAL_MS` | 客户端心跳间隔（毫秒） | `2000` |
| `CSAM_HEARTBEAT_TIMEOUT_MS` | 心跳探测超时（毫秒） | `3000` |
| `CSAM_HEARTBEAT_MISS_THRESHOLD` | 心跳丢失阈值，触发 RECONNECTING 状态 | `3` |
| `CSAM_RECONNECT_MAX_ATTEMPTS` | 最大重连尝试次数 | `10` |

### `.env.example` 模板说明

项目根目录提供 `.env.example` 模板文件，其中：

- **未注释的变量**（如 `CSAM_HMAC_SECRET=`）为必填或重要项，需根据实际环境填写。
- **以 `#` 注释的变量**（如 `# CSAM_ZMQ_ADDRESS=tcp://127.0.0.1:5555`）为可选项，取消注释并修改即可启用。

使用时复制为 `.env`，按需修改。`.env` 文件不应纳入版本控制，已在 `.gitignore` 中排除。

## 六、许可证

### 许可证机制

软件启动时由 `LicenseManager` 进行许可证校验：

1. 读取 `config/license.key` 许可证文件；
2. 使用 `config/public_key.pem` 公钥进行 **RSA-2048 签名验证**；
3. 校验机器码绑定（基于 MAC 地址与主机名哈希）；
4. 校验是否过期。

### 生产环境

- **`CSAM_HMAC_SECRET` 必须设置**。打包版（exe）若未设置此变量，启动时会记录错误并使用空密钥，HMAC 验证将不安全。
- 许可证文件 `license.key` 和公钥 `public_key.pem` 需放置在 `config/` 目录。

### 开发环境

- 无需设置 `CSAM_HMAC_SECRET`，软件会自动使用内置开发回退密钥 **`csam_dev_secret_2026`**（仅限开发用途，请勿用于生产）。
- 即便没有许可证文件，软件也能正常启动，仅会在日志中记录一条警告，不阻止任何功能。

### 签发许可证

```powershell
# 生成 RSA 密钥对（首次）
python -m repair_app.utils.license_manager keygen

# 签发许可证（默认 365 天）
python -m repair_app.utils.license_manager issue "用户名" 365
```

许可证文件会输出到 `config/license.key`。

## 七、升级

升级前请务必备份，避免数据丢失。

### 升级步骤

1. **备份配置和数据**
   - 备份 `config/` 目录（含 `license.key`、`public_key.pem`）；
   - 备份 `morphology_prediction/` 目录（含历史点云与速度数据）；
   - 备份 `.env` 文件（如有自定义配置）。

2. **升级依赖**

   ```powershell
   # 激活虚拟环境
   venv\Scripts\activate

   # 拉取新版本代码后，升级依赖
   pip install -r requirements.txt --upgrade
   ```

3. **重启软件**

   ```powershell
   python run_app.py
   ```

4. **如使用 MATLAB Server**，需同步更新 `matlab_server/` 目录并在 MATLAB 中重新执行 `startup`。

> 版本变更内容请查阅项目根目录的 `CHANGELOG.md`。

## 八、卸载

按以下顺序清理，可彻底移除软件：

1. **关闭软件**：退出 GUI 主程序；如在运行 MATLAB Server，在 MATLAB 中按 `Ctrl+C` 停止服务。

2. **删除虚拟环境**：直接删除 `venv` 目录即可移除所有 Python 依赖。

   ```powershell
   # 在项目根目录下执行
   rmdir /s /q venv
   ```

3. **删除安装目录**：删除整个 `industrial-vision` 文件夹。

4. **清理环境变量**：在 Windows「系统属性 → 环境变量」中，删除手动添加的 `CSAM_*` 变量。

5. **清理残留数据**（可选）：检查并删除用户目录下可能遗留的 matplotlib 缓存。

> MATLAB 本身的卸载请通过 MathWorks 安装器完成，与本软件无关。
