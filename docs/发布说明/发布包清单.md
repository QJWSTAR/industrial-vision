### 2.2 配置文件校验值

| 文件 | SHA256 | 备注 |
|------|--------|------|

### 2.3 发布包整体校验值

| 文件 | SHA256 | 备注 |
|------|--------|------|
| `CSAM_Repair_v1.0.0_Windows_x64.zip` | `__SHA256_TO_BE_FILLED__` | 待填充 |
| `CSAM_Repair_v1.0.0_Windows_x64.exe` | `__SHA256_TO_BE_FILLED__` | 安装版（如提供） |

### 2.4 SHA256 计算方法

在 PowerShell 中执行：

```powershell
# 计算单个文件
Get-FileHash .\dist\CSAM_Repair.exe -Algorithm SHA256

# 计算发布包 ZIP
Get-FileHash .\CSAM_Repair_v1.0.0_Windows_x64.zip -Algorithm SHA256
```

在 CMD 中执行：

```cmd
certutil -hashfile dist\CSAM_Repair.exe SHA256
```

> 将计算结果填入上表对应位置，并随发布包一并提供给用户核对。

## 3. 文件大小估算

| 文件 | 估算大小 | 说明 |
|------|----------|------|
| `CSAM_Repair.exe` | 约 180–250 MB | 单文件 EXE，含全部依赖（UPX 压缩后） |
| `config/public_key.pem` | 约 0.8 KB | RSA-2048 公钥 |
| `config/calibration_db.json` | 约 2–5 KB | 标定配置 |
| `config/license.key` | 约 1 KB | 授权文件 |
| `启动软件.bat` | 约 0.5 KB | 启动脚本 |
| `docs/` | 约 1–2 MB | 全部文档 |
| **便携版 ZIP 总计** | **约 180–260 MB** | 压缩后约 150–220 MB |

> 实际大小取决于依赖版本与 UPX 压缩率。构建完成后请以实际大小为准更新本表。

### 体积构成参考

| 组成部分 | 占比估算 | 说明 |
|----------|----------|------|
| Python 解释器 + 标准库 | 约 30–40 MB | 基础运行时 |
| PySide6 (Qt6) | 约 80–100 MB | GUI 框架，最大头 |
| numpy / scipy | 约 30–40 MB | 科学计算 |
| matplotlib | 约 20–30 MB | 可视化 |
| pyzmq / protobuf | 约 5–10 MB | 通信 |
| reportlab | 约 10 MB | PDF 生成 |
| cryptography | 约 5 MB | 加密 |
| shapely | 约 5 MB | 几何计算 |
| 数据文件 + MATLAB 脚本 | 约 1–2 MB | 业务资源 |
| 应用代码 | 约 1 MB | repair_app 包 |

## 4. 发布包命名规范

### 4.1 命名格式

```
CSAM_Repair_v<主版本>.<次版本>.<修订号>_<平台>_<架构>.<扩展名>
```

### 4.2 v1.0.0 发布包命名

| 类型 | 文件名 | 说明 |
|------|--------|------|
| 便携版 ZIP | `CSAM_Repair_v1.0.0_Windows_x64.zip` | 默认发布形态 |
| 安装版 EXE | `CSAM_Repair_v1.0.0_Windows_x64.exe` | NSIS/Inno Setup 封装（可选） |
| 源码包 ZIP | `CSAM_Repair_v1.0.0_Source.zip` | 开发者用 |
| 校验文件 | `CSAM_Repair_v1.0.0_checksums.txt` | 所有文件的 SHA256 列表 |

### 4.3 命名规则说明

- **版本号**：遵循语义化版本（Semantic Versioning），格式 `vMAJOR.MINOR.PATCH`
- **平台**：`Windows` / `macOS` / `Linux`
- **架构**：`x64`（64 位）/ `arm64`（如需）
- **扩展名**：`.zip`（压缩包）/ `.exe`（安装器）/ `.dmg`（macOS）/ `.tar.gz`（Linux）
- 版本号前必须加 `v` 前缀

### 4.4 后续版本示例

| 版本 | 文件名 |
|------|--------|
| v1.0.1（修订） | `CSAM_Repair_v1.0.1_Windows_x64.zip` |
| v1.1.0（次版本） | `CSAM_Repair_v1.1.0_Windows_x64.zip` |
| v2.0.0（主版本） | `CSAM_Repair_v2.0.0_Windows_x64.zip` |
| 候选版（RC） | `CSAM_Repair_v1.1.0-rc1_Windows_x64.zip` |
| Beta 版 | `CSAM_Repair_v1.1.0-beta2_Windows_x64.zip` |

## 6. 发布前检查清单

发布前请逐项确认：

- [ ] `run_all_tests.ps1` 全部通过（402 passed）
- [ ] `build_windows.bat` 构建成功，无错误
- [ ] `dist\CSAM_Repair.exe` 已生成
- [ ] `dist\config\license.key` 已放置（按客户机器签发）
- [ ] `dist\config\public_key.pem` 存在
- [ ] 在干净虚拟机（无 Python）上验证启动正常
- [ ] 版本号显示为 `1.0.0`
- [ ] SHA256 校验值已计算并填入本文档第 2 节
- [ ] 发布包 ZIP 已按命名规范命名

- [ ] 文档目录完整（发布说明、用户手册、更新日志）
