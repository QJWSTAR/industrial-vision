# 便携版说明 — CSAM Repair V1.0.0

> **版本**：1.0.0（正式版） ｜ **发布日期**：2026-07-15 ｜ **面向角色**：最终用户
> **适用系统**：Windows 10/11 64 位

本文档面向最终用户，说明 CSAM Repair 便携版的使用方法。便携版无需安装，解压即用。

---

## 1. 便携版特点

CSAM Repair 便携版是一款**绿色软件**，具有以下特点：

- **无需安装**：解压 ZIP 包即可使用，不写注册表，不污染系统目录
- **解压即用**：双击 `CSAM_Repair.exe` 直接启动，无需配置 Python 环境
- **携带方便**：整个文件夹可放入 U 盘，在任意 Windows 电脑运行
- **数据隔离**：所有用户数据保存在系统标准目录，不与软件目录混淆
- **干净卸载**：删除软件文件夹即可完全卸载，不留残留
- **离线运行**：除可选的 MATLAB 算法引擎外，软件完全离线运行，无需联网

> 便携版适合单机部署、临时使用、U 盘携带等场景。如需开始菜单快捷方式或文件关联，请使用安装版（由发布工程师另行提供）。

---

## 2. 使用步骤

### 2.1 第一步：解压软件包

1. 获取软件包 `CSAM_Repair_v1.0.0_Windows_x64.zip`
2. 右键点击 ZIP 文件，选择"全部解压缩"
3. 选择解压目标位置（建议路径不含中文和空格），如 `D:\CSAM_Repair\`
4. 解压完成后，进入解压目录

> 也可使用 7-Zip、WinRAR 等工具解压。

### 2.2 第二步：放置 License 文件

软件需要授权文件才能运行。请将收到的 `license.key` 文件放入 `config` 文件夹：

1. 打开解压后的 `CSAM_Repair` 文件夹
2. 进入 `config` 子文件夹
3. 将 `license.key` 文件复制到 `config` 文件夹内
4. 确认 `config` 文件夹中存在 `license.key` 文件

```
CSAM_Repair\
├── CSAM_Repair.exe
└── config\
    └── license.key    ← 放到这里
```

> - `license.key` 由软件供应方根据您的机器码签发，**仅限本机使用**
> - 若缺失该文件，软件启动后会提示"授权无效"
> - 文件名必须为 `license.key`，不可改名

### 2.3 第三步：双击启动

1. 双击 `CSAM_Repair.exe` 启动软件
2. 首次启动需等待 5–10 秒（软件正在初始化）
3. 主界面出现后即可开始使用

> 也可双击 `启动软件.bat` 启动，效果相同。

### 2.4 后续使用

- 之后每次使用，直接双击 `CSAM_Repair.exe` 即可
- 软件关闭后再次启动，之前的工程文件不会丢失（保存在用户数据目录）
- 如需升级版本，删除旧文件夹，解压新版本，重新放置 `license.key` 即可

## 3. 目录结构说明

便携版解压后的目录结构如下：

```
CSAM_Repair\                        # 软件根目录（解压位置可自定义）
├── CSAM_Repair.exe                 # 主程序（双击启动）
├── 启动软件.bat                     # 启动脚本（双击效果同 EXE）
├── 使用说明.txt                     # 快速上手说明（如有）
└── config\                         # 配置目录
    ├── license.key                 # 授权文件（用户提供）
    ├── public_key.pem              # 授权验证公钥（随软件发布，勿删）
    └── calibration_db.json         # 标定配置（随软件发布，一般勿改）
```

### 各文件说明

| 文件 | 作用 | 是否可删除 |
|------|------|-----------|
| `CSAM_Repair.exe` | 主程序，软件核心 | 否 |
| `启动软件.bat` | 启动脚本，等同于双击 EXE | 是（不影响使用） |
| `config/license.key` | 授权文件，绑定本机 | 否（缺失则无法启动） |
| `config/public_key.pem` | 授权验证公钥 | 否 |
| `config/calibration_db.json` | 标定参数配置 | 一般不删（可由工程师修改） |

> **重要**：请勿删除或修改 `config` 文件夹中的任何文件，除非工程师明确指示。

## 4. 数据存储位置

便携版虽解压在任意位置，但**用户数据统一保存在系统标准目录**，便于备份与管理。

### 4.1 数据根目录

```
%APPDATA%\CSAM_Repair\
```

即 `C:\Users\<用户名>\AppData\Roaming\CSAM_Repair\`

> 查看方法：在文件资源管理器地址栏输入 `%APPDATA%\CSAM_Repair` 并回车。

### 4.2 子目录说明

```
%APPDATA%\CSAM_Repair\
├── projects\               # 工程文件（.csam）
├── exports\                # 导出文件
│   ├── gcode\              # G-code 机器人程序（.nc / .gcode）
│   ├── pdf\                # PDF 修复报告
│   └── stl\                # 导出的 STL 模型
├── logs\                   # 运行日志
│   ├── app.log             # 主日志
│   ├── error.log           # 错误日志
│   └── crash_*.log         # 崩溃日志（如有）
├── recovery\               # 自动保存与恢复快照
└── cache\                  # 临时缓存（可定期清理）
```

### 4.3 数据目录说明

| 目录 | 内容 | 说明 |
|------|------|------|
| `projects\` | `.csam` 工程文件 | 保存修复任务参数与状态 |
| `exports\gcode\` | G-code 文件 | 供机器人执行的运动程序 |
| `exports\pdf\` | PDF 报告 | 修复过程与结果的归档报告 |
| `exports\stl\` | STL 模型 | 修复前后的模型文件 |
| `logs\` | 日志文件 | 排查问题时优先查看 `app.log` |
| `recovery\` | 自动恢复快照 | 异常退出后可恢复未保存的工作 |
| `cache\` | 临时缓存 | 可定期清理，不影响软件运行 |

### 4.4 数据备份建议

- **重要数据**：`projects\` 与 `exports\` 建议定期备份
- **日志**：`logs\` 出现问题时提供给技术支持
- **缓存**：`cache\` 可随时删除，软件会自动重建

### 4.5 自定义数据目录（高级）

如需将数据存放到其他位置（如 D 盘），可设置环境变量：

```
CSAM_USER_DATA=D:\CSAM_Data
```

设置方法：系统属性 → 环境变量 → 新建用户变量。

## 5. 便携版限制

便携版在便捷性方面有优势，但存在以下限制：

### 5.1 无开始菜单快捷方式

- 便携版**不会**在开始菜单或桌面创建快捷方式
- 每次启动需进入软件文件夹双击 `CSAM_Repair.exe`
- **解决方法**：手动右键 `CSAM_Repair.exe` → 发送到 → 桌面快捷方式

### 5.2 需手动关联文件类型

- 便携版**不会**关联 `.csam` 工程文件
- 双击 `.csam` 文件不会自动用本软件打开
- **解决方法**：右键 `.csam` 文件 → 打开方式 → 选择 `CSAM_Repair.exe` → 勾选"始终使用此应用"

### 5.3 无自动更新

- 便携版**不会**自动检测与安装更新
- 需手动从供应方获取新版本 ZIP 包
- 升级时需手动替换文件夹，并重新放置 `license.key`

### 5.4 其他限制

- **首次启动较慢**：需 5–10 秒解压临时文件
- **路径限制**：软件所在路径建议不含中文和空格，避免部分组件异常
- **杀毒软件误报**：部分杀毒软件可能对 UPX 压缩的 EXE 误报，请加入信任白名单
- **VC 运行时依赖**：极少数精简版 Windows 缺少 VC 运行时，需安装 [VC Redist 2015-2022](https://aka.ms/vs/17/release/vc_redist.x64.exe)

> 如需开始菜单快捷方式、文件关联、自动更新等功能，请向发布工程师索取**安装版 EXE**。

## 6. 常见问题

### Q1：双击 EXE 后没反应？

- 等待 10 秒（首次启动较慢）
- 打开任务管理器，确认 `CSAM_Repair.exe` 进程是否在运行
- 查看 `%APPDATA%\CSAM_Repair\logs\app.log` 是否有错误记录
- 安装 [VC Redist 2015-2022](https://aka.ms/vs/17/release/vc_redist.x64.exe) 后重试

### Q2：提示"授权无效"？

- 确认 `config\license.key` 文件存在
- 确认 `license.key` 是为本机签发的（绑定机器码）
- 联系软件供应方，提供本机机器码，重新签发 License

### Q3：软件可以打开，但路径规划功能报错？

- 路径规划需要 MATLAB 算法引擎支持
- 确认本机已安装 MATLAB R2025b（或 R2024b+）及相关 Toolbox
- 软件会自动启动 MATLAB Bridge，无需手动操作
- 若无 MATLAB，软件会自动降级到 Python 启发式算法（精度略低）

### Q4：导出的文件在哪里？

- 所有导出文件保存在 `%APPDATA%\CSAM_Repair\exports\` 下
- G-code 在 `exports\gcode\`
- PDF 报告在 `exports\pdf\`
- STL 模型在 `exports\stl\`
- 也可在软件内"文件 → 打开导出目录"直接定位

### Q5：如何完全卸载？

1. 删除软件文件夹（解压目录）
2. 删除 `%APPDATA%\CSAM_Repair\` 目录（如需清除所有数据）
3. 卸载完成，无残留
