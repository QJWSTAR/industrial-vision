# CSAM Repair v1.0 部署指南

面向运维人员。版本：1.0.0 | 发布日期：2026-07-15。

本指南覆盖从环境准备到首次运行验证的完整部署流程。

---

## 1. 系统要求

### 1.1 操作系统

| 平台 | 最低版本 | 备注 |
|------|---------|------|
| Windows | 10 (1903+) / 11 | 推荐生产环境，打包为单文件 EXE |
| macOS | 10.14 (Mojave)+ | 打包为 .app bundle，支持 Intel / Apple Silicon |
| Linux | Ubuntu 20.04+ / CentOS 8+ | 需安装 libegl1、libxkbcommon-x11-0 |

### 1.2 Python 运行环境

- 版本：Python 3.10 - 3.12（CI 矩阵全覆盖）
- 源码运行需要；EXE / 便携版无需单独安装 Python

### 1.3 MATLAB 运行环境

- 版本：MATLAB R2024b 或更高（推荐 R2025b）
- 向下兼容至 R2022a
- 必需 Toolbox：
  - MATLAB (核心)
  - Curve Fitting Toolbox（形貌预测插值）
  - Statistics and Toolbox（部分算法统计）
- MATLAB 必须加入系统 PATH，或部署时通过 `matlab_bridge_server.m` 指定路径

### 1.4 硬件建议

| 项目 | 最低 | 推荐 |
|------|------|------|
| CPU | 4 核 | 8 核+ |
| 内存 | 8 GB | 16 GB+ |
| 磁盘 | 5 GB（含 MATLAB 算法缓存） | 20 GB SSD |
| GPU | 不强制 | 支持 OpenGL 3.3（可视化更流畅） |

### 1.5 网络端口

- 默认 ZMQ 端口：`5555`（Windows） / IPC socket（macOS/Linux）
- 本机回环通信，默认不对外网开放

## 2. 安装方式

### 2.1 方式 A：源码安装（开发 / 自定义部署）

适合需要二次开发或深度定制的场景。

```powershell
# 1. 克隆代码
git clone <repo-url> industrial-vision
cd industrial-vision

# 2. 创建虚拟环境
python -m venv .venv
.\.venv\Scripts\Activate.ps1   # Windows
# source .venv/bin/activate    # macOS/Linux

# 3. 安装依赖
python -m pip install --upgrade pip
pip install -e ".[dev]"

# 4. 启动软件
python run_app.py
```

### 2.2 方式 B：EXE 安装包（推荐生产环境）

适合最终用户机器，无需 Python 环境。

1. 从发布渠道获取 `CSAM_Repair.exe`（单文件可执行）
2. 复制到目标目录（如 `C:\Program Files\CSAM_Repair\`）
3. 双击运行，或创建桌面快捷方式
4. 首次运行会在 `%APPDATA%\CSAM_Repair\` 自动创建用户数据目录

> EXE 打包参数：`console=False`（无控制台窗口）、`disable_windowed_traceback=True`（不向用户暴露 Python Traceback）。

### 2.3 方式 C：便携版

适合 U 盘携带、免安装场景。

1. 解压便携版压缩包到任意目录
2. 运行目录内的 `CSAM_Repair.exe`
3. 用户数据写入 EXE 同级的 `user_data/` 目录（不污染系统目录）

## 3. 环境变量配置

复制项目根目录的 `.env.example` 为 `.env` 并按需修改，或直接通过系统环境变量设置。

### 3.1 核心环境变量（必读）

| 变量名 | 说明 | 默认值 | 示例 |
|--------|------|--------|------|
| `CSAM_ALGORITHM_ENGINE` | 算法引擎选择 | `matlab` | `python`（调试用） |
| `CSAM_ZMQ_ADDRESS` | ZMQ 通信地址 | Windows: `tcp://127.0.0.1:5555`<br>macOS/Linux: `ipc:///tmp/csam_engine` | `tcp://127.0.0.1:5555` |
| `CSAM_HMAC_SECRET` | License HMAC 密钥 | 开发模式回退密钥（生产必填） | `csam_prod_secret_xxx` |
| `CSAM_LOG_LEVEL` | 日志级别 | `INFO` | `DEBUG` / `WARNING` / `ERROR` |
| `CSAM_USER_DATA` | 用户数据目录覆盖 | 打包：`%APPDATA%\CSAM_Repair`<br>开发：项目根 `user_data/` | `D:\CSAM_Data` |

### 3.2 Bridge 通信层（可选调优）

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `CSAM_BRIDGE_TIMEOUT_MS` | 请求超时（毫秒） | 30000 |
| `CSAM_BRIDGE_CONNECT_MS` | 连接超时（毫秒） | 5000 |
| `CSAM_BRIDGE_HEALTH_MS` | 健康检查超时（毫秒） | 2000 |
| `CSAM_BRIDGE_HEARTBEAT_MS` | 心跳间隔（毫秒） | 2000 |
| `CSAM_BRIDGE_HEARTBEAT_MISS` | 心跳丢失阈值 | 3 |
| `CSAM_BRIDGE_MAX_RETRIES` | 最大重试次数 | 3 |
| `CSAM_BRIDGE_RETRY_MS` | 重试初始间隔（毫秒） | 200 |
| `CSAM_BRIDGE_LATENCY_LOG_MS` | 延迟告警阈值（毫秒） | 5000 |

### 3.3 MATLAB 执行平台（可选调优）

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `CSAM_MATLAB_BIND` | MATLAB Server 监听地址 | `tcp://*:5570` |
| `CSAM_MATLAB_HOST` | MatlabEngine 连接主机 | `127.0.0.1` |
| `CSAM_MATLAB_PORT` | MatlabEngine 连接端口 | `5570` |
| `CSAM_MATLAB_LOG_DIR` | MATLAB Server 日志目录 | `./logs` |
| `CSAM_MATLAB_HEARTBEAT_MS` | MATLAB Server 心跳间隔 | 1000 |
| `CSAM_ENGINE_DISABLE_MATLAB` | 设为 1 禁用 MATLAB（降级到 Python 原型） | 0 |

### 3.4 引擎生命周期监控（可选调优）

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `CSAM_HEARTBEAT_INTERVAL_MS` | 客户端心跳间隔 | 2000 |
| `CSAM_HEARTBEAT_TIMEOUT_MS` | 心跳探测超时 | 3000 |
| `CSAM_HEARTBEAT_MISS_THRESHOLD` | 心跳丢失阈值（触发重连） | 3 |
| `CSAM_RECONNECT_MAX_ATTEMPTS` | 最大重连尝试次数 | 10 |

## 4. License 部署

软件采用 **HMAC + RSA 公钥 + 机器码绑定** 三重验证机制。

### 4.1 所需文件

| 文件 | 位置 | 说明 |
|------|------|------|
| `license.key` | 用户配置目录 | License 授权文件（JSON 格式，含签名） |
| `public_key.pem` | 打包内置（`_MEIPASS` 只读） | RSA-2048 公钥，验证签名 |

### 4.2 文件放置位置

**打包环境（EXE）：**

- `public_key.pem` 已内置于 EXE，从 `_MEIPASS` 只读加载，无需手动放置
- `license.key` 放置在用户配置目录：
  - Windows：`%APPDATA%\CSAM_Repair\config\license.key`
  - macOS：`~/Library/Application Support/CSAM_Repair/config/license.key`
  - Linux：`~/.local/share/CSAM_Repair/config/license.key`

**开发环境（源码）：**

- `public_key.pem` 放在项目根 `config/public_key.pem`
- `license.key` 放在项目根 `config/license.key`

### 4.3 部署步骤

1. 在目标机器上首次启动软件（无需 license，会进入试用 / 报错状态）
2. 从软件 "关于" 对话框或日志中获取本机机器码（UUID 格式）
3. 将机器码提交给授权方签发 `license.key`
4. 将签发的 `license.key` 复制到上述用户配置目录
5. 重启软件，确认授权状态变为 "已授权"

### 4.4 关键约束

- 公钥**只从内置只读目录加载**，不接受用户目录替换（防篡改）
- License 绑定机器码（MAC 地址 + 主机名哈希），换机需重新签发
- 到期前 7 天软件会提示续期
- 生产环境必须设置 `CSAM_HMAC_SECRET`，否则启动时会有显著警告

## 5. MATLAB 部署

### 5.1 版本要求

- 最低：MATLAB R2022a
- 推荐：MATLAB R2025b（CI 验证主版本）
- 任务背景要求：R2024b+

### 5.2 必需 Toolbox

| Toolbox | 用途 |
|---------|------|
| MATLAB | 核心运行时 |
| Curve Fitting Toolbox | 形貌预测插值 |
| Statistics and Machine Learning Toolbox | 部分统计算法 |

### 5.3 自动启动说明

软件**无需用户手动打开 MATLAB**。点击 "开始计算" 时，`MatlabBridgeLauncher` 自动完成：

1. 查找系统 PATH 中的 MATLAB 可执行文件（优先 R2025b 及接近版本）
2. 以 `-nodesktop -nosplash -r` 模式启动 MATLAB，自动运行 `matlab_bridge_server.m`
3. 等待 Bridge 端口就绪（默认超时 120 秒）
4. 软件退出时自动关闭 MATLAB 进程
5. MATLAB 崩溃时自动检测并重启（最多 3 次）

### 5.4 MATLAB 算法脚本部署

以下脚本必须可被 MATLAB 访问（打包环境已内置）：

- `matlab_bridge_server.m`（项目根，Bridge 服务端）
- `path_planning/`（路径规划算法）
- `profile_prediction/`（形貌预测算法）

**源码环境**：保持项目根目录结构不变即可。
**打包环境**：这些文件已通过 PyInstaller `datas` 内置到 EXE。

### 5.5 验证 MATLAB 可用性

```powershell
# 检查 MATLAB 是否在 PATH
matlab -batch "disp('MATLAB OK')"

# 检查版本
matlab -batch "version"
```

## 6. 日志位置与轮转策略

### 6.1 日志目录

| 环境 | 日志目录 |
|------|---------|
| 打包（Windows） | `%APPDATA%\CSAM_Repair\logs\` |
| 打包（macOS） | `~/Library/Application Support/CSAM_Repair/logs/` |
| 打包（Linux） | `~/.local/share/CSAM_Repair/logs/` |
| 开发环境 | `<项目根>\logs\` |
| 自定义 | `$CSAM_USER_DATA\logs\` |

### 6.2 日志文件

| 文件 | 说明 | 级别 |
|------|------|------|
| `app_YYYY-MM-DD.log` | 应用主日志 | INFO+ |
| `error_YYYY-MM-DD.log` | 错误专用日志 | ERROR+ |
| `structured_YYYY-MM-DD.jsonl` | 结构化日志（可选） | INFO+ |
| `crash_*.log` | 崩溃转储 | - |

### 6.3 轮转策略

- 单文件上限：**10 MB**（达到后自动滚动新文件）
- 保留时长：
  - `app_*.log`：30 天
  - `error_*.log`：60 天
- 压缩：滚动后自动 zip 压缩
- 日志库：loguru（结构化，支持 enqueue 线程安全）

## 7. 防火墙配置

### 7.1 ZMQ 端口

默认 Windows 通信端口 **5555**（TCP，本机回环）。

### 7.2 Windows 防火墙规则

若部署在受控环境或需要远程 MATLAB 节点，需放行端口：

```powershell
# 放行 5555 入站（仅本机回环默认无需配置）
New-NetFirewallRule -DisplayName "CSAM Repair ZMQ" `
  -Direction Inbound -Protocol TCP -LocalPort 5555 `
  -Action Allow -Profile Domain

# MATLAB Engine 端口（若启用远程引擎）
New-NetFirewallRule -DisplayName "CSAM MATLAB Engine" `
  -Direction Inbound -Protocol TCP -LocalPort 5570 `
  -Action Allow -Profile Domain
```

### 7.3 Linux iptables

```bash
# 放行 ZMQ 端口
sudo iptables -A INPUT -p tcp --dport 5555 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 5570 -j ACCEPT
```

### 7.4 安全建议

- 生产环境**仅放行本机回环**（`127.0.0.1`），不对外网开放
- 如需远程 MATLAB，使用 VPN 或专用网络隔离
- ZMQ 通信未加密，跨网络传输需额外加固

## 8. 首次运行验证步骤

部署完成后，按以下步骤验证软件可用性。

### 8.1 启动验证

1. 双击 `CSAM_Repair.exe`（或源码环境执行 `python run_app.py`）
2. 等待主窗口出现（首次启动可能稍慢，需初始化日志和路径）
3. 检查标题栏显示版本号 `1.0.0`

### 8.2 License 验证

1. 打开 "关于" 对话框
2. 确认 License 状态为 "已授权"
3. 确认授权用户名、到期日期正确

### 8.3 MATLAB 连接验证

1. 加载一个测试 STL 文件
2. 点击 "开始计算"
3. 观察日志目录 `logs\app_YYYY-MM-DD.log` 中是否出现：
   - `MATLAB 启动成功` / `Bridge 端口就绪`
   - 无 `MATLAB 连接失败` 错误
4. 确认计算结果正常返回

### 8.4 导出验证

1. 计算完成后，尝试导出 G-code
2. 确认导出文件出现在 `%APPDATA%\CSAM_Repair\exports\gcode\`
3. 打开导出文件确认内容完整

### 8.5 日志验证

1. 检查 `logs\` 目录下是否生成 `app_*.log`
2. 确认日志级别符合 `CSAM_LOG_LEVEL` 设置
3. 检查是否有 `error_*.log`（正常情况应为空或少量历史记录）

### 8.6 退出验证

1. 正常关闭软件
2. 确认 MATLAB 进程已自动清理（任务管理器查看）
3. 确认无僵尸进程残留

## 附录：常见部署问题

| 现象 | 排查方向 |
|------|---------|
| 启动即闪退 | 检查 `logs\error_*.log`；确认 `CSAM_HMAC_SECRET` 已设置 |
| License 验证失败 | 确认 `license.key` 在用户配置目录；检查机器码是否匹配 |
| MATLAB 连接超时 | 确认 MATLAB 在 PATH；查看 `launcher_startup_timeout_sec` 配置 |
| ZMQ 连接被拒 | 检查防火墙端口 5555；确认无端口占用 |
| 导出目录无文件 | 检查 `%APPDATA%\CSAM_Repair\exports\` 权限 |

更多问题参考 `docs\FAQ\常见问题.md` 和 `docs\调试指南\故障排查.md`。
