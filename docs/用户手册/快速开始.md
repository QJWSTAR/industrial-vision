# 快速开始

> **版本**：1.0.0（Stable Release） ｜ **协议**：v2.1（ZeroMQ + Protocol Buffers） ｜ **更新日期**：2026-07-15

本指南帮助你在 5 分钟内从零开始运行 CSAM Repair（冷喷涂增材制造缺陷修复软件），并完成一次完整的路径规划。无需任何编程经验，跟着步骤操作即可。

---

## 5 分钟快速开始

### 前置条件

开始前请确认你的电脑已经具备以下条件：

| 条件 | 要求 |
|------|------|
| 操作系统 | Windows 10/11、macOS 10.14+ 或 Linux |
| Python（Python 解释器） | 3.10 及以上（推荐 3.12） |
| 硬盘空间 | 至少 5 GB |
| 网络 | 首次安装依赖需要联网 |

> 如果你还没有安装 Python，请前往 [python.org](https://www.python.org/downloads/) 下载 3.12 版本。安装时务必勾选 **"Add Python to PATH"**。

### 第 1 步：克隆仓库

打开终端（Windows 用 PowerShell，macOS/Linux 用 Terminal），执行以下命令获取项目代码：

```bash
git clone <repository-url>
cd <project-directory>
```

> 如果从公司内部服务器获取，直接复制整个项目文件夹到本地即可。

### 第 2 步：创建虚拟环境

"虚拟环境"是软件专用的独立运行空间，不会影响电脑上的其他程序。建议使用。

**Windows（PowerShell）：**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**macOS / Linux：**

```bash
python3 -m venv venv
source venv/bin/activate
```

激活成功后，命令行最前面会出现 `(venv)` 字样。

> **Windows 报错"无法加载文件"**：执行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，按 Y 确认后重试。

### 第 3 步：安装依赖

升级 pip 后安装软件所需的所有组件（PySide6、numpy、scipy、matplotlib、shapely、pyzmq、protobuf、reportlab、cryptography 等）：

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

这一步会下载较多内容，可能需要几分钟，请耐心等待。看到 `Successfully installed ...` 即表示成功。

### 第 4 步：运行软件

```bash
python run_app.py
```

如果你已经将软件安装为系统命令，也可以直接执行：

```bash
csam-repair
```

**成功标志**：窗口标题显示"冷喷涂缺陷修复工作流"，左侧栏出现工作流步骤与操作按钮，中间是空白的 3D 视图区域，底部状态栏显示"路径规划 — 加载点云并选取缺陷区域后生成路径"。

## 加载演示数据

软件内置演示数据，无需外部文件即可上手体验。

1. 在左侧栏点击 **"📂 加载点云"** 按钮
2. 弹出文件选择对话框后，**点击"取消"** 关闭对话框
3. 弹出提示框"未选择文件。是否加载内置演示数据？"
4. **点击"是"**

**成功标志**：

- 3D 视图区域出现零件的三维点云图
- 底部状态栏显示"演示数据已加载 (xxxx 点)"
- 右侧栏"点云信息"显示点数
- 左侧栏出现选取工具

## 完成一次路径规划

### 选取缺陷

1. 在 3D 视图上方的工具栏中，点击 **"🧭 导航模式"** 按钮，切换到 **"✂️ 选取模式"**
2. 在"模式"下拉框中选择 **"矩形框选"**
3. 在 3D 视图中，按住鼠标左键从左上角拖到右下角，框住零件中间有凹陷的缺陷区域
4. 被选中的区域会变成红色高亮

> **如果选少了**：点击"✕ 清除选区"重新框选。
> **如果想补充**：切换到"区域选择"模式，用笔刷涂抹添加。

**成功标志**：选中了一块红色高亮区域，右侧栏"已选"显示的点数大于 3。

### 选择材料

1. 在左侧栏找到"材料选择"分组
2. 点击材料下拉框，选择 **"316L 不锈钢"**（最常用的修复材料，默认选择）
3. 下拉框下方显示材料信息，如"v_cr: 600 m/s | 密度: 7980 kg/m³"

### 生成修复路径

1. 确认"路径规划参数"保持默认值（新手不用修改）：
   - 层高：2.0 mm
   - 扫描角度：-45.0 °
   - 扫描步长：2.0 mm
   - 规划层数：10
2. 点击 **"🔧 生成修复路径"** 按钮
3. 等待计算完成（通常 5-30 秒）

> 将鼠标悬停在任意参数上可查看工具提示说明。

**计算过程中**：

- 底部状态栏显示"路径规划中..."
- 右侧栏进度条显示进度

**成功标志**：

- 3D 视图中出现绿色/蓝色的路径线条
- 弹出提示框"路径规划完成"
- 左侧栏"01 数据与路径"变成"✓ 01 数据与路径"

### 导出 G-code（可选）

1. 点击 **"📤 导出 G-code"** 按钮
2. 选择保存位置，文件名保持默认 `repair.nc`
3. 点击"保存"
4. 弹出提示"G-code 已保存: xxx"

恭喜！你已经完成了一次完整的路径规划。生成的 G-code 文件可以直接用于数控加工设备。

## MATLAB 集成（自动）

软件支持 MATLAB R2025b 作为工业算法引擎，可获得更精确的路径规划与形貌预测结果。

### 自动启动

软件启动时会**自动**拉起 MATLAB 会话，用户无需手动操作：

- 启动 Python GUI 后，后台自动初始化 MATLAB Bridge（以无界面模式启动 MATLAB）
- MATLAB 监听 `tcp://127.0.0.1:5555`
- 执行路径规划/形貌预测时，GUI 通过 Bridge 自动调用 MATLAB 算法
- MATLAB 不可用时自动降级到 Python 启发式算法，流程不中断

### 环境要求（仅首次部署需要）

- MATLAB R2025b（推荐）或 R2024b+
- 安装 MATLAB Engine API for Python（随 MATLAB 自动安装）
- Mapping Toolbox（路径规划算法需要）
- Curve Fitting Toolbox（粒子拟合算法需要）

> 详细的 MATLAB 集成说明、参数配置与验证步骤，请参阅 [算法说明.md](../MATLAB集成/算法说明.md)。
