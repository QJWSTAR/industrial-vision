## 软件简介

**CSAM 冷喷涂缺陷修复软件** 是一款面向冷喷涂增材制造（Cold Spray Additive Manufacturing）缺陷修复场景的工业软件。它将三维点云缺陷选区、路径规划、形貌预测与工艺交付集成在统一工作流中，支持本地计算引擎与远程 MATLAB 算法服务器双模式。

- **应用层**：Python + PySide6 桌面 GUI
- **算法层**：MATLAB R2025b 长驻算法服务器（19 个注册算法）
- **通信层**：ZeroMQ + Protocol Buffers 桥接架构（**已定稿，唯一生产路径**）
- **协议**：v2.1（Protobuf，生产路径）。v3.0（TCP/JSON）已弃用，详见 [COMMUNICATION.md](COMMUNICATION.md)
