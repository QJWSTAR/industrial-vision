## 1. 系统架构图

展示从 UI 到 MATLAB 算法层的完整分层。UI 层通过 `CoordinationService` 中介访问下层，不直接接触 `core/` 或 `communication/`。

```
┌─────────────────────────────────────────────────────────────────────┐
│                         UI 层 (PySide6)                              │
│   repair_app/ui/  (MainWindow, panels, workers, visualizer)          │
│   ↓ 唯一入口：CoordinationService（不直接调 core/communication）      │
└────────────────────────────────┬────────────────────────────────────┘
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────────────┐
│                    服务层 (CoordinationService)                      │
│   repair_app/service/coordination_service.py                        │
│   静态中介：build_repair_request / parse_repair_result / create_*    │
└──────────────┬──────────────────────────────────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────────────────────────────────┐
│                   通信层 (Bridge / Legacy)                            │
│   bridge/adapters/legacy_adapter   (LegacyZmqClient)                  │
│   bridge/communication/zmq_client  (BridgeClient)                     │
│   bridge/communication/config      (BridgeConfig)                     │
│   bridge/communication/exceptions  (BridgeError 层次)                 │
│   bridge/services/matlab_service   (MatlabService 门面，未接入 GUI)    │
└──────────────┬──────────────────────────────────────────────────────┘
               │ ZMQ REQ/REP, tcp://127.0.0.1:5555
               ▼
┌─────────────────────────────────────────────────────────────────────┐
│                   MATLAB 算法层                                       │
│   matlab_bridge_server.m  (MATLAB 宿主脚本，通过 pyenv 调用 Python)    │
│   MatlabAdapter (BridgeServer 子类，处理修复请求)                      │
│   MatlabEngineProxy (matlab.engine 单例，连接共享会话)                 │
│   形貌预测\ (path_planning.*)  /  路径规划\ (morphology.*)            │
│   run_path_planning.m / run_profile_prediction.m                     │
│   标定在 Python 侧 config/calibration_db.json（不在 MATLAB）           │
└─────────────────────────────────────────────────────────────────────┘
               │ 降级（MATLAB 不可用时）
               ▼
┌─────────────────────────────────────────────────────────────────────┐
│                   核心层 (Python 原型，降级用)                         │
│   core/path_planner.py             (路径规划原型)                      │
│   core/morphology_predictor.py     (形貌预测原型)                      │
│   core/feasibility_checker.py      (可行性检查)                        │
│   core/normal_estimator.py         (法向量估计)                        │
│   core/material_database.py        (材料数据库)                        │
│   engine/local_engine.py           (LocalEngine 降级引擎)              │
└─────────────────────────────────────────────────────────────────────┘
```

**分层说明**

| 层 | 主要职责 | 关键模块 |
| --- | --- | --- |
| UI 层 | 用户交互、可视化、任务调度 | `repair_app/ui/` |
| 服务层 | 中介 UI 与底层，屏蔽实现细节 | `CoordinationService` |
| 通信层 | ZMQ v2.1 Protobuf（唯一路径） | `bridge/` |
| MATLAB 算法层 | `matlab_bridge_server.m` + `MatlabAdapter` + 算法函数 | `matlab_bridge_server.m` / `MatlabAdapter` / `MatlabEngineProxy` |
| 核心层 | Python 原型算法（路径规划、形貌预测、可行性），降级用 | `core/` / `engine/local_engine.py` |

## 3. 通信流程图

系统使用单一通信路径：ZMQ v2.1 Protobuf。

### 3.1 通信流程

```
┌─────────┐   1. 用户操作     ┌──────────────────────┐
│  GUI    │ ───────────────▶ │ CoordinationService   │
│MainWindow│                  │ .create_zmq_client() │
└─────────┘                  └──────────┬───────────┘
                                        │ 2. 返回客户端
                                        ▼
                            ┌──────────────────────┐
                            │  LegacyZmqClient     │
                            │ (bridge/adapters/)    │
                            └──────────┬───────────┘
                                        │ 3. 委托
                                        ▼
                            ┌──────────────────────┐
                            │    BridgeClient       │
                            │(bridge/communication/ │
                            │   zmq_client.py)      │
                            └──────────┬───────────┘
                                        │ 4. 投递到线程
                                        ▼
                            ┌──────────────────────┐
                            │   _RequestWorker     │
                            │    (QThread)          │
                            └──────────┬───────────┘
                                        │ 5. zmq.REQ socket
                                        ▼
                            ┌──────────────────────┐
                            │  tcp://127.0.0.1:5555│
                            │  (ZMQ v2.1 Protobuf) │
                            └──────────┬───────────┘
                                        │ 6. 进 MATLAB 宿主
                                        ▼
                            ┌──────────────────────┐
                            │ matlab_bridge_server │
                            │       .m              │
                            └──────────┬───────────┘
                                        │ 7. pyenv 调用 Python
                                        ▼
                            ┌──────────────────────┐
                            │   MatlabAdapter      │
                            │ (BridgeServer 子类)   │
                            └──────────┬───────────┘
                                        │ 8. 调用算法
                                        ▼
                            ┌──────────────────────┐
                            │  MatlabEngineProxy   │
                            │ (matlab.engine 单例)  │
                            └──────────┬───────────┘
                                        │ 9. connect_matlab
                                        ▼
                            ┌──────────────────────┐
                            │   MATLAB 算法函数     │
                            │ run_path_planning.m  │
                            │ run_profile_         │
                            │   prediction.m       │
                            └──────────────────────┘
```

**特征**：协议 v2.1、Protobuf 序列化、端口 5555、GUI 生产路径。MATLAB 不可用时，MatlabAdapter 通过 `_invoke_with_fallback` 自动降级到 `LocalEngine`（Python 原型）。

| 端口 | 协议 | 用途 | 进程 |

### 4.3 跨平台传输地址

`platform/transport.py` 按操作系统选择传输地址：

```
┌──────────────────┐        ┌──────────────────────────┐
│   Windows        │        │   POSIX (Linux/macOS)    │
├──────────────────┤        ├──────────────────────────┤
│  tcp://127.0.0.1 │        │ ipc:///tmp/csam_engine   │
│  (TCP 回环)      │        │ (Unix 域套接字)          │
└──────────────────┘        └──────────────────────────┘
```

> 由环境变量 `CSAM_ZMQ_ADDRESS` 覆盖。详见 [09_API文档.md - BridgeConfig](./09_API文档.md#9-bridgeconfig)。

## 6. 关键架构决策

| 决策 | 说明 | 影响 |
| --- | --- | --- |
| Bridge 是唯一生产通信路径 | 旧版 `communication/` 已弃用但保留 | 兼容性回退，但代码冗余 |
| GUI 通过 CoordinationService 访问底层 | UI 不直接调用 `core/` / `communication/` | 解耦 UI 与实现，便于替换通信层 |
| MATLAB 通过 pyenv 宿主 Python | MATLAB 作为进程宿主启动 Python `MatlabAdapter`（`BridgeServer` 子类），共享引擎会话供反向调用 | MATLAB 与 Python 同进程，避免跨进程通信开销 |
| auto 模式降级策略 | MATLAB 不可用时 `MatlabAdapter` 通过 `_invoke_with_fallback` 自动降级到 `LocalEngine` Python 原型 | 保证生产连续性，由 `CSAM_ALGORITHM_ENGINE` 控制 |
| 标定置于 Python 侧 | `config/calibration_db.json` + `calibration_wizard.py` | MATLAB 保持纯计算，标定与 UI 同进程 |

## 7. 已知架构问题

| 问题 | 位置 / 证据 | 影响 |
| --- | --- | --- |
| MainWindow God Class | `repair_app/ui/main_window.py`（约 1898 行） | 单文件承担过多职责，难维护 |
| 通信层无自动重连 | `bridge/communication/zmq_client.py` | 连接断开后不会自动恢复，需用户重启操作 |
| 异常类型丢失 | `bridge/communication/zmq_client.py:279` | 底层异常未被翻译为结构化 `BridgeError`，业务层难以区分错误类型 |

> 异常类层次与翻译函数详见 [09_API文档.md - 异常类层次](./09_API文档.md#8-异常类层次)。
