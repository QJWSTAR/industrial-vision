## 1. 系统架构图

展示从 UI 到 MATLAB Server 的完整分层。UI 层通过 `CoordinationService` 中介访问下层，不直接接触 `core/` 或 `communication/`。

```
┌─────────────────────────────────────────────────────────────────────┐
│                         UI 层 (PySide6)                              │
│   repair_app/ui/  (MainWindow, panels, workers, visualizer)          │
│   ↓ 唯一入口：CoordinationService（不直接调 core/communication）      │
└────────────────────────────────┬────────────────────────────────────┘
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────────────┐
│                    服务层 (CoordinationService)                      │
│   repair_app/service/coordination_service.py                        │
│   静态中介：build_repair_request / parse_repair_result / create_*    │
└──────────────┬───────────────────────────────┬──────────────────────┘
               │ 生产路径 (Bridge)             │ 设计路径 (Engine)
               ▼                               ▼
┌──────────────────────────────────┐  ┌──────────────────────────────┐
│     通信层 (Bridge / Legacy)      │  │      引擎层 (EngineFactory)    │
│  bridge/adapters/legacy_adapter   │  │   engine/factory.py           │
│  bridge/communication/zmq_client  │  │   ├─ MatlabEngine (TCP v3.0)  │
│  bridge/communication/config      │  │   └─ LocalEngine  (Python)    │
│  bridge/communication/exceptions  │  │   domain/interfaces.py(IEngine)│
│  bridge/services/matlab_service   │  │                               │
│  bridge/protocol_v3/ (proto)      │  └──────────────┬───────────────┘
└──────────────┬───────────────────┘                 │
               │                                      ▼
               │                 ┌──────────────────────────────────┐
               │                 │      核心层 (Python 原型)          │
               │                 │  core/path_planner.py             │
               │                 │  core/morphology_predictor.py     │
               │                 │  core/feasibility_checker.py      │
               │                 │  core/normal_estimator.py         │
               │                 │  core/material_database.py        │
               │                 └──────────────────────────────────┘
               ▼
┌─────────────────────────────────────────────────────────────────────┐
│                       MATLAB Server 层                               │
│   matlab_server/ (server.m, dispatcher.m, registry.m, ...)           │
│   算法命名空间 csam.algorithm.v2 / 协议 v3.0                          │
│   形貌预测\ (path_planning.*)  /  路径规划\ (morphology.*)            │
│   标定在 Python 侧 config/calibration_db.json（不在 Server）          │
└─────────────────────────────────────────────────────────────────────┘
```

**分层说明**

| 层 | 主要职责 | 关键模块 |
| --- | --- | --- |
| UI 层 | 用户交互、可视化、任务调度 | `repair_app/ui/` |
| 服务层 | 中介 UI 与底层，屏蔽实现细节 | `CoordinationService` |
| 通信层 | ZMQ v2.1 Protobuf（生产）/ TCP v3.0 JSON（设计） | `bridge/` |
| 引擎层 | 引擎抽象与创建，双引擎策略 | `EngineFactory` / `MatlabEngine` / `LocalEngine` |
| 核心层 | Python 原型算法（路径规划、形貌预测、可行性） | `core/` |
| MATLAB Server 层 | 19 个生产算法、registry/dispatcher | `matlab_server/` |

## 3. 通信流程图

系统存在两条通信路径。

### 3.1 路径 A：ZMQ v2.1 Protobuf（端口 5555，GUI 实际使用）

```
┌─────────┐   1. 用户操作     ┌──────────────────────┐
│  GUI    │ ───────────────▶ │ CoordinationService   │
│MainWindow│                  │ .create_zmq_client() │
└─────────┘                  └──────────┬───────────┘
                                        │ 2. 返回客户端
                                        ▼
                            ┌──────────────────────┐
                            │  LegacyZmqClient     │
                            │ (bridge/adapters/)    │
                            └──────────┬───────────┘
                                        │ 3. 委托
                                        ▼
                            ┌──────────────────────┐
                            │    BridgeClient       │
                            │(bridge/communication/ │
                            │   zmq_client.py)      │
                            └──────────┬───────────┘
                                        │ 4. 投递到线程
                                        ▼
                            ┌──────────────────────┐
                            │   _RequestWorker     │
                            │    (QThread)          │
                            └──────────┬───────────┘
                                        │ 5. zmq.REQ socket
                                        ▼
                            ┌──────────────────────┐
                            │  tcp://127.0.0.1:5555│
                            │  (ZMQ v2.1 Protobuf) │
                            └──────────┬───────────┘
                                        │ 6. 进 MATLAB
                                        ▼
                            ┌──────────────────────┐
                            │ matlab_bridge_server │
                            │       .m              │
                            └──────────────────────┘
```

**特征**：协议 v2.1、Protobuf 序列化、端口 5555、GUI 当前生产路径。

### 3.2 路径 B：TCP v3.0 JSON（端口 5570，设计阶段未接 GUI）

```
┌──────────────┐   1. create_engine("matlab")   ┌──────────────────┐
│ EngineFactory│ ─────────────────────────────▶ │   MatlabEngine    │
└──────────────┘                                 │(engine/matlab_    │
                                                 │   engine.py)      │
                                                 └────────┬──────────┘
                                                          │ 2. 建链
                                                          ▼
                                               ┌──────────────────┐
                                               │   TcpChannel      │
                                               └────────┬──────────┘
                                                          │ 3. java.net.Socket
                                                          ▼
                                               ┌──────────────────┐
                                               │tcp://127.0.0.1   │
                                               │      :5570        │
                                               │(TCP v3.0 JSON)    │
                                               └────────┬──────────┘
                                                          │ 4. 进入 Server
                                                          ▼
                                               ┌──────────────────┐
                                               │ matlab_server/    │
                                               │  server.m         │
                                               └────────┬──────────┘
                                                          │ 5. 分发
                                                          ▼
                                               ┌──────────────────┐
                                               │   dispatcher.m    │
                                               └────────┬──────────┘
                                                          │ 6. 查表
                                                          ▼
                                               ┌──────────────────┐
                                               │    registry.m     │
                                               └────────┬──────────┘
                                                          │ 7. 执行
                                                          ▼
                                               ┌──────────────────┐
                                               │   算法函数句柄     │
                                               │ (path_planning.* /│
                                               │  morphology.*)    │
                                               └──────────────────┘
```

**特征**：协议 v3.0、JSON 序列化、端口 5570、设计阶段、GUI 未接入。

### 3.3 两条路径对比

| 维度 | 路径 A（生产） | 路径 B（设计） |
| --- | --- | --- |
| 协议 | ZMQ v2.1 | TCP v3.0 |
| 序列化 | Protobuf | JSON |
| 端口 | 5555 | 5570 |
| 入口 | `CoordinationService.create_zmq_client()` | `EngineFactory.create_engine("matlab")` |
| 服务端 | `matlab_bridge_server.m` | `matlab_server/server.m` |
| GUI 接入 | ✅ 是 | ❌ 否 |
| 自动重连 | ❌ 无 | — |

### 4.3 跨平台传输地址

`platform/transport.py` 按操作系统选择传输地址：

```
┌──────────────────┐        ┌──────────────────────────┐
│   Windows        │        │   POSIX (Linux/macOS)    │
├──────────────────┤        ├──────────────────────────┤
│  tcp://127.0.0.1 │        │ ipc:///tmp/csam_engine   │
│  (TCP 回环)      │        │ (Unix 域套接字)          │
└──────────────────┘        └──────────────────────────┘
```

> 由环境变量 `CSAM_ZMQ_ADDRESS` 覆盖。详见 [09_API文档.md - BridgeConfig](./09_API文档.md#9-bridgeconfig)。

## 6. 关键架构决策

| 决策 | 说明 | 影响 |
| --- | --- | --- |
| Bridge 是唯一生产通信路径 | 旧版 `communication/` 已弃用但保留 | 兼容性回退，但代码冗余 |
| GUI 通过 CoordinationService 访问底层 | UI 不直接调用 `core/` / `communication/` | 解耦 UI 与实现，便于替换通信层 |
| 双引擎策略 | `LocalEngine`（Python 原型）+ `MatlabEngine`（生产） | 原型可独立验证，生产用 MATLAB 算法 |
| MATLAB Server 无 ZMQ 依赖 | Server 用 `java.net.ServerSocket` | MATLAB 侧零第三方依赖，部署简单 |
| 协议 v3.0 通用算法协议 | 不绑定业务（路径规划/形貌预测） | 算法自描述，可扩展新算法不改协议 |
| 标定置于 Python 侧 | `config/calibration_db.json` + `calibration_wizard.py` | MATLAB Server 保持纯计算，标定与 UI 同进程 |

## 7. 已知架构问题

| 问题 | 位置 / 证据 | 影响 |
| --- | --- | --- |
| MainWindow God Class | `repair_app/ui/main_window.py`（约 1898 行） | 单文件承担过多职责，难维护 |
| MatlabService 门面未接入 GUI | `bridge/services/matlab_service.py` | 门面代码存在但未被调用，形成死路径 |
| 路径 A 无自动重连 | `bridge/communication/zmq_client.py` | 连接断开后不会自动恢复，需用户重启操作 |
| 异常类型丢失 | `bridge/communication/zmq_client.py:279` | 底层异常未被翻译为结构化 `BridgeError`，业务层难以区分错误类型 |
| 版本不一致 | Server 自称 `matlab-server-3.0.0`，客户端 `matlab_server/1.0.0` | 版本协商与日志追踪混淆 |

> 异常类层次与翻译函数详见 [09_API文档.md - 异常类层次](./09_API文档.md#8-异常类层次)。
