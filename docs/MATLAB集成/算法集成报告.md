# MATLAB 原始算法集成报告

> 版本：1.0.0 | 协议：v2.1 | 更新日期：2026-07-14 | 文档语言：简体中文

> 本报告记录将生产环境从 Python Demo 算法正式切换到 MATLAB 原始算法的完整变更。
> MATLAB 成为唯一计算引擎，Python 仅负责通信、转换和展示。

---

## 一、变更概述

### 1.1 变更目标

- 不再调用 `repair_app/core/path_planner.py`（Python Demo 路径规划）
- 不再调用 `repair_app/core/morphology_predictor.py`（Python Demo 形貌预测）
- 真正调用 `path_planning/generate_path.m`（MATLAB 路径规划）
- 真正调用 `profile_prediction/profilePredict.m`（MATLAB 形貌预测）
- 保持 Bridge / Protocol / GUI 完全兼容

### 1.2 变更范围

| 类别 | 变更 |
|------|------|
| 目录重命名 | `形貌预测/` → `path_planning/`，`路径规划/` → `profile_prediction/` |
| 代码修改 | 5 个文件（matlab_bridge_server.m / matlab_engine_proxy.py / matlab_adapter.py / run_profile_prediction.m / release_validation.py） |
| 算法逻辑 | 未修改任何 MATLAB 算法 |
| 接口变化 | 无（Protobuf v2.1 协议不变） |

## 二、修改文件清单

### 2.1 目录重命名

| 旧路径 | 新路径 | 说明 |
|-------|-------|------|
| `形貌预测/` | `path_planning/` | 旧名"形貌预测"与内容（路径规划）不符 |

```python
# ... 使用 Python path_planner 计算 ...

# 修改后：MATLAB 不可用时返回错误，仅测试模式允许 Python
engine_mode = os.environ.get("CSAM_ALGORITHM_ENGINE", "auto").lower()
if engine_mode != "python":
    # 生产路径：MATLAB 不可用时直接报错，不降级到 Python Demo
    return self._build_error_result(
        request_id, RepairStatusCode.ERR_ALGORITHM_FAIL,
        "MATLAB 算法引擎不可用",
        "MATLAB 管线调用失败。生产路径要求 MATLAB 原始算法，"
        "不再降级到 Python Demo。请启动 MATLAB Bridge ...",
    )
# 仅 CSAM_ALGORITHM_ENGINE=python 时使用 Python（测试模式）
```

**原因**：用户要求"不再调用 Python Demo"，生产路径强制使用 MATLAB。
