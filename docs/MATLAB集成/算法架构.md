## 二、算法调用关系

### 2.1 路径规划调用图

```
run_path_planning(stl_path, params)
    │
    ├── read_stl_file(stl_path)
    │       └── 返回 N×12 三角形数组 [v1_xyz, v2_xyz, v3_xyz, normal_xyz]
    │
    ├── model_process(triangles, 1.0, 1e-8, base_plane)
    │       └── 返回 all_triangles, additive_cluster, repairing_clusters, 边界
    │
    ├── layer_slice(additive_cluster, repairing_clusters, layer_height, base_plane)
    │       └── 返回 additive_layerlist, repairing_layerlist
    │
    ├── generate_path(additive_layerlist, repairing_layerlist, ...)
    │       ├── aStarSearch(...)  ← 避障路径搜索
    │       └── 返回 pointlist(M×6), velocitylist(M×1), zonelist
    │
    ├── velocity_to_numeric(velocitylist, traversing_speed_mms)
    │       └── ABB 速度字符串 → 数值 (mm/s)
    │
    └── derive_layer_indices(pointlist, ...)
            └── 由 Z 值反推层号

输出：
  pointlist     : M×6  [x, y, z, nx, ny, nz]
  feed_rates    : M×1  进给速度 (mm/s)
  layer_indices : M×1  层号
  meta_out      : struct (waypoint_count, compute_time_s, ...)
```

### 2.2 形貌预测调用图

```
run_profile_prediction(stl_path, excel_path, params, pointlist_in, velocitylist_in)
    │
    ├── read_STLfile(stl_path)
    │       └── 返回 N×9 三角形数组 [v1_xyz, v2_xyz, v3_xyz]
    │
    ├── recursiveSubdivide(triangles, max_edge)
    │       └── 三角形递归细分
    │
    ├── improveShortEdges(triangles, [], threshold)
    │       └── 短边优化
    │
    ├── particleFitting(excel_path, standoff_distance)
    │       └── 返回 rays_indices, rays_origins, rays_directions,
    │                 rays_speeds, rays_possiLengths, rays_Vcr
    │
    ├── [若 pointlist_in 为空] run_path_planning(stl_path, params)
    │       └── 内部调用路径规划（预计算时跳过）
    │
    ├── spotInterp(ReferencePoint, pointlist, velocitylist, spot_step)
    │       └── 返回 spotsList (喷斑列表)
    │
    └── for i = 1:steps  ← 逐点形貌预测循环
            │
            ├── rayMove(spot, rays_origins, rays_directions)
            │       └── 移动射线到喷斑位置
            │
            ├── buildOctree(triangles, max_depth, max_tris)
            │       └── 构建八叉树
            │
            ├── batchOctreeFilter(octree, origins, directions)
            │       └── 过滤候选三角形
            │
            ├── ray_triangle_intersection(rays, origins, directions, triangles, candidates)
            │       └── 返回相交射线ID、三角形ID、交点
            │
            ├── classifyRemovedTriangles(triangles, intersected_tris, ...)
            │       └── 返回移除三角形ID、射线簇、边界顶点
            │
            └── profilePredict(triangles, removed, rays, ...)
                    └── 返回 oldTriangles, newTriangles
                    └── triangles = [old; new]  ← 更新网格

输出：
  mesh                 : N×9  最终沉积表面三角形
  substrate_triangles  : N×9  原始基体三角形
  layer_profiles       : L×4  [layer_idx, max_h, avg_h, dep_eff]
  particle_distribution : struct (px, py, vx, vy, vz, vcr, dep_eff, diameter, temperature)
  uniformity           : [0, 1]
  estimated_mass_g     : float
  estimated_time_s     : float
  predicted_volume_mm3 : float
  warnings             : cell array
```

### 2.3 MATLABPipeline 串联调用

```
MATLABPipeline.run(xyz, meta)
    │
    ├── 阶段 1：eng.run_path_planning(stl_path, params)
    │       └── 返回 pointlist, feed_rates, layer_indices
    │
    ├── 内存传递（不写文件）：
    │       pointlist → pointlist_in
    │       feed_rates → velocitylist（通过 _feed_rates_to_velocitylist 转换）
    │
    └── 阶段 2：eng.run_profile_prediction(stl_path, excel_path, params, pointlist_in, velocitylist_in)
            └── 传入预计算航点，跳过内部重复路径规划
            └── 返回完整形貌预测结果
```

## 三、完整数据流

### 3.1 GUI → Bridge → MATLAB → GUI 数据流

```
┌──────────────────────────────────────────────────────────────────┐
│ GUI（main_window.py）                                             │
│                                                                   │
│  用户点击"开始计算"                                                │
│  → 构造 RepairRequest (protobuf)                                  │
│      含 xyz 点云 + normals + 工艺参数                              │
└───────────────────────────┬──────────────────────────────────────┘
                            │ ZMQ REQ/REP (protobuf bytes)
                            ↓
┌──────────────────────────────────────────────────────────────────┐
│ Bridge（matlab_adapter.py）                                       │
│                                                                   │
│  handle_repair(request)                                           │
│  → parse_point_cloud(request) → xyz, normals, meta                │
│  → _invoke_pipeline_with_fallback(xyz, meta)                      │
│      → MATLABPipeline.run(xyz, meta)                              │
└───────────────────────────┬──────────────────────────────────────┘
                            │ matlab.engine API
                            ↓
┌──────────────────────────────────────────────────────────────────┐
│ MATLAB Engine Proxy（matlab_engine_proxy.py）                     │
│                                                                   │
│  call_full_pipeline(xyz, meta)                                    │
│                                                                   │
│  Python → MATLAB 输入转换：                                        │
│  ├── _write_xyz_as_stl(xyz) → 临时 STL 文件                       │
│  ├── _meta_to_profile_params(meta) → MATLAB struct dict           │
│  └── _feed_rates_to_velocitylist(feed_rates) → MATLAB string 数组 │
│                                                                   │
│  MATLAB 调用：                                                    │
│  ├── eng.run_path_planning(stl_path, params)  → 路径规划           │
│  │       ↓                                                        │
│  │    generate_path → aStarSearch                                 │
│  │       ↓                                                        │
│  │    pointlist (M×6), feed_rates (M×1), layer_indices (M×1)      │
│  │                                                                │
│  └── eng.run_profile_prediction(stl_path, excel, params,          │
│                                  pointlist, velocitylist)         │
│          ↓                                                        │
│       profilePredict → rayMove → buildOctree → ...                │
│          ↓                                                        │
│       mesh (N×9), layer_profiles (L×4), particle_dist,            │
│       uniformity, mass, time, warnings                            │
│                                                                   │
│  MATLAB 输出 → Python 转换：                                       │
│  ├── _parse_profile_result(raw) → Python dict                     │
│  │   ├── matlab.double → numpy.ndarray                            │
│  │   └── cell array → list[str]                                   │
│  └── _triangles_to_binary_stl(mesh) → STL bytes                   │
└───────────────────────────┬──────────────────────────────────────┘
                            │ Python dict
                            ↓
┌──────────────────────────────────────────────────────────────────┐
│ Bridge（matlab_adapter.py）                                       │
│                                                                   │
│  build_repair_result(waypoints, ...)                              │
│  → Protobuf RepairResult                                          │
│      含 waypoints + mesh_data + layer_profiles                    │
│      + particle_dist + uniformity + mass + time + warnings        │
└───────────────────────────┬──────────────────────────────────────┘
                            │ ZMQ REP/REQ (protobuf bytes)
                            ↓
┌──────────────────────────────────────────────────────────────────┐
│ GUI（main_window.py + profile_result_panel.py）                   │
│                                                                   │
│  _on_zmq_path_result(result)                                      │
│  → parse_repair_result(msg) → dict                                │
│  → set_profile_result(dict)                                       │
│      ├── 3D 预览面板：路径动画                                     │
│      ├── 沉积网格 Tab：mesh (STL → Poly3DCollection)              │
│      ├── 逐层轮廓 Tab：layer_profiles (柱状图)                     │
│      ├── 粒子分布 Tab：particle_dist (散点热力图)                  │
│      ├── 均匀性仪表 Tab：uniformity (仪表盘)                       │
│      └── 指标卡片：mass, time, volume, warnings                   │
└──────────────────────────────────────────────────────────────────┘
```

### 3.2 数据转换链路

| 阶段 | Python 数据 | 转换函数 | MATLAB 数据 |
|------|------------|---------|------------|
| 输入 | xyz (N×3 ndarray) | `_write_xyz_as_stl()` | STL 文件路径 (char) |
| 输入 | meta (dict) | `_meta_to_profile_params()` | params (struct) |
| 输入 | feed_rates (M×1 ndarray) | `_feed_rates_to_velocitylist()` | velocitylist (string array) |
| 输出 | — | `eng.run_path_planning()` | pointlist (M×6 double) |
| 输出 | — | `eng.run_profile_prediction()` | result (struct) |
| 输出 | mesh (N×9 ndarray) | `_parse_profile_result()` | mesh (N×9 double) |
| 输出 | mesh_stl_bytes (bytes) | `_triangles_to_binary_stl()` | — |
| 输出 | layer_profiles (L×4 ndarray) | `_parse_profile_result()` | layer_profiles (L×4 double) |
| 输出 | particle_dist (dict) | `_parse_profile_result()` | particle_distribution (struct) |
| 输出 | warnings (list[str]) | `_parse_profile_result()` | warnings (cell array) |

## 四、算法精度保证

### 4.1 未修改 MATLAB 算法逻辑

- `generate_path.m` — 原始路径生成算法，未修改
- `profilePredict.m` — 原始形貌预测算法，未修改
- `particleFitting.m` — 原始 CFD 粒子拟合算法，未修改
- 所有依赖函数 — 原始实现，未修改

### 4.2 Python 仅做数据转换

| 操作 | 类型 | 说明 |
|------|------|------|
| `_write_xyz_as_stl` | I/O 转换 | 点云 → STL 文件（Delaunay 三角化），非算法 |
| `_meta_to_profile_params` | 格式转换 | Python dict → MATLAB struct，非算法 |
| `_feed_rates_to_velocitylist` | 格式转换 | 数值 → ABB 速度字符串，与 `velocity_to_numeric` 互逆 |
| `_parse_profile_result` | 格式转换 | matlab.double → numpy.ndarray，非算法 |
| `_triangles_to_binary_stl` | 格式转换 | mesh 数组 → STL bytes，非算法 |

### 4.3 无精度损失

- MATLAB double (64-bit) → Python float64 → float32（Protobuf 传输）→ GUI 显示
- 三角网格顶点坐标完整保留，无降采样
- 粒子分布完整传递，无过滤
- 逐层轮廓指标完整传递
