# 算法验证体系使用说明

> 版本：1.0.0 | 协议：v2.1 | 更新日期：2026-07-14 | 文档语言：简体中文

## 这个工具是做什么的

软件里有两套算法：

- **MATLAB 算法**：正式的、精确的算法，在 MATLAB 里运行。
- **Python 算法**：简化的、快速的算法，在软件内部运行。

这两套算法做的是同一件事：根据点云数据，生成修复路径。

这个工具的作用是：**用同一份点云数据，分别跑两套算法，然后把结果放在一起比对**。

比对的结果会自动写成一份报告，告诉你两套算法的结果差多少。

---

## 怎么运行

### 准备工作

打开命令行窗口（按 Win+R，输入 cmd，回车）。

切换到软件目录：

```
cd d:\work\demo\industrial-vision
```

### 最简单的运行方式

直接输入：

```
python validate_algorithms.py
```

软件会自动做以下事情：

1. 生成一份测试点云（用固定种子 42，每次结果一样）。
2. 跑 MATLAB 算法。
3. 跑 Python 算法。
4. 把两边的输出逐项比对。
5. 生成一份 Diff Report。

运行完之后，屏幕上会显示一个摘要。

### 常用选项

| 你想做什么 | 输入什么 |
|------------|----------|
| 指定随机种子 | `python validate_algorithms.py --seed 100` |
| 指定缺陷类型 | `python validate_algorithms.py --defect pit groove` |
| 指定点云点数 | `python validate_algorithms.py --n-points 5000` |
| 指定报告路径 | `python validate_algorithms.py --output my_report.md` |
| 跳过 MATLAB（MATLAB 没装时用） | `python validate_algorithms.py --no-matlab` |
| 静默模式（少输出） | `python validate_algorithms.py --quiet` |

可以组合使用，例如：

```
python validate_algorithms.py --seed 100 --defect pit groove --n-points 5000 --output my_report.md
```

## 报告在哪里

报告默认保存在日志目录：

```
用户数据目录\logs\algorithm_diff_YYYYMMDD_HHMMSS.md
```

文件名里的数字是时间戳。比如 `algorithm_diff_20260714_230224.md` 表示 2026 年 7 月 14 日 23:02:24 生成的。

用户数据目录的位置：

- **开发环境**：`d:\work\demo\industrial-vision\user_data\logs\`
- **打包后的软件**：`%APPDATA%\CSAM_Repair\logs\`
- **自定义**：设置环境变量 `CSAM_USER_DATA` 后，在该目录下的 `logs\`

## 报告里有什么

报告是 Markdown 格式，用任何文本编辑器都能打开。推荐用 VS Code 或 Typora 打开，表格会显示得更好看。

报告包含 9 个部分：

### 第 1 部分：验证概览

显示总体结论（通过 / 存在差异）和指标统计。

还会显示测试输入信息：随机种子、缺陷类型、点云点数、缺陷点数。

### 第 2 部分：算法版本

显示两套算法的版本号和 MATLAB Runtime 版本。

| 引擎 | 算法版本 | MATLAB Runtime |
|------|----------|----------------|
| MATLAB | matlab-2.0.0 | R2025b |
| Python | python-heuristic-1.0.0 | — |

### 第 3 部分：系统信息

显示 Python 版本、操作系统、NumPy 版本。方便排查环境问题。

### 第 4 部分：耗时对比

显示两套算法各跑了多久。

| 引擎 | 执行耗时 | 状态 |
|------|----------|------|
| MATLAB | 2.345s | 成功 |
| Python | 0.634s | 成功 |

如果两边都成功，还会显示耗时比（谁快谁慢，快几倍）。

### 第 5 部分：六维度结果比对

这是报告的核心部分。两套算法的输出从 6 个维度逐项比对。

每个维度有一张表格，显示每个指标的 MATLAB 值、Python 值、绝对误差、相对误差、通过/失败。

图标的含义：

- ✅ 通过：误差在允许范围内。
- ❌ 失败：误差超出允许范围。
- ⚠️ 跳过：一方或双方没有数据，无法比对。

### 第 6 部分：失败项详情

列出所有失败的指标，方便快速定位问题。

### 第 7 部分：引擎执行异常

如果 MATLAB 或 Python 引擎执行失败，这里会显示错误信息。

### 第 8 部分：警告信息

显示算法执行过程中产生的警告。

### 第 9 部分：工艺参数

显示本次验证使用的所有工艺参数。

## 六个维度分别比什么

### 1. pointlist（航点位置）

航点是喷嘴要经过的点。每个点有 x、y、z 坐标。

因为两套算法的航点数量可能不同，不逐点比对。改用统计指标：

- 点数（总共有多少个航点）
- AABB 边界框（所有航点的 X/Y/Z 最小值和最大值）
- 质心位置（所有航点的中心点）
- 路径总长度（航点连起来的总距离）

### 2. velocitylist（进给速度）

每个航点对应的喷嘴移动速度。

比对指标：

- 速度点数
- 平均速度
- 最大速度
- 最小速度
- 速度标准差（速度波动大小）

### 3. Layer（逐层轮廓）

修复是分层进行的。每一层有自己的轮廓数据。

比对指标：

- 层数
- 每层的最大高度
- 每层的平均高度
- 每层的沉积效率

### 4. Mesh（沉积表面网格）

沉积表面的三角网格。

比对指标：

- 三角形数量
- 网格包围盒体积
- 网格质心位置
- 沉积最大高度

### 5. Volume（填充体积）

预测的填充体积、质量、时间。

比对指标：

- 预测体积（mm³）
- 预估质量（g）
- 预估时间（s）

### 6. Uniformity（表面均匀性）

沉积表面的均匀程度，0 到 1 之间。越接近 1 越均匀。

比对指标：

- 均匀性评分

## 误差允许范围

每个指标都有一个允许的误差范围。误差在这个范围内就算通过。

| 类型 | 允许范围 | 含义 |
|------|----------|------|
| 相对误差 | 15% | MATLAB 值和 Python 值的相对差异不超过 15% |
| 体积绝对误差 | 50 mm³ | 体积差不超过 50 立方毫米 |
| 均匀性绝对误差 | 0.15 | 均匀性评分差不超过 0.15 |
| 路径长度相对误差 | 20% | 路径总长度的相对差异不超过 20% |

一个指标只要满足绝对误差或相对误差中的任意一个，就算通过。

## 怎么看结果

### 全部通过

所有指标都在允许范围内。说明两套算法的结果一致。

### 部分失败

有些指标的误差超出范围。看第 6 部分"失败项详情"，找到是哪个维度、哪个指标失败。

常见原因：

- **MATLAB 和 Python 算法本身设计不同**：这是正常的。Python 是简化版，结果会有差异。
- **参数不同**：检查第 9 部分的工艺参数是否和预期一致。
- **点云不同**：确保用相同的随机种子。

### MATLAB 失败

如果 MATLAB 引擎执行失败，报告里 MATLAB 部分会标记为"失败"，并显示错误信息。

常见原因：

- MATLAB 没有安装或没有启动。
- MATLAB 的 `run_path_planning` 函数不在搜索路径上。需要在 MATLAB 里先 `addpath` 到 `path_planning/` 目录。
- MATLAB 共享引擎不可用。

这种情况下可以用 `--no-matlab` 跳过 MATLAB，只跑 Python：

```
python validate_algorithms.py --no-matlab
```

## MATLAB 版本怎么看

报告第 2 部分会显示 MATLAB Runtime 版本。

软件通过以下方式获取版本号：

1. 先从 `MatlabLifecycleManager` 查询。
2. 查不到则从 MATLAB 安装路径解析（正则匹配 `R2025b` 这样的版本号）。
3. 都查不到则显示 `unknown`。

## 常见问题

### 问：运行时报 `ModuleNotFoundError: No module named 'numpy'`

需要先安装依赖。在命令行输入：

```
pip install numpy scipy
```

### 问：运行时报 `ModuleNotFoundError: No module named 'PySide6'`

PySide6 是软件的图形界面库。如果只跑算法验证，也需要安装：

```
pip install PySide6
```

### 问：MATLAB 引擎报错 `未定义函数 'run_path_planning'`

MATLAB 的路径规划函数不在搜索路径上。需要在 MATLAB 命令行里执行：

```matlab
addpath('path_planning 目录的完整路径')
```

然后重新运行验证。

### 问：报告里的相对误差非常大（比如几百万%）

这通常是因为 MATLAB 值为 0，Python 值不为 0。相对误差 = 差值 / MATLAB 值，当 MATLAB 值为 0 时分母极小，导致相对误差爆炸。

这种情况下看绝对误差更有意义。或者检查 MATLAB 引擎是否执行成功。

### 问：每次运行结果一样吗

是的。使用相同的随机种子（默认 42），生成的测试点云完全一样。这样多次运行的结果可以对比。

### 问：可以验证自己的点云数据吗

目前验证体系使用自动生成的测试点云。如果需要验证自定义点云，可以在 `algorithm_validator.py` 的 `_generate_test_input` 方法中替换点云生成逻辑。

## 退出码

命令行运行后，退出码的含义：

- **0**：所有指标通过，两套算法结果一致。
- **1**：存在差异或引擎失败。

可以在脚本中用退出码判断验证结果：

```
python validate_algorithms.py --quiet
if %errorlevel% equ 0 (
    echo 验证通过
) else (
    echo 验证失败，请查看报告
)
```
