## 一、软件简介

### CSAM Repair 是什么

CSAM Repair（冷喷涂缺陷修复软件）是一款面向冷喷涂增材制造（Cold Spray Additive Manufacturing，CSAM）工艺的工业视觉修复工具。它把扫描得到的零件点云数据导入电脑，自动计算喷涂路径，并预测修复后的表面形貌，最终导出数控机床可用的 G-code 加工文件和 PDF 修复报告。

### 主要功能

- 加载三维点云数据（CSV、TXT、XYZ、ASC 格式）
- 在 3D 视图中查看零件表面
- 用鼠标框选缺陷区域
- 自动生成喷涂路径
- 模拟冷喷涂沉积过程，预测修复后的形貌
- 检查修复方案是否可行
- 导出 G-code 数控加工文件（.nc）
- 导出 PDF 修复报告

### 适用场景

- **操作工**：日常使用，加载点云 → 选缺陷 → 生成路径 → 导出 G-code
- **技术员**：调整工艺参数，做可行性检查，导出报告
- **工程师**：分析修复方案，评估不同材料的效果
- **质检员**：查看 PDF 报告，核对修复参数和结果

> 软件不需要联网即可使用本地计算引擎；仅在调用远程 MATLAB（Matrix Laboratory，矩阵实验室）算法服务时需要在同一局域网内连接 MATLAB 服务器。

## 二、常见问题

### 2.1 安装相关

#### Q1. 软件需要什么电脑配置？

基本要求：Windows 10 及以上 64 位系统、4GB 以上内存、5GB 以上空闲硬盘空间。如果要做形貌预测，建议 8GB 以上内存。不支持 32 位系统。

#### Q2. Python（派森）版本有什么要求？

软件要求 Python 3.10、3.11 或 3.12 三个版本之一。其他版本（如 3.9 或 3.13）不保证兼容。在 PowerShell 中执行 `python --version` 查看当前版本。

#### Q3. 依赖装不全怎么办？

在虚拟环境中执行以下命令一次性安装所有依赖：

```
pip install -r requirements.txt
```

如果某些包安装失败，可单独安装。常见依赖：PySide6、pyzmq、numpy、scipy、shapely、reportlab、cryptography。

#### Q4. 虚拟环境怎么激活？

进入软件目录后执行：

```
.\venv\Scripts\Activate.ps1
```

如果提示"禁止运行脚本"，先执行一次：

```
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

按 Y 确认后重新激活。

#### Q5. 软件能装在 D 盘或 U 盘吗？

可以装在 D 盘，但安装路径里不要有中文或空格。不建议装在 U 盘，软件需要往系统写配置，U 盘运行容易出错或变慢。多台电脑使用时，每台电脑各装一份。

#### Q6. 杀毒软件报警怎么办？

本软件安全。安装时选择"允许"或"信任"。如果杀毒软件强制删除文件，临时关闭杀毒软件，装完再打开，并把软件目录加入白名单。

#### Q7. 软件更新了要重新装吗？

新版本需要先卸载旧版本再安装新版本。卸载不会删除已生成的文件。如果有重要的参数配置，更新前请让技术员备份。

### 2.2 运行相关

#### Q8. 软件如何启动？

在 PowerShell 中进入软件目录并激活虚拟环境后执行：

```
python run_app.py
```

MATLAB Bridge（桥接服务）则在 MATLAB 中执行：

```matlab
matlab_bridge_server
```

#### Q9. 启动时弹出错误框怎么办？

先把错误框里的文字截图保存，再点"确定"关闭。最常见原因是电脑缺少运行环境。把截图交给技术员，通常装一个小补丁就能解决。

#### Q10. 启动很慢正常吗？

第一次启动比较慢（约 10-20 秒）是正常的，软件在初始化。之后启动会快一些。如果每次都要等一两分钟，可能是电脑配置较低或硬盘较老，请联系技术员。

#### Q11. 软件打开后是空白界面怎么办？

请等约 10 秒钟，软件第一次启动需要加载组件。如果等了 30 秒还是空白，关闭软件重新打开一次。连续三次空白请联系技术员。

#### Q12. 启动时提示"端口 5555 被占用"怎么办？

可能有另一个程序（或之前打开过本软件没关）正在用这个端口。解决办法：①把之前打开的软件全部关掉；②重启一次电脑；③如果还不行，让技术员修改环境变量 `CSAM_ZMQ_ADDRESS` 换一个端口。

#### Q13. 界面文字显示乱码怎么办？

让技术员把系统区域设置改成"中文（简体，中国）"，并勾选"Beta 版 UTF-8 支持"，重启电脑后即可正常显示。

#### Q14. 软件能同时开两个吗？

不建议。同时开两个可能因为端口冲突（5555）报错，电脑也会变卡。建议一个一个来，做完一个再开下一个。

#### Q15. 软件卡死了怎么办？

①先等 1 分钟，可能正在计算；②按 Ctrl+Shift+Esc 打开任务管理器，找到软件右键"结束任务"；③重新打开软件。建议经常导出中间结果，避免卡死后从头来。

#### Q16. 软件闪退了怎么办？

闪退通常是内存不足或软件 bug 导致。①关闭其他占内存的程序；②如果经常闪退，让技术员查看 `logs/` 目录中的崩溃日志；③养成习惯，每完成一步就导出一次中间结果。

### 2.3 MATLAB 相关

#### Q17. MATLAB 是什么？需要自己装吗？

MATLAB 是一种数值计算软件。如果你只用"本地计算引擎"，完全不需要 MATLAB。只有在选择"远程服务 MATLAB"时才需要，而且 MATLAB 装在另一台电脑（服务器）上，不是你的操作电脑。

#### Q18. MATLAB 版本不对怎么办？

软件要求 MATLAB R2025b 或更高版本，低版本（如 R2024a）不能使用。如果暂时不能升级，请使用"本地计算引擎"，不需要 MATLAB。

#### Q19. 远程 MATLAB 服务连不上怎么办？

请按顺序检查：①运行 MATLAB 的电脑是否开机；②那台电脑上 MATLAB R2025b 是否打开；③MATLAB 服务程序是否启动（在 MATLAB 中执行 `matlab_bridge_server`）；④两台电脑是否在同一个网络里。以上都确认后重试。

#### Q20. 怎么知道 MATLAB 服务在运行？

最简单的办法：在软件里选"远程服务 MATLAB"，点"测试连接"按钮。提示"连接成功"说明服务正常；提示"连接失败"说明服务没开或网络有问题。运维人员也可在 PowerShell 中执行 `Get-NetTCPConnection -State Listen -LocalPort 5555` 查看端口监听状态。

#### Q21. MATLAB 服务端口是多少？

端口是 5555。请确保这个端口没有被其他程序占用，防火墙也允许通过。如需修改，通过环境变量 `CSAM_ZMQ_ADDRESS` 配置。

#### Q22. 本地引擎和 MATLAB 引擎结果不一样正常吗？

正常。两种引擎用的计算方法略有不同，远程 MATLAB 更精确一些。差异通常很小，不影响实际使用。对精度要求高时以 MATLAB 结果为准；日常使用本地引擎就够了。

#### Q23. 什么时候会自动降级到 Python 原型？

当 `CSAM_ALGORITHM_ENGINE=auto`（默认值）时，如果 MATLAB 不可用（连接失败、共享会话未找到、算法异常等），系统会自动降级到 Python 原型算法继续工作，保证业务连续性。降级事件会在日志中通过 `fallback.invoke` 关键字记录。

#### Q24. MATLAB 电脑坏了能用本地的吗？

能。把计算引擎切换成"本地计算引擎"即可，不需要 MATLAB 电脑。本地引擎可以完成所有功能，只是某些复杂计算精度稍低。等 MATLAB 电脑修好后再切回去。

#### Q25. MATLAB 服务经常掉线怎么办？

可能是网络不稳定。①检查网线连接是否松动；②让技术员检查网络有没有拥堵；③如果经常断，建议改用本地引擎。运维人员可通过 `heartbeat.miss`、`engine.lost` 等日志事件确认掉线原因。

#### Q26. 能在自己电脑上装 MATLAB 当远程用吗？

技术上可以，但不建议。MATLAB 很占内存，同时跑软件和 MATLAB 会让电脑很卡。建议 MATLAB 装在单独的电脑上，操作电脑和 MATLAB 电脑分开。

### 2.4 通信相关

#### Q27. ZMQ（ZeroMQ）是什么？

ZMQ（ZeroMQ，零消息队列）是软件内部用于 Python 与 MATLAB 之间通信的消息库。默认连接地址由环境变量 `CSAM_ZMQ_ADDRESS` 控制，Windows 下默认为 `tcp://127.0.0.1:5555`。

#### Q28. ZMQ 请求超时怎么办？

可能原因：MATLAB 算法计算慢、网络不稳定、MATLAB 进程卡死。解决办法：①查看 MATLAB 命令窗口是否有错误输出；②如果在 MATLAB 中卡住，按 Ctrl+C 终止服务，重新运行 `matlab_bridge_server`；③复杂算法可调大 `CSAM_BRIDGE_TIMEOUT_MS`（默认 30000 毫秒，复杂算法建议调到 120000）；④重试请求。

#### Q29. Bridge（桥接）通信错误怎么识别？

Bridge 通信层负责把 Python 侧请求（LegacyZmqClient → BridgeClient）通过 ZMQ 转发给 MATLAB 内的 MatlabAdapter。常见错误包括：序列化失败、协议版本不匹配、连接超时。这些错误会以 `request.crash`、`heartbeat.miss`、`engine.lost` 等事件记录在日志（logger 名 `csam.bridge.matlab`）中。

#### Q30. 协议版本不匹配怎么办？

当前协议版本为 v2.1。如果 Python 端和 MATLAB 端版本不一致，会报协议版本不匹配错误。解决办法：确保两端运行同一版本软件，升级后必须同时重启 MATLAB 算法服务（`matlab_bridge_server`）和 GUI（`python run_app.py`）。

#### Q31. 防火墙拦截了通信怎么办？

让运维人员在防火墙中放行 5555 端口（或自定义端口）。Windows 防火墙可在"高级安全设置"中添加入站规则，允许 5555 端口的 TCP 流量。

### 2.5 导出相关

#### Q32. G-code 导出失败怎么办？

常见原因：①没有生成路径（请先完成路径生成）；②目标文件夹没有写入权限（换一个文件夹，比如桌面）；③文件名含特殊字符（用纯英文或数字命名）；④航点坐标有异常值，重新生成路径。逐项检查后再试。

#### Q33. G-code 文件是什么格式？

导出的文件后缀是 .nc（比如 repair.nc）。这是数控加工文件，拷到数控机床或喷涂设备上就能用。不要手动修改文件内容，否则设备可能出错。

#### Q34. PDF 报告导出失败怎么办？

可能原因：①reportlab 未安装（执行 `pip install reportlab`）；②中文字体缺失；③没有形貌预测结果；④保存路径含特殊字符。建议先确认已完成形貌预测，再尝试保存到简单路径（如 D:\）。

#### Q35. PDF 报告是空白的怎么办？

可能是导出时还没有完成前面的步骤。请确认：①已加载点云；②已选取缺陷；③已生成路径；④已做形貌预测。所有步骤都完成后，PDF 才会有完整内容。重新做一遍再导出。

#### Q36. PDF 报告里包含什么内容？

PDF 报告包含：①零件和缺陷信息；②选用的材料和参数；③生成的路径示意图；④可行性检查结果；⑤形貌预测对比图（修复前后）；⑥日期和操作信息。可给质检员或客户看。

#### Q37. 能只导出 G-code 不导出 PDF 吗？

可以。G-code 和 PDF 是两个独立的导出按钮，想导哪个就点哪个。但建议两个都导，PDF 方便存档和追溯。

#### Q38. 导出的 G-code 能直接传到机床吗？

可以，把 .nc 文件用 U 盘拷到设备控制器上即可。但第一次使用前，请让工程师确认设备的 G-code 格式和软件导出格式一致。如有差异，需要工程师做一次格式适配。

### 2.6 许可证相关

#### Q39. 软件有使用次数限制吗？

本软件是本地部署，没有使用次数限制，也不会到期。装好后可以一直用。请遵守公司软件使用规定，不要私自拷贝给外部人员。

#### Q40. 多人能同时用这个软件吗？

每台电脑各装一份，各自独立使用。但注意：如果要用远程 MATLAB 服务，多台电脑连的是同一个 MATLAB 服务器，同时计算可能会排队或变慢，建议错开使用。

#### Q41. MATLAB 工具箱许可证失效怎么办？

部分 MATLAB 算法依赖 `Map_Toolbox`、`Curve_Fitting_Toolbox`。运维人员可在 MATLAB 中执行 `license('test', 'Map_Toolbox')` 检查，返回 1 表示可用。如失效请联系 IT 续期，或临时切换到本地引擎。

#### Q42. 需要联网激活吗？

不需要。软件本地部署，离线可用。只有在调用远程 MATLAB 时才需要局域网连接。

### 2.7 性能相关

#### Q43. 软件运行很慢怎么办？

可能原因：点云数据太大、电脑内存不足、参数设置导致计算量大。解决办法：①减小点云数据量；②关闭其他占内存的程序；③减小规划层数；④增大扫描步长和层高；⑤增加电脑内存。

#### Q44. 路径规划一直显示"计算中"正常吗？

如果选取的点很多，计算确实需要时间（几十秒到几分钟）。请耐心等待，不要反复点击。如果等了 5 分钟以上还没反应，可能卡住了，参考 Q15 处理。

#### Q45. 形貌预测要等很久吗？

本地引擎一般 30 秒到 2 分钟。远程 MATLAB 会更久，1-5 分钟。层数越多、点数越多，等待时间越长。请耐心等待，不要关闭软件。

#### Q46. MATLAB 计算为什么有时很慢？

MATLAB 算法首次调用时需要编译，第一次会比后续慢。独立启动 MATLAB 也有几秒到几十秒的延迟。如果长期慢，请检查 MATLAB 内存是否超过阈值（默认 4096 MB），或调大 `CSAM_BRIDGE_TIMEOUT_MS` 避免超时。

#### Q47. 3D 视图卡顿怎么办？

可能是显卡驱动较旧或点云数据量大。①更新显卡驱动；②减小点云数据量；③关闭其他占用显卡资源的程序；④尝试设置环境变量 `$env:QT_OPENGL="angle"` 后重新启动。

#### Q48. 内存占用很高怎么办？

形貌预测会生成中间文件（位于 `morphology_prediction/` 目录）。①定期清理该目录的旧文件；②关闭其他占内存的程序；③减小规划层数；④如经常不足，考虑升级内存到 16GB。

## 三、术语表

> 以下术语按字母/拼音排序，技术名词首次出现时给出中英文对照。

### CSAM（冷喷涂增材制造）

CSAM（Cold Spray Additive Manufacturing，冷喷涂增材制造）是一种金属修复与制造技术。通过高速气体把金属粉末喷到零件表面，粉末撞击后附着，不需要高温融化，所以叫"冷"喷涂。

### ZeroMQ（ZMQ）

ZeroMQ（ZMQ，零消息队列）是一种高性能消息库。本软件用它实现 Python 与 MATLAB 之间的请求-应答通信，默认地址 `tcp://127.0.0.1:5555`。

### Protocol Buffers（Protobuf）

Protocol Buffers（Protobuf，协议缓冲区）是 Google 提出的数据序列化格式。本软件的通信协议（当前版本 v2.1）使用 Protobuf 对请求和响应进行序列化，保证跨语言（Python ↔ MATLAB）的高效传输。

### Bridge（桥接）

Bridge（桥接）指连接 Python 端与 MATLAB 端的通信中间层。请求链路为：LegacyZmqClient（遗留 ZMQ 客户端）→ BridgeClient（桥接客户端）→ ZMQ → MatlabAdapter（MATLAB 适配器）。

### MATLAB R2025b

MATLAB R2025b 是 MathWorks 公司的数值计算软件版本。本软件要求该版本或更高。注意 R2025b 拒绝 `.m` 文件中的非 ASCII 字符，算法文件注释必须为纯 ASCII。

### G-code

G-code（数控加工指令代码）是数控机床能识别的加工指令文件。软件导出的 .nc 文件就是 G-code 文件，需要导入到数控机床执行。

### STL

STL（Standard Tessellation Language，标准三角网格语言）是一种描述三维表面网格的文件格式。本软件目前直接处理点云（CSV/TXT/XYZ/ASC），如需用 STL 数据请先转换为点云格式。

### 点云

点云（Point Cloud）是用三维坐标（x, y, z）记录的一组点的集合。可理解成用无数小点拼出来的零件三维形状，用三维扫描仪扫描零件得到。

### 缺陷区域

缺陷区域（Defect Region）是操作员在 3D 视图中用鼠标框选出来的有缺陷的区域。软件只在这个区域内生成修复路径。

### 路径规划

路径规划（Path Planning）是计算喷枪移动路线的过程。软件根据缺陷形状、材料属性、工艺参数，自动计算最优路径。

### 形貌预测

形貌预测（Profile Prediction）是模拟冷喷涂沉积过程、预测修复后表面形状的功能。告诉你"修完大概长这样"。

### 沉积

沉积（Deposition）是粉末颗粒附着在零件表面的过程。"沉积点"就是附着上去的粉末颗粒。

### 临界速度

临界速度（Critical Velocity）是每种材料的"最低速度门槛"。粉末颗粒速度必须超过这个门槛才能附着。例如 316L 不锈钢为 600 m/s，纯铜为 340 m/s。软件根据材料自动填入，不能手动修改。

### LegacyZmqClient

LegacyZmqClient（遗留 ZMQ 客户端）是 Python 侧与 Bridge 通信的客户端组件，负责发起算法请求。在新架构中通过 BridgeClient 转发到 ZMQ，再由 MatlabAdapter 处理。

### MatlabAdapter

MatlabAdapter（MATLAB 适配器）是运行在 MATLAB 进程内的 Python 组件，负责接收 ZMQ 请求并调用 MATLAB 算法函数。日志通过 logger 名 `csam.bridge.matlab` 输出。

### MatlabEngineProxy

MatlabEngineProxy（MATLAB 引擎代理）是 Python 单例，负责连接并共享同一个 MATLAB 会话（共享引擎会话），避免每次请求都重新启动 MATLAB。连接名称由环境变量 `CSAM_MATLAB_SHARED_NAME` 控制。

### ProfileResultPanel

ProfileResultPanel（形貌预测结果面板）是 GUI 中显示形貌预测结果的组件，展示修复前后的对比图、填充点数等指标。

### RepairVisualizer

RepairVisualizer（修复可视化器）是 GUI 中的 3D 视图组件，负责渲染点云、缺陷区域、修复路径与沉积形貌。

### 降级策略

降级策略（Fallback Strategy）指当 `CSAM_ALGORITHM_ENGINE=auto` 时，若 MATLAB 不可用（连接失败、共享会话未找到、算法异常），系统自动改用 Python 原型算法继续工作。降级事件以 `fallback.invoke` 记录在日志中。

### 共享引擎会话

共享引擎会话（Shared Engine Session）指 MatlabEngineProxy 通过 `matlab.engine.connect_matlab` 连接的一个已运行的 MATLAB 会话，多个请求复用同一会话以降低启动开销。会话名称由 `CSAM_MATLAB_SHARED_NAME` 指定。
