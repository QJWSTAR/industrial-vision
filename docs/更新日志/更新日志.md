## [1.0.0] — 2026-07-15 (Stable Release)

### 变更 (Changed) — RC→正式版加固

RC 审查发现的 4 个 Blocker 与 3 个关键 Critical 已全部修复，正式版转正：

- `launcher.py` 启动模式从 `-batch` 改为 `-nodesktop -nosplash -r`，支持 engine sharing（修复 Blocker B-1）
- `repair_app.spec` 补充缺失数据文件：`parameter_schema.json` / `matlab_bridge_server.m` / `path_planning/` / `profile_prediction/` 算法目录（修复 Blocker B-2）
- License 公钥从 `_MEIPASS` 只读目录加载（新增 `get_builtin_config_file()`），防止公钥替换攻击（修复 Blocker B-3）
- `repair_app.spec` 设置 `disable_windowed_traceback=True`，避免 `console=False` 模式下异常信息泄露（修复 Blocker B-4）
- `workers.py` `_pack_error` 完整传递三段式消息（What + 原因 + 建议），不再丢弃 Why/How 字段（修复 Critical C-1）
- `crash_handler.py` 所有 stderr 写入前检查 `sys.stderr is not None`，避免 frozen 模式崩溃（修复 Critical C-2）
- `repair_visualizer.py` 新增 `cleanup()` 方法（停止定时器 + clf + deleteLater），在 `closeEvent` 中清理 matplotlib Figure，消除内存泄漏（修复 Critical C-3）

### 新增 (Added)
- **MATLAB 工业路径规划算法接入**（`run_path_planning.m`）
- **MATLAB 工业形貌预测算法接入**（`run_profile_prediction.m`）
- **Python GUI 原生渲染 MATLAB 计算结果**：`ProfileResultPanel` 支持沉积网格、逐层轮廓、粒子分布、均匀性仪表盘四种可视化视图
- **Bridge 通信层**：基于 ZeroMQ REP/REQ + Protobuf v2.1 协议
- **MatlabEngineProxy 单例代理**：共享 MATLAB 会话 + 自动降级
- **工业可靠性降级策略**：MATLAB 不可用时自动降级到 Python 启发式算法
- **G-code 导出 + PDF 报告生成**
- **完整用户手册**：11 篇文档，面向无编程经验操作员

### 修复 (Fixed)
- 修复 `auto` 模式下独立启动 MATLAB 导致的 51 秒延迟
- 修复 `handle_repair` 算法失败时未降级到 Python 的问题
- 修复 Python 降级路径不生成 mesh 数据的问题
- 修复 `_try_profile_prediction` 重复尝试 MATLAB 连接的问题

### 删除 (Removed) — RC 清理
- 移除废弃的 v3.0 TCP/JSON 通信路径：`matlab_server/`、`bridge/protocol_v3/`、`engine/matlab_engine.py`、`factory.py`、`lifecycle.py`
- 移除 Demo MATLAB 入口：`main.m`、`createfigures.m`、`createvideo.m`
- 移除调试快照：`*.mat` 调试文件、`*.scdoc` CAD 源文件
- 移除重复数据文件：`路径规划/` 下的孤儿数据
- 移除 9 份重复文档
- 移除空目录 `repair_app/controller/`
- 移除所有 `__pycache__` 缓存

### 测试
- 402 个单元测试全部通过
- 27 项端到端验证全部通过
