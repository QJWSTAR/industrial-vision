# 工业算法说明

> 本文档说明 CSAM 修复平台中 MATLAB Server 注册的全部工业算法，以及 Python 侧的标定逻辑。
> 协议版本 v3.0，算法命名空间为 `csam.algorithm.v2`。
>
> 相关文档：
> - 算法协议定义见 [09_API文档.md](./09_API文档.md#协议-v30-消息)
> - 系统分层与部署见 [10_架构文档.md](./10_架构文档.md)
> - MATLAB Server 部署细节见 [MATLAB_DEPLOYMENT_GUIDE.md](./MATLAB_DEPLOYMENT_GUIDE.md)

## 1. 概述

MATLAB Server 共注册 **19 个算法**，分布于两个命名空间：

| 命名空间 | 算法数 | 用途 |
| --- | --- | --- |
| `path_planning.*` | 7 | 读取 STL、模型分类、逐层切片、喷涂路径生成、位姿解释、机器人指令输出 |
| `morphology.*` | 12 | 网格细分与优化、粒子拟合、射线追踪、八叉树加速、沉积剖面预测 |

协议版本 v3.0，命名空间 `csam.algorithm.v2`。

### 1.1 标定逻辑位置

> **重要**：标定逻辑位于 Python 侧，**不在** MATLAB Server。

- 标定数据库：`config/calibration_db.json`（约 187 KB），含材料、喷嘴、距离、角度、速度等测量值与修正系数。
- 标定向导：`repair_app/utils/calibration_wizard.py` 提供交互式标定向导。
- MATLAB Server 本身不包含任何标定算法，仅执行纯几何/路径计算。

详见本文档 [§8 标定](#8-标定)。

## 2. 重要说明：目录命名交叉

源码中存在两个**中文命名**目录，但目录名与实际存放的算法命名空间**交叉相反**，查阅代码时务必以算法命名空间为准，不要以目录名为准。

| 目录名 | 实际存放的算法 | 命名空间 |
| --- | --- | --- |
| `形貌预测\` | 路径规划算法（`layer_slice.m`、`model_process.m`、`generate_path.m` 等） | `path_planning.*` |
| `路径规划\` | 形貌预测算法（`profilePredict.m`、`spotInterp.m` 等） | `morphology.*` |

> **判断规则**：以算法在注册表中声明的命名空间（`path_planning.*` / `morphology.*`）为准，忽略目录名带来的直觉误导。

## 3. 工具箱依赖

MATLAB Server 算法对工具箱的依赖分为三档：

| 依赖档位 | 涉及算法 | 说明 |
| --- | --- | --- |
| 需要 `Map_Toolbox`（`polyxpoly`） | `path_planning.generate_path`、`morphology.profile_predict` | 仅 2 个算法 |
| 需要 `Curve_Fitting_Toolbox`（`fit` / `fittype`） | `morphology.particle_fitting` | 仅 1 个算法 |
| 基础 MATLAB（无需工具箱） | 其余 16 个 | 使用内置 `containers.Map`、`graph`、`conncomp`、`dfsearch`、`polyshape`、`polybuffer`、`delaunayTriangulation` |

基础 MATLAB 提供的、被算法广泛使用的内置能力：

- `containers.Map` —— A* 开放集、键值映射
- `graph` / `conncomp` / `dfsearch` —— 连通分量、深度优先遍历（切片、边界环提取）
- `polyshape` / `polybuffer` —— 多边形运算与缓冲
- `delaunayTriangulation` —— 三角化（剖面预测）

> 工具箱缺失时，MATLAB Server 会返回 `ERR_DEPS` 错误码（见 [09_API文档.md](./09_API文档.md#matlab-server-api)）。

## 4. 路径规划算法（7 个）

本节逐一说明 `path_planning.*` 命名空间下的 7 个算法。

### 4.1 path_planning.read_stl_file

- **源文件**：`形貌预测\read_stl_file.m`
- **作用**：读取 STL 文件为 `N*12` 矩阵。

**输入**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `filepath` | string | STL 文件路径 |

**输出**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `triangles` | `N*12` 矩阵 | 每行 `[v1x,v1y,v1z, v2x,v2y,v2z, v3x,v3y,v3z, nx,ny,nz]`，即 3 个顶点坐标 + 1 个法向量 |

**流程**

1. 自动识别 STL 是 ASCII 还是二进制格式。
2. 解析三角面片及其法向量。
3. 使用 `try` / `cleanup` 显式 `fclose` 文件句柄，保证异常时不泄漏。

> 与 `morphology.read_stlfile` 的区别：本算法输出 `N*12`（含法向量），后者输出 `N*9`（仅顶点）。

### 4.2 path_planning.model_process

- **源文件**：`形貌预测\model_process.m`
- **作用**：对三角面分类为"添加簇"与"修复簇"，并计算每个三角面的边界信息。

**输入**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `triangles` | `N*12` 矩阵 | 来自 `read_stl_file` 的三角面 + 法向量 |

**输出**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `clusters` | 结构/矩阵 | 分类后的添加簇与修复簇 |
| `annotated` | `N*15` 矩阵 | `[顶点9 + 法向量3 + minz + maxz + angle]` |

**流程**

1. 按法向量方向与几何特征将三角形分类为添加簇 / 修复簇。
2. 对每个三角面计算 `minz`、`maxz`（包围盒高度）与 `angle`（倾角）。
3. 输出标注后的 `N*15` 矩阵供切片使用。

### 4.3 path_planning.layer_slice

- **源文件**：`形貌预测\layer_slice.m`
- **作用**：将三角面簇切片为逐层多边形。

**输入**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `clusters` | 矩阵/结构 | 来自 `model_process` 的分类结果 |
| `layer_height` | double | 切片层高（mm） |

**输出**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `layers` | cell 数组 | 每层一个多边形列表 |

**流程**

1. 按 `layer_height` 在 Z 方向生成切平面。
2. 求每个三角面与切平面的交线。
3. 用 `graph` 构建交线邻接关系，`conncomp` 划分连通分量，`dfsearch` 拼接成闭合多边形。
4. 输出逐层多边形列表。

### 4.4 path_planning.generate_path

- **源文件**：`形貌预测\generate_path.m`
- **作用**：由层列表生成喷涂 `pointlist` / `velocitylist` / `zonelist`。
- **工具箱依赖**：`Map_Toolbox`（`polyxpoly`）

**输入**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `layers` | cell 数组 | 来自 `layer_slice` 的逐层多边形 |
| 路径参数 | dict | 步长、补偿、扫描方向等 |

**输出**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `pointlist` | `N*6` 矩阵 | `[x,y,z, nx,ny,nz]`，单位 mm |
| `velocitylist` | JSON 字符串 | 每点速度 |
| `zonelist` | JSON 字符串 | 每点所属区域 |

**流程**

1. **Zig-Zag 填充**：对每层多边形按扫描方向生成往返填充线。
2. **边缘补偿**：用 `polyxpoly` 求填充线与多边形边界交点，补偿边缘。
3. **A\* 连接**：层间与往返换向处用 A* 搜索连接路径。
4. 输出 `pointlist(N*6)`、`velocitylist`、`zonelist`。

> ⚠️ **已知缺陷**：第 36–63 行存在全局警告开关（`warning off` / `warning on`），但**没有** `try/finally` 保护。若中间抛出异常，全局警告状态将被永久关闭，影响后续所有 MATLAB 代码的诊断输出。调用方应自行在外层恢复警告状态。

### 4.5 path_planning.a_star_search

- **源文件**：`形貌预测\aStarSearch.m`
- **作用**：在占用栅格上执行 A* 路径搜索。

**输入**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `grid` | 矩阵 | 占用栅格（0=自由，1=障碍） |
| `start` / `goal` | 坐标 | 起止栅格坐标 |

**输出**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `path` | 矩阵 | 搜索得到的路径点序列 |

**流程**

1. 用 `containers.Map` 作为 `openSet`，记录节点与 f 值。
2. 标准 A* 迭代：取出 f 最小节点 → 扩展邻居 → 更新 g/h/f。
3. 命中目标后回溯路径。

### 4.6 path_planning.point_interpretaion

- **源文件**：`形貌预测\point_interpretaion.m`
- **作用**：将 `pointlist` 的法向量转换为 ABB `reltool` 欧拉角。

**输入**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `pointlist` | `N*6` 矩阵 | `[x,y,z, nx,ny,nz]` |

**输出**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `euler` | `N*?` 矩阵 | ABB `reltool` 欧拉角序列 |

**流程**

1. 由法向量解算工具姿态旋转轴。
2. 映射为 ABB `reltool` 所需的欧拉角。

> ⚠️ **已知 bug**：第 54 行应为 `z_rotaxis`，源码误写为 `y_rotaxis`，会导致 Z 轴旋转计算错误。修复时需将第 54 行的 `y_rotaxis` 改为 `z_rotaxis`。

### 4.7 path_planning.robot_command_output

- **源文件**：`形貌预测\robot_command_output.m`
- **作用**：输出 ABB Rapid 移动指令文件。

**输入**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `pointlist` / `euler` | 矩阵 | 来自前序算法的位姿数据 |
| 输出参数 | dict | 文件名、速度、区域等 |

**输出**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `rapid_file` | `.mod` 文件 | ABB Rapid 移动指令 |

**流程**

1. 将位姿序列格式化为 ABB Rapid 语法。
2. 写出 `.mod` 模块文件，可由 ABB 控制器直接加载执行。

## 5. 形貌预测算法（12 个）

本节逐一说明 `morphology.*` 命名空间下的 12 个算法。

### 5.1 morphology.read_stlfile

- **源文件**：`路径规划\read_STLfile.m`
- **作用**：用 `stlread` 读取 STL 为 `N*9` 矩阵。

**输入 / 输出**

| 方向 | 参数 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `filepath` | string | STL 文件路径 |
| 输出 | `triangles` | `N*9` 矩阵 | `[v1x,v1y,v1z, v2x,v2y,v2z, v3x,v3y,v3z]`，**仅顶点**，无法向量 |

**流程**：调用 MATLAB 内置 `stlread`，仅提取三角形顶点重组为 `N*9` 矩阵。

### 5.2 morphology.recursive_subdivide

- **源文件**：`路径规划\recursiveSubdivide.m`
- **作用**：递归细分三角形直至边长低于阈值。

**输入 / 输出**

| 方向 | 参数 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `triangles` | `N*9` 矩阵 | 输入三角面 |
| 输入 | `edge_threshold` | double | 目标最大边长 |
| 输出 | `refined` | `M*9` 矩阵 | 细分后的三角面（`M >= N`） |

**流程**：对每个三角形检查最长边；若超过阈值，沿最长边中点一分为二，递归处理直至全部满足阈值。

### 5.3 morphology.improve_short_edges

- **源文件**：`路径规划\improveShortEdges.m`
- **作用**：折叠短边以改善三角形质量。

**输入 / 输出**

| 方向 | 参数 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `triangles` | `N*9` 矩阵 | 待优化三角面 |
| 输入 | `short_threshold` | double | 短边阈值 |
| 输出 | `optimized` | `M*9` 矩阵 | 优化后的三角面 |

**流程**：检测长度低于阈值的边，将相邻三角形合并/折叠以消除退化三角形，提升网格质量（避免后续八叉树与射线相交出现数值问题）。

### 5.4 morphology.particle_fitting

- **源文件**：`路径规划\particleFitting.m`
- **作用**：将 CFD 粒子分布拟合为射线属性。
- **工具箱依赖**：`Curve_Fitting_Toolbox`（`fittype` `lowess`）

**输入 / 输出**

| 方向 | 参数 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `excel_path` | string | CFD 粒子数据 Excel 文件 |
| 输出 | `rays_indices` | 矩阵 | 射线索引 |
| 输出 | `origins` | 矩阵 | 射线原点 |
| 输出 | `directions` | 矩阵 | 射线方向 |
| 输出 | `speeds` | 矩阵 | 粒子速度 |
| 输出 | `possiLengths` | 矩阵 | 可能长度 |
| 输出 | `Vcr` | 矩阵 | 临界速度 |

**流程**

1. 从 Excel 读取 CFD 粒子数据。
2. 用 `fittype('lowess')` 对粒子分布做局部加权回归拟合。
3. 由拟合结果导出射线属性（原点、方向、速度、临界速度等）。

### 5.5 morphology.spot_interp

- **源文件**：`路径规划\spotInterp.m`
- **作用**：沿 `pointlist` 按固定步长插值喷涂点。

**输入 / 输出**

| 方向 | 参数 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `pointlist` | `N*6` 矩阵 | 来自路径规划的喷涂点 |
| 输入 | `step` | double | 插值步长 |
| 输出 | `spots` | `N*7` 矩阵 | `[x,y,z, nx,ny,nz, velocity_compensation_coeff]` |

**流程**：沿点列按固定步长重采样，对法向量与位置做插值，并附加速度补偿系数（取自标定数据库）。

### 5.6 morphology.ray_move

- **源文件**：`路径规划\rayMove.m`
- **作用**：将射线原点/方向变换到喷嘴姿态。

**输入 / 输出**

| 方向 | 参数 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `origins` / `directions` | 矩阵 | 来自 `particle_fitting` 的射线 |
| 输入 | `nozzle_pose` | 矩阵 | 喷嘴位姿 |
| 输出 | `transformed_origins` / `transformed_directions` | 矩阵 | 变换后的射线 |

**流程**：用 **Rodrigues 旋转**将射线原点与方向从粒子坐标系旋转到喷嘴姿态坐标系，保证后续相交计算在统一坐标系下进行。

### 5.7 morphology.build_octree

- **源文件**：`路径规划\buildOctree.m`
- **作用**：为三角面构建八叉树加速结构。

**输入 / 输出**

| 方向 | 参数 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `triangles` | `N*9` 矩阵 | 输入三角面 |
| 输出 | `octree` | 结构 | 八叉树根节点 |

**流程**：递归划分包围盒为 8 子节点，直至每叶节点三角形数低于阈值，用于加速射线-三角形相交测试。

### 5.8 morphology.batch_octree_filter

- **源文件**：`路径规划\batchOctreeFilter.m`
- **作用**：遍历八叉树按射线过滤候选三角形。

**输入 / 输出**

| 方向 | 参数 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `octree` | 结构 | 来自 `build_octree` |
| 输入 | `rays` | 矩阵 | 射线集合 |
| 输出 | `candidates` | cell 数组 | 每条射线对应的候选三角形列表 |

**流程**：对每条射线遍历八叉树，仅保留包围盒与射线相交的节点中的三角形，大幅缩减后续精确相交测试的规模。

### 5.9 morphology.ray_triangle_intersection

- **源文件**：`路径规划\ray_triangle_intersection.m`
- **作用**：Moller-Trumbore 射线/三角形相交测试。

**输入 / 输出**

| 方向 | 参数 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `ray_origin` / `ray_dir` | 向量 | 射线原点与方向 |
| 输入 | `triangles` | `N*9` 矩阵 | 候选三角形 |
| 输出 | `hits` | 矩阵 | 命中点与相交参数 |

**流程**：实现经典 Moller-Trumbore 算法，计算射线与每个三角形的相交参数 `t`，剔除无交点与背面交点。

### 5.10 morphology.classify_removed_triangles

- **源文件**：`路径规划\classifyRemovedTriangles.m`
- **作用**：聚类被移除三角形并提取边界环。

**输入 / 输出**

| 方向 | 参数 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `removed_triangles` | `N*9` 矩阵 | 被射流移除的三角形 |
| 输出 | `boundary_loops` | cell 数组 | 提取出的边界环 |

**流程**：用 `graph` 构建三角形邻接关系，`conncomp` 划分连通簇，对每簇提取外边界环，供剖面预测使用。

### 5.11 morphology.create_triangulation_from_matrix

- **源文件**：`路径规划\createTriangulationFromMatrix.m`
- **作用**：由 `N*9` 矩阵构建 `triangulation` 对象。

**输入 / 输出**

| 方向 | 参数 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `matrix` | `N*9` 矩阵 | 三角形顶点 |
| 输出 | `T` | `triangulation` | MATLAB `triangulation` 对象 |

**流程**：去重顶点、构建点表与连接表，返回标准 `triangulation` 对象供可视化与导出。

### 5.12 morphology.profile_predict

- **源文件**：`路径规划\profilePredict.m`
- **作用**：预测单次喷涂移动的沉积剖面三角形。
- **工具箱依赖**：`Map_Toolbox`（`polyxpoly`）

**输入 / 输出**

| 方向 | 参数 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `spot` | `1*7` 矩阵 | 喷涂点（来自 `spot_interp`） |
| 输入 | `rays` / `candidates` | 矩阵 | 射线与候选三角形 |
| 输出 | `profile_triangles` | `N*9` 矩阵 | 本次喷涂的沉积剖面三角形 |

**流程**

1. **PCA 投影**：将命中点投影到主成分平面。
2. **Delaunay 三角化**：在投影平面构建三角网格。
3. **improveShortEdges 优化**：折叠短边提升网格质量。
4. 用 `polyxpoly` 裁剪边界，输出沉积剖面三角形。

## 6. 完整工作流

### 6.1 路径规划流水线

```
read_stl_file → model_process → layer_slice → generate_path
                                                       │
                                                       ▼
                            point_interpretaion → robot_command_output
```

| 步骤 | 算法 | 产出 |
| --- | --- | --- |
| 1 | `path_planning.read_stl_file` | `N*12` 三角面 + 法向量 |
| 2 | `path_planning.model_process` | `N*15` 标注三角面（分类 + 边界） |
| 3 | `path_planning.layer_slice` | 逐层多边形列表 |
| 4 | `path_planning.generate_path` | `pointlist(N*6)` + `velocitylist` + `zonelist` |
| 5 | `path_planning.point_interpretaion` | ABB `reltool` 欧拉角 |
| 6 | `path_planning.robot_command_output` | ABB Rapid `.mod` 文件 |

### 6.2 形貌预测流水线

```
read_STLfile → recursive_subdivide → improve_short_edges
                                            │
                                            ▼
        particle_fitting → spot_interp
                            │
                            ▼
   ┌──────────────── 循环（逐喷涂点）────────────────┐
   │  ray_move → build_octree → batch_octree_filter  │
   │  → ray_triangle_intersection                    │
   │  → classify_removed_triangles → profile_predict │
   └─────────────────────────────────────────────────┘
                            │
                            ▼
              create_triangulation_from_matrix
```

| 步骤 | 算法 | 产出 |
| --- | --- | --- |
| 1 | `morphology.read_stlfile` | `N*9` 三角面 |
| 2 | `morphology.recursive_subdivide` | 细分后的三角面 |
| 3 | `morphology.improve_short_edges` | 优化后的三角面 |
| 4 | `morphology.particle_fitting` | 射线属性集合 |
| 5 | `morphology.spot_interp` | 插值喷涂点 `N*7` |
| 6（循环） | `morphology.ray_move` | 喷嘴坐标系射线 |
| 7（循环） | `morphology.build_octree` | 八叉树 |
| 8（循环） | `morphology.batch_octree_filter` | 候选三角形 |
| 9（循环） | `morphology.ray_triangle_intersection` | 命中点 |
| 10（循环） | `morphology.classify_removed_triangles` | 边界环 |
| 11（循环） | `morphology.profile_predict` | 沉积剖面三角形 |
| 12 | `morphology.create_triangulation_from_matrix` | 最终 `triangulation` |

## 7. 输入 / 输出文件格式

### 7.1 输入文件格式

| 文件类型 | 读取算法 | 说明 |

## 8. 标定

### 8.1 标定数据库

- **路径**：`config/calibration_db.json`（约 187 KB）
- **内容**：材料、喷嘴、距离、角度、速度等维度的测量值与修正系数。
- **使用者**：`morphology.spot_interp` 通过 `velocity_compensation_coeff` 间接消费标定结果；MATLAB Server 算法本身不读取该文件。

### 8.2 标定向导

- **路径**：`repair_app/utils/calibration_wizard.py`
- **作用**：提供交互式标定向导，引导用户采集测量值并写入 `calibration_db.json`。
- **MATLAB Server 侧**：无标定算法，标定完全在 Python 侧完成。

> 标定向导的 API 与使用方式见 [09_API文档.md](./09_API文档.md)。
